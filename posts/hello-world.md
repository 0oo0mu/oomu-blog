## 블로그를 시작한 이유

오랫동안 "언젠간 블로그를 만들어야지" 하고 미뤄왔는데, 드디어 실행에 옮겼습니다. 😄

공부한 내용을 그냥 노트에 정리해두면 나중에 찾기도 힘들고, 정리가 안 되어 있으면 금방 잊어버리더라구요. 블로그에 글로 쓰면 더 깊게 이해하게 된다는 말도 있잖아요.

> "배운 것을 가르칠 수 있을 때 비로소 진정으로 이해한 것이다."
> — 리처드 파인만

## 앞으로 올릴 내용들

크게 세 가지 카테고리로 정리할 예정이에요.

### 개발 이야기

- JavaScript, CSS 같은 웹 기술 정리
- 삽질하면서 배운 것들
- 유용한 도구나 라이브러리 소개

### 공부 기록

- 책 읽고 정리한 내용
- 강의 들으면서 메모한 것들
- 개념 정리 & 요약

### 일상

- 가끔 일상 이야기도 올릴 예정

## 블로그 구조

이 블로그는 별도 서버 없이 **HTML, CSS, JavaScript**만으로 만들었어요.

```
📁 Blog/
  ├── index.html     # 메인 페이지 (포스트 목록)
  ├── post.html      # 포스트 상세 페이지
  ├── style.css      # 전체 스타일
  └── posts/
      ├── posts.json # 포스트 목록 데이터
      └── *.md       # 마크다운 글 파일들
```

새 글을 쓰려면 `posts/` 폴더에 `.md` 파일을 만들고, `posts.json`에 메타데이터를 추가하면 됩니다.
