# 글 목록 화면 만들기

08편에서 만든 이벤트 버스(`app.js`) 위에서, 이번엔 **글 목록을 카드로 보여주는 화면**을 만듭니다. 세 부품이 협력합니다.

- **posts-loader** — `posts.json`을 불러와 "글 다 불러왔어" 방송
- **renderer** — 그 목록을 받아 카드 HTML로 그리기
- **cards.css** — 카드 디자인

## 부품 1 — posts-loader.js

`js/modules` 폴더에 `posts-loader.js`를 만드세요. `posts.json`을 fetch로 불러오고, 다 되면 이벤트를 방송합니다.

```javascript
import App from '../core/app.js';

let _cache = null;      // 한 번 불러온 글은 캐시
let _catCache = null;   // (사이드바용) 카테고리 목록 캐시

const PostsLoader = {
  async load() {
    // 이미 불러왔으면 캐시 재사용
    if (_cache) {
      App.emit('posts:loaded', { posts: _cache, categories: _catCache || [] });
      return _cache;
    }

    try {
      const res = await fetch('posts/posts.json');
      if (!res.ok) throw new Error(`posts.json 실패: HTTP ${res.status}`);
      const posts = await res.json();

      // 날짜 내림차순 정렬 (최신 먼저)
      posts.sort((a, b) => new Date(b.date) - new Date(a.date));

      // (사이드바용) 폴더 기반 카테고리 목록 — 10편에서 사용
      let categories = [];
      try {
        const cres = await fetch('posts/categories.json');
        if (cres.ok) categories = await cres.json();
      } catch (_) {}

      _cache = posts;
      _catCache = categories;
      App.emit('posts:loaded', { posts, categories });
      return posts;

    } catch (error) {
      console.error('[PostsLoader]', error);
      App.emit('posts:error', { error });
      throw error;
    }
  },
};

export default PostsLoader;
```

**해설**

- `import App`으로 이벤트 버스를 가져옵니다. (경로 `../core/app.js` — `..`는 "한 폴더 위로". modules 폴더에서 core 폴더로 가려면 위로 갔다 들어가야 하죠.)
- `_cache` — 한 번 불러온 글을 저장해뒀다가, 또 요청하면 다시 fetch하지 않고 재사용합니다(빠르게). 파일 맨 위에 `let`으로 둔 이유는 값이 바뀌기 때문.
- `load()`는 `async` 함수라 안에서 `await fetch(...)`로 `posts.json`을 읽습니다. `res.ok`가 false면(파일 없음 등) 에러를 던집니다.
- `await res.json()` — 받은 내용을 자바스크립트 배열/객체로 변환. (`.text()`는 글자로, `.json()`은 JSON을 객체로.)
- 날짜순 정렬 후, `App.emit('posts:loaded', { posts, categories })`로 **"글 다 불러왔어!"** 방송을 쏩니다. 여기에 데이터를 실어 보냅니다.
- `categories`(빈 카테고리 포함 목록)는 10편 사이드바에서 씁니다. 지금 넣어둬도 무해해요. 없으면 빈 배열.
- 에러가 나면 `posts:error`를 방송하고 콘솔에 찍습니다.

## 부품 2 — renderer.js

`js/modules/renderer.js`를 만드세요. 글 목록을 받아 카드로 그립니다.

```javascript
import App from '../core/app.js';

const Renderer = {
  init() {
    // "걸러진 글 목록" 방송을 구독 → 그리기
    App.on('posts:filtered', ({ posts, query = '' }) => {
      this.render(posts, query);
    });
  },

  render(posts, query = '') {
    const grid = document.getElementById('postsGrid');
    if (!grid) return;

    if (posts.length === 0) {
      grid.innerHTML = `
        <div class="empty-state">
          <div class="empty-icon">${query ? '🔍' : '📭'}</div>
          <p>${query
            ? `<strong>"${escapeHtml(query)}"</strong>에 대한 결과가 없어요.`
            : '해당하는 포스트가 없어요.'}</p>
        </div>`;
      return;
    }

    grid.innerHTML = posts.map(post => this._cardHTML(post, query)).join('');
  },

  _cardHTML(post, query) {
    const href    = `post.html?file=${encodeURIComponent(post.file)}`;
    const title   = escapeHtml(post.title   || '');
    const excerpt = escapeHtml(post.excerpt || '');

    const categoryBadge = post.category
      ? `<span class="post-category">${escapeHtml(post.category)}</span>`
      : '';
    const tagsHTML = (post.tags || [])
      .map(t => `<span class="post-tag">#${escapeHtml(t)}</span>`)
      .join('');

    return `
      <a class="post-card" href="${href}" data-file="${escapeHtml(post.file)}">
        ${categoryBadge}
        <h2 class="post-card-title">${title}</h2>
        <p class="post-card-excerpt">${excerpt}</p>
        <div class="post-card-meta">
          <span class="post-date">${formatDate(post.date)}</span>
          <div class="post-tags">${tagsHTML}</div>
        </div>
      </a>`;
  },
};

/** HTML 특수문자 이스케이프 (XSS 방지) */
function escapeHtml(str) {
  if (!str) return '';
  return str.replace(/&/g,'&amp;').replace(/</g,'&lt;')
            .replace(/>/g,'&gt;').replace(/"/g,'&quot;');
}

/** 'YYYY-MM-DD' → '2024년 1월 15일' */
function formatDate(dateStr) {
  if (!dateStr) return '';
  return new Date(dateStr).toLocaleDateString('ko-KR', {
    year: 'numeric', month: 'long', day: 'numeric',
  });
}

export default Renderer;
```

**해설**

- `init()`에서 `App.on('posts:filtered', ...)`로 구독합니다. 여기서 `posts:loaded`가 아니라 **`posts:filtered`**를 듣는 게 포인트예요. 원래 흐름은 "로더가 불러옴 → **필터**가 걸러서 `posts:filtered` 방송 → 렌더러가 그림"입니다. 필터(카테고리·검색)는 11편에서 만들 거라, 지금은 아래 '임시 연결'로 이어줍니다.
- `render(posts)` — 글이 없으면 빈 상태 안내를, 있으면 각 글을 `_cardHTML`로 바꿔 이어붙여 그립니다. `posts.map(...)`은 **배열의 각 요소를 변환**하는 도구(여기선 글 하나 → 카드 HTML 하나), `.join('')`은 그 조각들을 하나의 문자열로 합칩니다.
- `_cardHTML(post)` — 카드 한 장의 HTML을 만듭니다. `<a>` 태그로 감싸 클릭 가능하게 하고, `href`는 `post.html?file=...`(자바스크립트가 꺼져 있어도 동작하는 대비책), `data-file`은 나중에 SPA 라우터(10편)가 클릭을 가로챌 때 쓸 표시입니다.
- **`escapeHtml`** — 아주 중요한 안전장치입니다. 글 제목·요약에 `<` 같은 특수문자가 있으면 HTML로 오인돼 화면이 깨지거나 **악성 스크립트가 실행(XSS 공격)**될 수 있어요. 그래서 `<`를 `&lt;`처럼 안전한 형태로 바꿔줍니다. 사용자/외부에서 온 글자를 화면에 넣기 전엔 항상 이스케이프하는 게 습관입니다.
- `formatDate` — `2026-07-14`를 `2026년 7월 14일`처럼 한국식으로 바꿉니다. `toLocaleDateString('ko-KR', ...)`가 브라우저 내장 기능이에요.

## 부품 3 — cards.css

`css/cards.css`를 만드세요. 카드 그리드와 디자인입니다.

```css
/* 카드들이 배치되는 그리드 컨테이너 */
.posts-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(min(300px, 100%), 1fr));
  gap: 1.5rem;
}

/* 개별 포스트 카드 */
.post-card {
  display: flex;
  flex-direction: column;
  gap: 0.7rem;
  padding: 1.5rem;
  background: var(--bg-card);
  border: 1px solid var(--border);
  border-radius: 12px;
  text-decoration: none;
  color: inherit;
  transition: transform var(--transition), box-shadow var(--transition), border-color var(--transition);
  cursor: pointer;
}
.post-card:hover {
  transform: translateY(-3px);
  box-shadow: var(--shadow);
  border-color: var(--accent);
  opacity: 1;
}

/* 카테고리 배지 */
.post-category {
  align-self: flex-start;
  font-size: 0.72rem;
  font-weight: 600;
  text-transform: uppercase;
  letter-spacing: 0.06em;
  color: var(--accent);
  background: var(--accent-light);
  padding: 0.2rem 0.6rem;
  border-radius: 4px;
}

.post-card-title {
  font-size: 1.1rem;
  font-weight: 700;
  color: var(--text-heading);
  line-height: 1.4;
  letter-spacing: -0.02em;
}

/* 요약 (최대 3줄만 보이고 잘림) */
.post-card-excerpt {
  font-size: 0.88rem;
  color: var(--text-muted);
  line-height: 1.6;
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
  flex: 1;
}

/* 카드 하단 메타 (날짜 + 태그) */
.post-card-meta {
  display: flex;
  align-items: center;
  justify-content: space-between;
  flex-wrap: wrap;
  gap: 0.5rem;
  margin-top: auto;
}
.post-date { font-size: 0.78rem; color: var(--text-muted); }

.post-tags { display: flex; flex-wrap: wrap; gap: 0.3rem; }
.post-tag {
  font-size: 0.72rem;
  color: var(--text-muted);
  background: var(--bg);
  border: 1px solid var(--border);
  padding: 0.12rem 0.5rem;
  border-radius: 4px;
}
```

**CSS 새 개념 몇 가지**

- **`display: grid`** — 자식들을 **격자(그리드)**로 배치합니다. `grid-template-columns`가 열을 어떻게 나눌지 정해요.
- **`repeat(auto-fill, minmax(min(300px,100%), 1fr))`** — 말은 어렵지만 뜻은 "칸 하나 최소 300px, 남는 공간은 나눠 갖고(`1fr`), 화면 폭에 맞게 열 개수를 **자동으로** 채워라". 그래서 넓은 화면엔 카드가 3~4개씩, 좁은 폰엔 1개씩 자동으로 배치됩니다. 이게 **반응형**(화면 크기에 맞춰 변하는) 그리드예요.
- **`display: flex; flex-direction: column`** — 카드 안 요소들을 세로로 쌓습니다. `margin-top: auto`(메타 영역)는 "남는 공간을 위에 다 밀어넣어" 날짜/태그를 **카드 맨 아래에 고정**합니다.
- **`-webkit-line-clamp: 3`** — 요약을 **3줄까지만** 보이게 하고 넘치면 `...`로 자릅니다. 카드 높이를 가지런하게 유지해줘요.
- **`transition`과 `:hover`의 `translateY(-3px)`** — 마우스를 올리면 카드가 살짝 위로 떠오르고 테두리가 포인트 색으로 바뀌는 효과. `box-shadow`로 그림자도 생깁니다.

## 조립하기 — index.html + 진입점

### index.html 본문

`index.html`의 `<head>`에 `cards.css`를 추가하고(변수→base→cards 순), `<body>`를 목록용으로 바꿉니다.

```html
<head>
  <meta charset="UTF-8" />
  <title>내 블로그</title>
  <link rel="stylesheet" href="css/variables.css" />
  <link rel="stylesheet" href="css/base.css" />
  <link rel="stylesheet" href="css/cards.css" />
</head>
<body>
  <div class="page-container">
    <h1>내 블로그</h1>
    <div class="posts-grid" id="postsGrid"></div>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/marked@9/marked.min.js"></script>
  <script type="module" src="js/app-index.js"></script>
</body>
```

`id="postsGrid"`인 빈 `<div>`가 카드가 채워질 자리입니다.

### 진입점 app-index.js

`js/app-index.js`를 만들어 부품들을 조립합니다. (이전에 만든 `js/app.js`는 이제 안 쓰니 지워도 됩니다.)

```javascript
import App         from './core/app.js';
import PostsLoader from './modules/posts-loader.js';
import Renderer    from './modules/renderer.js';

// 렌더러 등록 (init 안에서 posts:filtered 구독)
App.register('renderer', Renderer);

// [임시 연결] 필터(11편) 만들기 전까지, 불러온 글을 그대로 "걸러진 글"로 넘김
App.on('posts:loaded', ({ posts }) => {
  App.emit('posts:filtered', { posts });
});

// 글 불러오기 → posts:loaded 방송
PostsLoader.load();
```

**흐름 정리**: `PostsLoader.load()`가 `posts.json`을 불러와 `posts:loaded`를 방송 → 임시 연결이 그걸 받아 `posts:filtered`로 다시 방송 → `Renderer`가 그걸 듣고 카드를 그림. 08편의 이벤트 버스가 실제로 작동하는 순간입니다!

> `App.register(...)`(구독)를 `PostsLoader.load()`(발행)보다 **먼저** 둔 것에 주목하세요. 08편에서 강조한 "구독 먼저, 발행 나중" 규칙입니다.

로컬 서버로 열어 새로고침하면, `posts` 폴더의 글들이 **카드 그리드로 좍 펼쳐집니다.** 여러 개 만들어보면 자동으로 열이 채워지는 것도 확인해보세요.

## 자주 나는 실수

- **카드가 안 뜨고 빈 화면** → `posts.json`이 있는지(=`node build.js` 돌렸는지), 로컬 서버(`http://`)로 열었는지 확인. 콘솔(F12) 에러도 보세요.
- **`postsGrid`를 못 찾음** → HTML의 `id`와 JS의 `getElementById` 철자가 같아야 합니다.
- **글은 있는데 목록이 하나도 안 나옴** → 임시 연결(`posts:loaded → posts:filtered`)을 빠뜨렸을 수 있어요. renderer는 `posts:filtered`를 듣습니다.
- **카드 디자인이 안 먹음** → `cards.css`를 `<head>`에 연결했는지, 변수 파일이 그보다 먼저인지 확인.

## 정리

- 목록 화면은 **posts-loader(불러오기) → (필터) → renderer(그리기)**의 협업이다.
- posts-loader는 `posts.json`을 fetch해 `posts:loaded` 방송, renderer는 `posts:filtered`를 구독해 카드로 그린다.
- 화면에 넣기 전 **escapeHtml**로 안전 처리(XSS 방지)한다.
- **CSS 그리드**로 반응형 카드 배치, `line-clamp`로 요약 3줄 제한.
- 필터가 아직 없으니 **임시 연결**로 이어 붙였다(11편에서 교체).

다음 편(10)에서는 카드를 클릭하면 **페이지 이동 없이 글이 열리는 SPA 라우터(router.js)**를 만들고, 글 본문을 보여주는 포스트 뷰를 완성합니다.
