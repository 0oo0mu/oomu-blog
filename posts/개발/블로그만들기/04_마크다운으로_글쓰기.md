# 마크다운으로 글쓰기

지금까지 만든 페이지의 글자는 HTML 태그로 직접 적었습니다. 그런데 블로그 글을 매번 `<h2>`, `<p>`, `<ul>`로 쓰면 너무 번거롭죠. 그래서 블로그는 보통 **마크다운**으로 글을 씁니다. 이번 편에서 마크다운을 화면에 렌더링하고, 이 블로그의 실제 파서 파일 **`markdown.js`**를 완성합니다.

## 마크다운이 뭔가요

**마크다운(Markdown)**은 **아주 간단한 기호로 글의 서식을 표현하는 문법**입니다. 예를 들어:

```markdown
# 큰 제목
## 중간 제목

이건 평범한 문단입니다. 단어를 **굵게** 하거나 *기울임*도 됩니다.

- 목록 항목 1
- 목록 항목 2

[링크 텍스트](https://example.com)
```

- `#` 하나 = 큰 제목(`<h1>`), `##` 두 개 = 그다음 제목(`<h2>`)
- `**굵게**`, `*기울임*`
- `- ` 로 시작하면 목록
- `[글자](주소)` 는 링크

HTML로 `<h1>큰 제목</h1>` 쓰는 것보다 `# 큰 제목`이 훨씬 빠르고 읽기도 편하죠. 그래서 개발자 문서, 깃허브 README, 블로그가 대부분 마크다운을 씁니다.

우리 계획은 이렇습니다.

> 글은 마크다운 `.md` 파일로 쓴다 → 프로그램이 그걸 읽어 **HTML로 바꿔서** 화면에 보여준다.

이 "마크다운 → HTML 변환"을 직접 만들려면 아주 복잡합니다(수많은 규칙 처리). 그래서 **이미 잘 만들어진 도구**를 가져다 씁니다.

## marked.js — 마크다운 변환기

**marked.js**는 마크다운 문자열을 HTML로 바꿔주는 유명한 자바스크립트 라이브러리입니다. 우리가 설치할 필요 없이, 인터넷 주소(CDN)에서 바로 불러다 쓸 수 있어요.

**CDN**이란 "라이브러리 파일을 인터넷에 올려두고 누구나 주소로 가져다 쓰게 해주는 서비스"입니다. `<script>` 한 줄로 불러옵니다.

```html
<script src="https://cdn.jsdelivr.net/npm/marked@9/marked.min.js"></script>
```

- `<script>` — 자바스크립트를 불러오거나 실행하는 태그
- `src="..."` — 불러올 자바스크립트 파일의 주소
- `marked@9` — marked의 9번 버전을 쓰겠다는 뜻 (버전을 고정하면 나중에 갑자기 동작이 바뀌는 걸 막아줍니다)

이 줄을 넣으면 `marked`라는 도구가 준비되고, `marked.parse("# 안녕")` 처럼 부르면 `<h1>안녕</h1>`을 돌려줍니다.

## 자바스크립트 아주 살짝 — 화면 조작 3단계

여기서 처음으로 **자바스크립트(JS)**를 씁니다. JS는 웹페이지에 **동작**을 넣는 언어예요(HTML=뼈대, CSS=꾸밈, JS=동작). 지금은 딱 세 가지 개념만 알면 됩니다.

1. **요소 가져오기** — `document.getElementById('id이름')` : HTML에서 특정 아이디를 가진 요소를 집어옵니다.
2. **내용 바꾸기** — 그 요소의 `.innerHTML = "..."` : 요소 안의 HTML 내용을 통째로 바꿉니다.
3. **함수 호출** — `marked.parse("...")` : 도구에게 일을 시키고 결과를 받습니다.

이 셋을 조합해봅시다. `index.html`의 `<body>` 안에 빈 상자 하나와 스크립트를 넣습니다.

```html
<body>
  <div id="content"></div>

  <script src="https://cdn.jsdelivr.net/npm/marked@9/marked.min.js"></script>
  <script>
    const md = "# 안녕, 마크다운\n\n이건 **굵게** 쓴 글이야.";
    const html = marked.parse(md);
    document.getElementById('content').innerHTML = html;
  </script>
</body>
```

- `const md = "..."` — `const`는 값에 이름을 붙이는 방법입니다(변수 만들기). `md`라는 이름에 마크다운 문자열을 담았어요. `\n`은 줄바꿈을 뜻하는 특수 표시입니다.
- `marked.parse(md)` — 마크다운을 HTML로 변환해서 `html`에 담습니다.
- `document.getElementById('content').innerHTML = html` — id가 `content`인 `<div>`를 찾아, 그 안을 변환된 HTML로 채웁니다.

저장 → 새로고침하면, `<div>` 자리에 "안녕, 마크다운"이 제목으로, "굵게"가 진하게 나타납니다. **마크다운 문자열이 실제 화면 요소로 바뀐** 거예요.

> ⚠️ 스크립트 순서 주의: marked를 불러오는 `<script src=...>`가 **먼저** 와야, 그다음 스크립트에서 `marked`를 쓸 수 있습니다.

## Front Matter — 글의 정보표

블로그 글에는 본문 말고도 **제목·날짜·카테고리·태그** 같은 정보가 필요합니다. 이걸 `.md` 파일 맨 위에 `---`로 감싸서 적는 관습이 있는데, 이 영역을 **Front Matter**라고 부릅니다.

```markdown
---
title: 나의 첫 글
date: 2026-07-14
category: 일상
tags: [블로그, 시작]
---

# 본문 시작

여기부터가 진짜 글 내용입니다.
```

- 위쪽 `---` ~ `---` 사이 = **정보(메타데이터)**
- 그 아래 = **본문(마크다운)**

그러니 `.md` 파일을 화면에 보여주려면, 먼저 이 파일을 **"정보 부분"과 "본문 부분"으로 나눠야** 합니다. 이걸 해주는 게 우리가 만들 `markdown.js`의 두 번째 기능이에요.

## 실제 파일 — js/modules/markdown.js

이제 이 블로그가 실제로 쓰는 마크다운 모듈을 만듭니다. `Blog` 폴더에 `js` 폴더를 만들고, 그 안에 `modules` 폴더를, 다시 그 안에 `markdown.js` 파일을 만드세요. (`js/modules/markdown.js`) 아래는 실제 코드 그대로입니다.

```javascript
/**
 * js/modules/markdown.js — 마크다운 파서
 *
 * marked.js(CDN)를 래핑합니다.
 */

const Markdown = {
  /**
   * 마크다운 텍스트를 HTML 문자열로 변환합니다.
   */
  parse(mdText) {
    if (typeof window.marked === 'undefined') {
      console.error('[Markdown] marked.js가 로드되지 않았습니다.');
      return `<p>마크다운 파서를 불러올 수 없습니다.</p>`;
    }
    return window.marked.parse(mdText);
  },

  /**
   * 마크다운 파일 맨 위의 Front Matter를 파싱합니다.
   * @returns {{ meta: Object, content: string }}
   */
  parseFrontMatter(raw) {
    const meta = {};

    // 파일이 ---\n으로 시작하는지 확인 (없으면 그대로 반환)
    const match = raw.match(/^---\n([\s\S]*?)\n---\n([\s\S]*)$/);
    if (!match) return { meta, content: raw };

    // "키: 값" 을 줄 단위로 파싱
    match[1].split('\n').forEach(line => {
      const colonIdx = line.indexOf(':');
      if (colonIdx === -1) return; // ':' 없는 줄은 건너뜀

      const key = line.slice(0, colonIdx).trim();
      const val = line.slice(colonIdx + 1).trim();

      if (key === 'tags') {
        meta.tags = val
          .replace(/[\[\]]/g, '')      // 대괄호 제거
          .split(',')
          .map(t => t.trim())
          .filter(Boolean);            // 빈 문자열 제거
      } else {
        meta[key] = val;
      }
    });

    return { meta, content: match[2] };
  },
};

// marked.js 옵션 설정 (window.marked가 있을 때만)
if (typeof window !== 'undefined') {
  window.addEventListener('load', () => {
    if (window.marked) {
      window.marked.setOptions({
        gfm:    true, // GitHub Flavored Markdown (표, 취소선 등)
        breaks: true, // 줄바꿈을 <br>로 변환
      });
    }
  });
}

export default Markdown;
```

### 이 파일 해설

먼저 큰 그림: 이 파일은 **`Markdown`이라는 객체**를 만들어 두 가지 기능(`parse`, `parseFrontMatter`)을 담고, 맨 아래에서 `export`로 내보냅니다.

- **`const Markdown = { ... }`** — 관련 기능을 하나로 묶은 **객체**입니다. 중괄호 안에 `parse`, `parseFrontMatter`라는 **메서드(객체에 속한 함수)**를 넣었어요. 이렇게 묶으면 `Markdown.parse(...)`처럼 정리된 이름으로 부를 수 있습니다.

- **`parse(mdText)`** — 마크다운 문자열을 HTML로 바꿉니다.
  - `if (typeof window.marked === 'undefined')` — 혹시 marked.js가 안 불러와졌으면(undefined면) 에러를 콘솔에 찍고 안내 문구를 반환합니다. **"도구가 없을 때를 대비"**하는 방어 코드예요. `window`는 브라우저 전체를 뜻하는 최상위 객체이고, CDN으로 불러온 marked는 `window.marked`에 담깁니다.
  - 정상이면 `window.marked.parse(mdText)`로 변환 결과를 돌려줍니다.

- **`parseFrontMatter(raw)`** — `.md` 파일 전체 텍스트(`raw`)를 **정보(meta)**와 **본문(content)**으로 나눕니다.
  - `raw.match(/^---\n([\s\S]*?)\n---\n([\s\S]*)$/)` — 이 알쏭달쏭한 것은 **정규식(regular expression)**입니다. "특정 패턴의 글자를 찾는 도구"예요. 여기선 "맨 앞이 `---`로 시작하고, 다시 `---`로 닫힌 뒤 본문이 이어지는" 모양을 찾습니다. 지금은 **"Front Matter 영역과 본문을 뽑아내는 마법의 패턴"** 정도로 이해하면 충분합니다.
  - 패턴이 안 맞으면(`if (!match)`) Front Matter가 없는 것이니, 정보는 빈 객체 `{}`, 본문은 원본 그대로 돌려줍니다.
  - 맞으면 정보 부분(`match[1]`)을 줄 단위로 쪼개서 `키: 값`을 하나씩 뽑습니다. `line.indexOf(':')`로 콜론 위치를 찾고, 그 앞을 `key`, 뒤를 `val`로 자릅니다. `.trim()`은 앞뒤 공백 제거예요.
  - `tags`만 특별 취급합니다. `[블로그, 시작]`처럼 대괄호에 쉼표로 적혀 있으니, 대괄호를 지우고 쉼표로 쪼개서 **배열**(여러 값을 담는 목록)로 만듭니다.
  - 결과로 `{ meta: {정보들}, content: "본문" }`을 돌려줍니다.

- **맨 아래 `window.addEventListener('load', ...)`** — 페이지 로딩이 끝나면 marked에 옵션을 겁니다.
  - `gfm: true` — 표, 취소선 등 **깃허브 스타일 마크다운**을 지원.
  - `breaks: true` — 마크다운에서 그냥 엔터 한 번 친 줄바꿈도 실제 줄바꿈(`<br>`)으로 처리. (원래 마크다운은 엔터 한 번을 무시하는데, 블로그에선 친 대로 줄이 바뀌는 게 자연스러워서 켭니다.)

- **`export default Markdown;`** — 이 파일이 만든 `Markdown` 객체를 **다른 파일에서 가져다 쓸 수 있게 내보냅니다.** 자바스크립트를 여러 파일로 나눠 만들 때(모듈), 한 파일에서 `export`한 걸 다른 파일에서 `import`로 받아옵니다. 다음 편부터 이 방식으로 파일을 조립합니다.

## 자주 나는 실수

- **`marked is not defined` 에러** → marked CDN `<script>`가 이 코드보다 뒤에 있거나, 주소 오타. 순서와 주소 확인.
- **Front Matter가 본문에 그대로 보인다** → `---`가 파일 **맨 첫 줄**에 있어야 하고, `---` 아래위에 딴 글자가 없어야 합니다. 또 각 줄은 `키: 값`(콜론+공백) 형식.
- **한글 tags가 이상하게 잘린다** → `tags: [태그1, 태그2]`처럼 쉼표로 구분. 대괄호는 있어도 없어도 됩니다.
- **`export`에서 에러** → `export`는 `<script type="module">`에서만 됩니다. 다음 편에서 이 module 방식으로 연결할 거예요. 지금은 파일만 만들어 두면 됩니다.

## 정리

- 블로그 글은 **마크다운(`.md`)**으로 쓰고, **marked.js**로 HTML로 변환한다.
- 자바스크립트 3종 세트: `getElementById`(요소 집기) · `.innerHTML`(내용 바꾸기) · 함수 호출.
- `.md` 파일 맨 위 `---` 사이는 **Front Matter**(제목·날짜·태그 등 정보), 그 아래는 본문.
- 실제 파일 **`markdown.js`**를 완성했다: `parse`(변환) + `parseFrontMatter`(정보/본문 분리) + marked 옵션 설정 + `export`.

다음 편(05)에서는 **자바스크립트 기초를 조금 더 다지고**, `.md` 파일을 프로그램이 직접 **불러와서(fetch)** 화면에 띄웁니다. 드디어 "파일로 쓴 글이 사이트에 뜨는" 순간입니다.
