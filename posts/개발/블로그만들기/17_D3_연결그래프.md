# D3 연결 그래프 (전체 코드 해설)

글과 카테고리가 점·선으로 이어지는 연결 그래프입니다. `graph.js`는 이 시리즈에서 가장 길지만, 큰 그림은 단순합니다: **데이터(노드·링크) 만들기 → D3로 그리기 → 물리 시뮬레이션으로 배치.** 전체 화면 그래프와 사이드바 미니 그래프 두 개를 담당해요. 구간별로 전부 봅니다.

## 사전 개념 (요약)

- **D3.js** — 데이터를 SVG 도형으로 그리는 시각화 라이브러리(CDN 로드).
- **노드/링크** — 노드는 점(글·카테고리), 링크는 두 노드를 잇는 선.
- **force simulation** — 노드에 밀고 당기는 가상의 힘을 걸어 스스로 배치되게 하는 D3 기능.

## [1] 초기화

```javascript
import App    from '../core/app.js';
import Router from '../core/router.js';

const Graph = {
  _posts:       [],
  _currentFile: null,
  _isVisible:   false,
  _sim:         null,   // 전체 그래프 시뮬레이션
  _miniSim:     null,   // 미니 그래프 시뮬레이션
  _d3:          null,

  init() {
    // 글 로드되면 미니 그래프 렌더
    App.on('posts:loaded', ({ posts, categories }) => {
      this._posts = posts;
      this._categories = categories || [];
      this._loadD3().then(() => { this._d3 = window.d3; this._rebuildMini(); });
    });
    // 현재 보는 글 추적 → 미니 그래프 갱신
    App.on('router:post', ({ file }) => {
      this._currentFile = file;
      if (this._isVisible) this._rebuild();
      this._rebuildMini();
    });
    App.on('router:list', () => {
      this._currentFile = null;
      if (this._isVisible) this._rebuild();
      this._rebuildMini();
    });

    this._createButton();
    this._createOverlay();
  },
```

이벤트 버스를 구독합니다. 글이 로드되면(`posts:loaded`) D3를 불러와 미니 그래프를 그리고, 현재 보는 글이 바뀌면(`router:post`/`router:list`) 미니 그래프를 다시 그립니다. 헤더의 그래프 버튼과 전체화면 오버레이도 만들어 둡니다.

    return new Promise((resolve, reject) => {
      const s = document.createElement('script');
      s.src = 'https://cdn.jsdelivr.net/npm/d3@7/dist/d3.min.js';

      document.head.appendChild(s);
    });

- 그래프를 **열 때만** D3를 불러옵니다(`_loadD3`). 무거운 라이브러리라, 그래프를 안 보면 다운로드도 안 해 첫 페이지가 빨라집니다. `Promise`로 "로드 끝나면 그다음"을 잇습니다.
- 닫으면 시뮬레이션을 멈추고 SVG를 비웁니다(자원 정리).

## [4] 데이터 빌드 — 노드와 링크

```javascript
  _buildData() {
    const posts = this._posts;
    const nodes = [], links = [], byId = {};
    const add = (node) => { nodes.push(node); byId[node.id] = node; return node; };

    // 카테고리 계층 모으기 (개발, 개발/C++ ...)
    const catSet = new Set();
    posts.forEach(p => {
      if (!p.category) return;
      p.category.split('/').reduce((acc, part) => {
        const full = acc ? `${acc}/${part}` : part;
        catSet.add(full); return full;
      }, '');
    });

    // 각 카테고리의 하위 포함 글 수
    const catPostCount = {};
    catSet.forEach(cat => { catPostCount[cat] = 0; });
    posts.forEach(p => {
      if (!p.category) return;
      let cur = '';
      p.category.split('/').forEach(part => {
        cur = cur ? `${cur}/${part}` : part;
        if (catPostCount[cur] !== undefined) catPostCount[cur]++;
      });
    });

    // 카테고리 노드 생성 (크기 = 깊이·글수에 따라)
    catSet.forEach(cat => {
      const parts = cat.split('/');
      const depth = parts.length, count = catPostCount[cat] || 0;
      const depthBonus = Math.max(0, 3 - depth) * 2;
      const countBonus = Math.sqrt(count) * 1.4;
      const r = Math.min(20, Math.round(8 + depthBonus + countBonus));
      add({ id: `cat:${cat}`, type: 'category', label: parts[parts.length-1], r, depth, count, isCurrent: false });
    });
    // 부모→자식 링크
    catSet.forEach(cat => {
      const parts = cat.split('/');
      if (parts.length > 1)
        links.push({ source: `cat:${parts.slice(0,-1).join('/')}`, target: `cat:${cat}`, ltype: 'cat', dist: 60 });
    });

    // 글 노드 + 글→카테고리 링크
    posts.forEach(p => {
      const isCurrent = (p.file === this._currentFile);
      add({ id: `post:${p.file}`, type: 'post', label: p.title || p.file, file: p.file, r: isCurrent ? 14 : 7, isCurrent });
      if (p.category && byId[`cat:${p.category}`])
        links.push({ source: `cat:${p.category}`, target: `post:${p.file}`, ltype: 'cat', dist: 55 });
    });

    return { nodes, links };
  },
```

13편 사이드바 트리와 **똑같은 원리**로 카테고리 계층을 모읍니다(경로를 `/`로 쪼개 누적). 각 카테고리를 노드로 만들되 **크기(`r`)를 깊이와 글 수에 따라** 다르게 줘, 상위 폴더·글 많은 폴더가 크게 보입니다. 카테고리끼리는 부모→자식으로, 글은 자기 카테고리에 링크로 잇습니다. **지금 보는 글**(`isCurrent`)은 더 크게 표시해요.

## [5] 전체 그래프 렌더링 — force simulation

```javascript
  _rebuild() {
    if (this._sim) { this._sim.stop(); this._sim = null; }
    const svgEl = document.getElementById('graphSvg');
    svgEl.innerHTML = '';
    const { nodes, links } = this._buildData();
    if (!nodes.length) return;

    this._resizeSvg();
    const W = svgEl.clientWidth, H = svgEl.clientHeight;
    const d3 = window.d3, svg = d3.select('#graphSvg');

    // 줌/패닝: g 그룹에 변환 적용, 처음엔 중앙으로 이동
    const g = svg.append('g').attr('class', 'graph-root');
    const zoom = d3.zoom().scaleExtent([0.15, 5]).on('zoom', ev => g.attr('transform', ev.transform));
    svg.call(zoom).call(zoom.transform, d3.zoomIdentity.translate(W/2, H/2));

    // 링크(선)
    const linkSel = g.append('g').attr('class', 'g-links')
      .selectAll('line').data(links).join('line')
      .attr('class', d => `graph-link graph-link-${d.ltype}`);

    // 노드 그룹 + 드래그
    const nodeSel = g.append('g').attr('class', 'g-nodes')
      .selectAll('g').data(nodes).join('g')
      .attr('class', d => `g-node g-node-${d.type}${d.isCurrent ? ' g-node-current' : ''}`)
      .call(d3.drag()
        .on('start', (ev, d) => { if (!ev.active) this._sim.alphaTarget(0.3).restart(); d.fx = d.x; d.fy = d.y; })
        .on('drag',  (ev, d) => { d.fx = ev.x; d.fy = ev.y; })
        .on('end',   (ev, d) => { if (!ev.active) this._sim.alphaTarget(0); d.fx = null; d.fy = null; }));

    // 카테고리 = 둥근 사각형, 글 = 원, 라벨
    nodeSel.filter(d => d.type === 'category').append('rect')
      .attr('class', 'node-shape')
      .attr('width', d => d.r*1.9).attr('height', d => d.r*1.9)
      .attr('x', d => -d.r*0.95).attr('y', d => -d.r*0.95).attr('rx', 4);
    nodeSel.filter(d => d.type !== 'category').append('circle')
      .attr('class', 'node-shape').attr('r', d => d.r);
    nodeSel.append('text').attr('class', 'node-label')
      .attr('dy', d => d.r + 13).attr('text-anchor', 'middle')
      .text(d => (d.type === 'category' || d.isCurrent)
        ? d.label
        : (d.label.length > 14 ? d.label.slice(0,13) + '…' : d.label));

    // 글 노드 클릭 → 글 열기
    nodeSel.filter(d => d.type === 'post').style('cursor', 'pointer')
      .on('click', (ev, d) => { ev.stopPropagation(); this.close(); Router.goPost(d.file); });

    // 툴팁 (마우스 올리면 이름 표시)
    const tooltip = document.getElementById('graphTooltip');
    nodeSel
      .on('mouseenter', (ev, d) => { tooltip.textContent = d.type==='category' ? `${d.label} (${d.count}개)` : d.label; tooltip.style.display='block'; this._moveTooltip(ev); })
      .on('mousemove', ev => this._moveTooltip(ev))
      .on('mouseleave', () => { tooltip.style.display='none'; });

    // ── force simulation ──
    this._sim = d3.forceSimulation(nodes)
      .force('link', d3.forceLink(links).id(d => d.id).distance(d => d.dist || 60).strength(0.7))
      .force('charge', d3.forceManyBody().strength(d => {
        if (d.type === 'category') return -90 - d.r * 7; // 큰 카테고리일수록 강하게 밀어냄
        if (d.isCurrent)          return -160;
        return -120;
      }))
      .force('collision', d3.forceCollide(d => d.r + 6)) // 노드끼리 안 겹치게
      .force('x', d3.forceX(0).strength(0.04))            // 중앙으로 약하게 모음
      .force('y', d3.forceY(0).strength(0.04))
      .on('tick', () => {
        linkSel.attr('x1', d => d.source.x).attr('y1', d => d.source.y)
               .attr('x2', d => d.target.x).attr('y2', d => d.target.y);
        nodeSel.attr('transform', d => `translate(${d.x ?? 0},${d.y ?? 0})`);
      });
  },

  _resizeSvg() {
    const wrap = document.querySelector('.graph-canvas-wrap');
    const svg  = document.getElementById('graphSvg');
    if (!wrap || !svg) return;
    svg.setAttribute('width', wrap.clientWidth);
    svg.setAttribute('height', wrap.clientHeight);
  },
  _moveTooltip(ev) {
    const tt = document.getElementById('graphTooltip');
    if (!tt) return;
    tt.style.left = `${ev.clientX + 14}px`;
    tt.style.top  = `${ev.clientY - 36}px`;
  },
```

전체 그래프의 핵심입니다.

- **줌/패닝** — `d3.zoom()`을 `svg`에 걸고, 변환을 `g` 그룹에 적용합니다. 처음엔 원점을 화면 중앙으로 옮겨(`translate(W/2, H/2)`) 데이터가 (0,0) 근처에 모여도 가운데 보이게 합니다.
- **`.data(...).join(...)`** — 링크 배열·노드 배열마다 `line`·`g`를 하나씩 만듭니다. 카테고리는 `rect`(둥근 사각형), 글은 `circle`(원), 그리고 `text` 라벨을 붙여요.
- **드래그** — `d.fx`/`d.fy`(고정 좌표)를 마우스 위치로 두면 그 노드가 손을 따라오고, 놓으면 고정을 풀어 다시 힘에 맡깁니다. `alphaTarget`은 시뮬레이션을 다시 "데워" 움직이게 하는 것.
- **force들** — `forceLink`(이어진 노드 당김), `forceManyBody`(음수=서로 밀어냄, 큰 카테고리는 더 강하게), `forceCollide`(반지름만큼 안 겹치게), `forceX/forceY`(중앙으로 약하게 수렴). 이 힘들이 균형을 이뤄 예쁜 별자리가 됩니다.
- **`tick`** — 매 프레임 좌표 갱신. 링크는 양 끝점(`source.x` 등), 노드는 `transform: translate`로 옮깁니다.
- **툴팁·클릭** — 노드에 마우스를 올리면 이름/글 수를, 글 노드를 클릭하면 그래프를 닫고 해당 글로 이동(`Router.goPost`)합니다.

## [6] 미니 그래프 — 사이드바 내장

미니 그래프는 사이드바에 상시 표시되는 작은 버전입니다. 데이터 규칙이 조금 다릅니다: **글을 보는 중이면** 그 글의 카테고리 계층 + 같은 카테고리 글들만, **목록 화면이면** 카테고리 노드만(글은 너무 많아 생략) 보여줍니다.

```javascript
  _buildMiniData() {
    const posts = this._posts;
    const nodes = [], links = [], byId = {};
    const add = n => { nodes.push(n); byId[n.id] = n; return n; };

    if (this._currentFile) {
      // 글 보는 중: 현재 카테고리 계층 + 소속 글
      const cur = posts.find(p => p.file === this._currentFile);
      const cat = cur?.category;
      if (!cat) return { nodes, links };
      const parts = cat.split('/');
      let pathSoFar = '';
      parts.forEach((part, i) => {
        const prev = pathSoFar;
        pathSoFar = pathSoFar ? `${pathSoFar}/${part}` : part;
        add({ id: `cat:${pathSoFar}`, type: 'category', label: part, r: i === parts.length-1 ? 14 : 9, depth: i+1, isCurrent: false });
        if (prev) links.push({ source: `cat:${prev}`, target: `cat:${pathSoFar}` });
      });
      posts.filter(p => p.category === cat || p.category?.startsWith(cat + '/')).forEach(p => {
        const isCurrent = p.file === this._currentFile;
        add({ id: `post:${p.file}`, type: 'post', label: p.title || p.file, file: p.file, r: isCurrent ? 10 : 5, isCurrent });
        const linkTarget = byId[`cat:${p.category}`] ? `cat:${p.category}` : `cat:${cat}`;
        links.push({ source: linkTarget, target: `post:${p.file}` });
      });
    } else {
      // 목록 화면: 카테고리 노드만 (빈 카테고리 포함)
      const catSet = new Set(), catPostCount = {};
      posts.forEach(p => p.category?.split('/').reduce((a, part) => { const f = a?`${a}/${part}`:part; catSet.add(f); return f; }, ''));
      (this._categories || []).forEach(cat => cat.split('/').reduce((a, part) => { const f = a?`${a}/${part}`:part; catSet.add(f); return f; }, ''));
      catSet.forEach(c => catPostCount[c] = 0);
      posts.forEach(p => { let cur=''; p.category?.split('/').forEach(part => { cur = cur?`${cur}/${part}`:part; if (catPostCount[cur]!==undefined) catPostCount[cur]++; }); });
      catSet.forEach(cat => {
        const parts = cat.split('/'), depth = parts.length, count = catPostCount[cat] || 0;
        const r = Math.min(18, Math.round(8 + Math.max(0, 3-depth)*3 + Math.sqrt(count)*1.5));
        add({ id: `cat:${cat}`, type: 'category', label: parts[parts.length-1], r, depth, count, isCurrent: false });
      });
      catSet.forEach(cat => { const parts = cat.split('/'); if (parts.length>1) links.push({ source: `cat:${parts.slice(0,-1).join('/')}`, target: `cat:${cat}` }); });
    }
    return { nodes, links };
  },
```

렌더링은 전체 그래프와 비슷하되 좁은 공간(~220×185)에 맞춘 파라미터를 씁니다. 여기서 이 블로그를 만들며 **실제로 고쳤던 버그 두 개**가 핵심 교훈입니다.

```javascript
  _rebuildMini() {
    const d3 = this._d3 || window.d3;
    const svgEl = document.getElementById('miniGraphSvg');
    if (!d3 || !svgEl) return;
    if (this._miniSim) { this._miniSim.stop(); this._miniSim = null; }
    const w = svgEl.clientWidth || 220, h = svgEl.clientHeight || 185;
    const svg = d3.select(svgEl);
    svg.selectAll('*').remove();

    const { nodes, links } = this._buildMiniData();
    if (!nodes.length) return;
    const nodeById = {};
    nodes.forEach(n => nodeById[n.id] = n);
    const validLinks = links.filter(l => nodeById[l.source] && nodeById[l.target]);

    // 줌: 현재 변환을 저장 (드래그 좌표 보정용)
    const g = svg.append('g');
    let miniTransform = d3.zoomIdentity;
    svg.call(d3.zoom().scaleExtent([0.4, 4])
      .on('zoom', ev => { miniTransform = ev.transform; g.attr('transform', ev.transform); }));

    const linkSel = g.append('g').selectAll('line').data(validLinks).join('line')
      .style('stroke', 'var(--border)').style('stroke-width', '1px').style('stroke-opacity', '0.7');
    const nodeSel = g.append('g').selectAll('g').data(nodes).join('g')
      .style('cursor', d => d.type === 'post' ? 'pointer' : 'default');

    // 카테고리 사각형 / 글 원 / 라벨 (SVG 색은 .style로 CSS 변수 적용!)
    nodeSel.filter(d => d.type === 'category').append('rect')
      .attr('rx', 3).attr('x', d => -d.r).attr('y', d => -d.r*0.65)
      .attr('width', d => d.r*2).attr('height', d => d.r*1.3)
      .style('fill', 'var(--accent)').style('fill-opacity', '0.75').style('stroke', 'var(--accent)');
    nodeSel.filter(d => d.type === 'post').append('circle').attr('r', d => d.r)
      .style('fill', d => d.isCurrent ? 'var(--accent)' : 'var(--text-muted)')
      .style('fill-opacity', d => d.isCurrent ? '1' : '0.6');

    nodeSel.filter(d => d.type === 'post').on('click', (ev, d) => Router.goPost(d.file));

    // 드래그: 포인터를 줌 변환의 역으로 풀어 시뮬레이션 좌표로 (확대 상태에서도 정확히 따라옴)
    nodeSel.call(d3.drag()
      .on('start', (ev, d) => { if (!ev.active) this._miniSim.alphaTarget(0.3).restart(); d.fx=d.x; d.fy=d.y; })
      .on('drag',  (ev, d) => { const [px, py] = miniTransform.invert(d3.pointer(ev, svgEl)); d.fx=px; d.fy=py; })
      .on('end',   (ev, d) => { if (!ev.active) this._miniSim.alphaTarget(0); d.fx=null; d.fy=null; }));

    this._miniSim = d3.forceSimulation(nodes)
      .force('link', d3.forceLink(validLinks).id(d => d.id)
        .distance(d => (nodeById[typeof d.source==='object'?d.source.id:d.source]?.type==='category') ? 55 : 38).strength(1))
      .force('charge', d3.forceManyBody().strength(d => d.type==='category' ? -120 - d.r*6 : -60))
      .force('center', d3.forceCenter(w/2, h/2).strength(0.3))
      .force('collision', d3.forceCollide(d => d.r + 6))
      .alphaDecay(0.025)
      .on('tick', () => {
        // ★ 버그1 해결: 노드를 화면 안에 가둘 때 d.x/d.y 값 자체를 보정해야
        //    링크(선)와 노드(상자)가 같은 좌표를 써서 선이 상자에 정확히 붙는다.
        nodes.forEach(d => {
          const nx = Math.max(d.r+2, Math.min(w - d.r-2, d.x ?? w/2));
          const ny = Math.max(d.r+2, Math.min(h - d.r-2, d.y ?? h/2));
          if (nx !== d.x) { d.x = nx; d.vx = 0; } // 벽에 닿으면 속도 0 → 떨림 방지
          if (ny !== d.y) { d.y = ny; d.vy = 0; }
        });
        linkSel.attr('x1', d=>d.source.x).attr('y1', d=>d.source.y).attr('x2', d=>d.target.x).attr('y2', d=>d.target.y);
        nodeSel.attr('transform', d => `translate(${d.x},${d.y})`);
      });
  },
};

export default Graph;
```

**실전 교훈 (실제로 이 블로그에서 고친 버그)**

1. **선과 상자가 어긋남** — 노드를 화면 밖으로 못 나가게 "가둘" 때, 노드 위치만 보정하고 링크는 원본 좌표를 쓰면 선이 상자에 안 붙습니다. 그래서 tick에서 **`d.x`/`d.y` 값 자체를 보정**해, 노드와 링크가 **같은 좌표**를 쓰게 했습니다. 벽에 닿으면 그 축 속도(`vx`/`vy`)를 0으로 눌러 떨림도 없앴어요.
2. **줌 상태에서 드래그가 어긋남** — 확대/이동한 뒤 노드를 끌면 손과 노드가 따로 놉니다. 그래서 드래그 시 포인터 좌표를 **현재 줌 변환의 역(`miniTransform.invert(...)`)** 으로 풀어 시뮬레이션 좌표계에 맞췄습니다.

**중요**: SVG 도형의 색은 `.attr('fill', ...)`이 아니라 **`.style('fill', 'var(--accent)')`** 로 줘야 CSS 변수가 먹습니다. 그래야 다크 모드·색상 테마가 그래프에도 반영돼요.

## 정리

- 그래프는 **노드/링크 데이터 → D3 렌더 → force simulation 배치**의 3단계.
- 카테고리 계층은 13편 트리와 같은 원리로 만들고, 크기를 깊이·글수로 조절한다.
- `forceLink`·`forceManyBody`·`forceCollide`·`forceX/Y`의 균형으로 자연스럽게 퍼진다.
- `tick`마다 좌표 갱신, `d3.drag`/`d3.zoom`으로 상호작용. **SVG 색은 `.style`로.**
- 미니 그래프의 교훈: **노드·링크 좌표 일치**, **줌 역변환 드래그.**
