# D3 연결 그래프

이 블로그에서 가장 눈에 띄는 기능, **연결 그래프**입니다. 글과 카테고리가 점으로, 그 관계가 선으로 이어져 마치 별자리처럼 보이죠. **D3.js**라는 시각화 라이브러리의 **force simulation(물리 시뮬레이션)**으로 만듭니다. graph.js는 650줄이라 여기선 **핵심 개념과 코드 조각**을 다루고, 전체는 저장소를 참고하세요.

## D3와 force simulation이 뭔가요

- **D3.js** — 데이터를 SVG 도형(원, 선 등)으로 그리는 강력한 시각화 라이브러리. CDN으로 불러옵니다.
- **force simulation** — 노드(점)들에 **가상의 물리 힘**을 걸어 스스로 자리를 잡게 하는 기능입니다. 마치 자석처럼 노드끼리 밀어내고(서로 안 겹치게), 선으로 이어진 노드는 서로 당깁니다. 그 결과 손대지 않아도 보기 좋게 퍼집니다.

D3는 CDN에서 필요할 때 동적으로 불러옵니다.

```javascript
function loadD3() {
  if (window.d3) return Promise.resolve();
  return new Promise((resolve, reject) => {
    const s = document.createElement('script');
    s.src = 'https://cdn.jsdelivr.net/npm/d3@7/dist/d3.min.js';
    s.onload = resolve; s.onerror = () => reject(new Error('D3 로드 실패'));
    document.head.appendChild(s);
  });
}
```

## 1단계 — 노드와 링크 데이터 만들기

그래프는 **노드(nodes) 배열**과 **링크(links) 배열**로 표현합니다.

- 노드: 점 하나. `{ id, type: 'post'|'category', label, r(반지름) }`
- 링크: 두 노드를 잇는 선. `{ source: 노드id, target: 노드id }`

posts.json에서 이렇게 만듭니다(핵심만).

```javascript
const nodes = [];
const links = [];

// 카테고리 노드 + 부모→자식 링크 (13편 트리와 같은 원리)
const catSet = new Set();
posts.forEach(p => {
  p.category?.split('/').reduce((acc, part) => {
    const full = acc ? `${acc}/${part}` : part;
    catSet.add(full);
    return full;
  }, '');
});
catSet.forEach(cat => {
  nodes.push({ id: `cat:${cat}`, type: 'category', label: cat.split('/').pop(), r: 10 });
  const parts = cat.split('/');
  if (parts.length > 1) {
    links.push({ source: `cat:${parts.slice(0,-1).join('/')}`, target: `cat:${cat}` });
  }
});

// 글 노드 + 글→카테고리 링크
posts.forEach(p => {
  nodes.push({ id: `post:${p.file}`, type: 'post', label: p.title, r: 7 });
  if (p.category) links.push({ source: `cat:${p.category}`, target: `post:${p.file}` });
});
```

카테고리끼리는 부모→자식으로 잇고(개발 → 개발/C++), 글은 자기 카테고리에 잇습니다(개발/C++ → step01). 그러면 자연스럽게 나무 모양 별자리가 됩니다.

## 2단계 — SVG에 그리기

D3로 SVG 안에 선(`line`)과 노드 그룹(`g`)을 만듭니다.

```javascript
const svg = d3.select('#graphSvg');
const g = svg.append('g'); // 줌/이동을 적용할 그룹

// 링크(선)
const linkSel = g.append('g').selectAll('line')
  .data(links).join('line')
  .style('stroke', 'var(--border)');

// 노드(그룹: 원/사각형 + 라벨)
const nodeSel = g.append('g').selectAll('g')
  .data(nodes).join('g');

nodeSel.filter(d => d.type === 'post')
  .append('circle').attr('r', d => d.r).style('fill', 'var(--accent)');

nodeSel.append('text').text(d => d.label).attr('font-size', '7px');
```

`.data(...).join(...)`는 D3의 핵심 패턴입니다. "데이터 배열의 각 항목마다 도형 하나씩 만들어라"는 뜻이에요. 데이터가 10개면 선/노드가 10개 생깁니다.

## 3단계 — force simulation 돌리기

이제 물리 힘을 겁니다.

```javascript
const sim = d3.forceSimulation(nodes)
  // 링크로 이어진 노드는 서로 당김 (거리 유지)
  .force('link', d3.forceLink(links).id(d => d.id).distance(50))
  // 모든 노드는 서로 밀어냄 (안 겹치게)
  .force('charge', d3.forceManyBody().strength(-120))
  // 화면 중앙으로 모으는 힘
  .force('center', d3.forceCenter(width/2, height/2))
  // 매 프레임(tick)마다 위치 갱신
  .on('tick', () => {
    linkSel
      .attr('x1', d => d.source.x).attr('y1', d => d.source.y)
      .attr('x2', d => d.target.x).attr('y2', d => d.target.y);
    nodeSel.attr('transform', d => `translate(${d.x},${d.y})`);
  });
```

- `forceLink` — 링크로 이어진 노드끼리 일정 거리를 유지하게 당깁니다.
- `forceManyBody().strength(-120)` — 음수는 **밀어내는 힘**. 노드들이 서로 안 겹치고 퍼집니다.
- `forceCenter` — 전체를 화면 가운데로 모읍니다.
- **`tick`** — 시뮬레이션이 한 걸음 진행될 때마다 발생. 이때 각 노드의 새 좌표(`d.x`, `d.y`)를 SVG에 반영합니다. 선은 양 끝점을, 노드는 위치를 옮겨요. 이게 초당 수십 번 일어나며 부드럽게 움직입니다.

## 4단계 — 드래그 & 줌

노드를 마우스로 끌고, 휠로 확대/축소할 수 있게 합니다.

```javascript
// 드래그
nodeSel.call(d3.drag()
  .on('start', (ev, d) => { if (!ev.active) sim.alphaTarget(0.3).restart(); d.fx = d.x; d.fy = d.y; })
  .on('drag',  (ev, d) => { d.fx = ev.x; d.fy = ev.y; })
  .on('end',   (ev, d) => { if (!ev.active) sim.alphaTarget(0); d.fx = null; d.fy = null; }));

// 줌/이동
let transform = d3.zoomIdentity;
svg.call(d3.zoom().scaleExtent([0.4, 4])
  .on('zoom', ev => { transform = ev.transform; g.attr('transform', ev.transform); }));
```

- 드래그: `d.fx`/`d.fy`(고정 좌표)를 마우스 위치로 두면 그 노드가 손을 따라옵니다. 놓으면(`end`) 고정을 풀어 다시 물리 힘에 맡깁니다. `alphaTarget`은 "시뮬레이션을 다시 데워(움직이게) 달라"는 뜻이에요.
- 줌: `g` 그룹에 변환을 적용해 전체를 확대/이동합니다.

> 실전 팁(이 블로그에서 실제 겪은 것): 작은 미니 그래프에서 노드를 화면 안에 가둘 때, **선(링크)과 노드가 같은 좌표를 쓰도록** 좌표 보정을 노드 자체(`d.x`/`d.y`)에 해야 선이 상자에 정확히 붙습니다. 또 줌 상태에서 드래그가 어긋나면, 포인터 좌표를 `transform.invert(...)`로 되돌려 시뮬레이션 좌표계에 맞춰야 합니다.

## SVG 색과 CSS 변수

한 가지 주의: SVG 도형에 색을 CSS 변수로 줄 땐 `.attr('fill', ...)`이 아니라 **`.style('fill', 'var(--accent)')`**를 써야 변수가 적용됩니다. 그래야 다크 모드나 색상 테마가 그래프에도 반영돼요.

## 정리

- **D3 force simulation**은 노드에 물리 힘(당기기·밀어내기·중앙 모으기)을 걸어 스스로 배치하게 한다.
- 데이터를 **노드 배열 + 링크 배열**로 만들고(카테고리 계층 + 글↔카테고리), `.data().join()`으로 SVG 도형을 생성한다.
- `tick`마다 좌표를 갱신하고, `d3.drag`/`d3.zoom`으로 상호작용을 붙인다.
- SVG 색은 `.style('fill', 'var(--...)')`로 줘야 테마 변수가 먹는다.
