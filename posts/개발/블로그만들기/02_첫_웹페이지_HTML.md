# 첫 웹페이지 만들기

이번 편에서 만드는 것: **브라우저에 내 글자가 뜨는 페이지 하나.** 작지만 여기서부터 전부 시작됩니다.

## HTML이 뭔가요

**HTML**은 "이 자리에는 제목, 저기에는 문단" 하고 **웹페이지의 뼈대(구조)**를 적는 언어입니다. 집으로 치면 벽·문·창문의 위치를 정하는 설계도예요. (색·꾸밈은 다음 편 CSS가 담당합니다.)

HTML은 **태그(tag)**로 이루어집니다. 태그는 꺾쇠 `< >`로 감싼 표시예요.

```html
<h1>큰 제목</h1>
```

- `<h1>` : 시작 태그 (여기서부터 큰 제목)
- `큰 제목` : 내용
- `</h1>` : 끝 태그 (`/`가 붙으면 끝이라는 뜻)

이렇게 시작~끝으로 내용을 감싼 한 덩어리를 **요소(element)**라고 부릅니다. `<h1>`은 heading 1(제목 1)의 약자고, `<p>`는 paragraph(문단)입니다.

## index.html 만들기

웹사이트의 첫 화면 파일은 관례적으로 **`index.html`**이라고 짓습니다. 브라우저가 "폴더에 들어오면 index.html부터 보여줘" 하고 약속돼 있거든요.

1. VS Code 왼쪽 `Blog` 폴더에 마우스를 올리면 나오는 **새 파일** 아이콘 클릭
2. 이름을 `index.html`로 입력
3. 열린 빈 파일에 아래를 그대로 씁니다

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <title>내 블로그</title>
</head>
<body>
  <h1>안녕, 블로그</h1>
  <p>이건 내가 만든 첫 웹페이지야.</p>
</body>
</html>
```

Ctrl+S(맥은 Cmd+S)로 저장하세요.

## 한 줄씩 뜯어보기

- `<!DOCTYPE html>` : "이 문서는 최신 HTML이야"라는 신호. 맨 위에 딱 한 번.
- `<html lang="ko">` : 문서 전체를 감싸는 가장 바깥 요소. `lang="ko"`는 한국어라는 표시(검색·번역에 도움).
- `<head>` : **화면에 안 보이는** 정보(제목, 문자 인코딩, 나중엔 CSS 연결 등)를 넣는 곳.
  - `<meta charset="UTF-8" />` : 한글이 깨지지 않게 하는 문자 설정. 없으면 `안녕`이 `ì•ˆë…•`처럼 깨질 수 있어요. 끝이 `/>`인 건 내용이 없는 태그라 혼자 닫는 형식입니다.
  - `<title>내 블로그</title>` : **브라우저 탭에 뜨는 이름**.
- `<body>` : **실제 화면에 보이는** 내용이 들어가는 곳.
  - `<h1>` 큰 제목, `<p>` 문단.

정리하면 문서는 항상 **head(안 보이는 설정) + body(보이는 내용)** 두 덩어리로 나뉩니다.

## 브라우저에서 열어보기

가장 쉬운 방법: 탐색기에서 `index.html` 파일을 **더블클릭**하면 기본 브라우저로 열립니다. 주소창에 `file:///D:/Blog/index.html` 같은 게 뜨고, 화면에 **"안녕, 블로그"**가 큼직하게 보이면 성공입니다. 🎉

> 나중에 자바스크립트가 파일을 불러오기 시작하면 더블클릭(`file://`) 방식은 막히는 게 생깁니다. 그때는 간단한 로컬 서버로 여는 법을 따로 알려드릴게요. 지금은 더블클릭으로 충분합니다.

## 조금 더 놀아보기

내용을 바꿔보며 감을 익혀보세요. `<body>` 안에 이렇게 추가해봅니다.

```html
<h2>오늘 배운 것</h2>
<ul>
  <li>HTML은 뼈대를 만든다</li>
  <li>태그는 시작과 끝으로 내용을 감싼다</li>
  <li>head는 설정, body는 보이는 내용</li>
</ul>
```

- `<h2>` : `<h1>`보다 한 단계 작은 제목
- `<ul>` : 순서 없는 목록(unordered list), 점(•) 목록
- `<li>` : 목록 항목(list item) 하나

저장하고 브라우저를 새로고침(F5)하면 목록이 나타납니다. **"저장 → 새로고침"**이 앞으로 계속 반복할 리듬입니다.

## 자주 나는 실수

- **한글이 깨진다** → `<meta charset="UTF-8" />`가 `<head>` 안에 있는지 확인.
- **바꿨는데 화면이 그대로다** → 저장(Ctrl+S)을 안 했거나, 브라우저 새로고침(F5)을 안 한 경우.
- **태그를 안 닫았다** → `<p>`만 쓰고 `</p>`를 빠뜨리면 화면이 이상해집니다. 시작이 있으면 끝도 있어야 합니다(혼자 닫는 `<meta ... />` 류는 예외).

이제 뼈대는 섰습니다. 다음 편에서는 **CSS로 색과 여백을 입혀** 밋밋한 이 페이지를 블로그답게 꾸며봅니다.
