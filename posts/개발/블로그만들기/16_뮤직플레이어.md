# 뮤직 플레이어 (전체 코드 해설)

10편에서 "SPA를 쓰는 진짜 이유는 음악이 안 끊기게 하기 위해서"라고 했죠. 이번 편에서 그 뮤직 플레이어의 **전체 코드**를 구간별로 나눠 해설합니다. 파일이 길지만, 각 구간은 단순한 일을 합니다.

## 큰 그림

`music-player.js`는 이런 구조입니다.

- **상태** — 지금 어떤 곡을 어떻게 재생 중인지 (플레이리스트, 현재 인덱스, 재생 여부 등)
- **init** — 곡 목록 로드 → 화면(하단 바) 생성 → 이벤트 연결 → 이전 상태 복원
- **[1]~[6]** — DOM 생성 / 이벤트 / 재생 제어 / 셔플·반복 / UI 갱신 / 저장·복원

하나씩 봅니다.

## 상태와 init

```javascript
import Storage from '../core/storage.js';

// localStorage 키
const SK = {
  INDEX:   'mp_index',   TIME:    'mp_time',   VOLUME:  'mp_volume',
  SHUFFLE: 'mp_shuffle',  REPEAT:  'mp_repeat',
};

const MusicPlayer = {
  audio:        null,    // HTMLAudioElement
  playlist:     [],      // 전체 곡 목록
  currentIndex: 0,
  isPlaying:    false,
  isShuffled:   false,
  repeatMode:   'none',  // 'none' | 'one' | 'all'
  shuffleOrder: [],
  el: {},                // DOM 요소 참조 모음

  async init() {
    try {
      const res = await fetch('music/playlist.json');
      if (!res.ok) throw new Error('playlist.json not found');
      this.playlist = await res.json();
    } catch {
      this.playlist = []; // 없으면 빈 목록으로
    }

    this._buildDOM();     // 하단 바 HTML 생성
    this._bindEvents();   // 버튼/슬라이더/오디오 이벤트 연결
    this._restoreState(); // 이전 상태 복원
    this._renderPlaylist();
    this._updateTrackInfo();
    this._updateControls();

    // 페이지 떠나기 전에 현재 상태 저장
    window.addEventListener('beforeunload', () => this._saveState());
  },
```

- **`SK`** — localStorage 키 이름을 한 곳에 모아, 오타를 막고 관리하기 쉽게 합니다.
- **상태 필드** — `audio`(소리 내는 객체), `playlist`(곡 목록), `currentIndex`(지금 몇 번째 곡), `isPlaying`, 셔플/반복 상태, `el`(자주 쓰는 DOM 요소들을 담아둘 통).
- **`init()`** — `App.register('music', MusicPlayer)`가 이걸 자동 호출합니다(08편). `playlist.json`을 불러오고(없으면 빈 목록), 화면을 만들고, 이벤트를 걸고, 이전 상태를 복원합니다. 마지막으로 **페이지를 떠날 때(`beforeunload`)** 현재 상태를 저장하도록 예약합니다.

- 플레이어 HTML을 통째로 만들어 **`document.body`에 붙입니다.** HTML 파일마다 따로 넣지 않고 JS가 어느 페이지에서든 동일하게 삽입해요.
- 위쪽 `playlist-panel`은 재생목록(위로 슬라이드), 아래 `player-bar`는 항상 보이는 재생 바입니다. 트랙 정보 / 재생 컨트롤+진행바 / 셔플·반복·볼륨·목록의 3구역이죠.
- **`this.el = {...}`** — 자주 쓰는 요소들을 미리 한 번에 잡아 `el`에 저장합니다. 매번 `getElementById`를 부르지 않아 코드가 짧고 빨라져요.
- **`this.audio = new Audio()`** — 화면에 안 보이는 오디오 객체. `preload = 'metadata'`는 "재생 전엔 길이 같은 정보만 미리 읽어둬"라는 뜻(전체를 미리 다운로드하지 않아 가벼움).

## [2] 이벤트 연결

```javascript
  _bindEvents() {
    const { el, audio } = this;

    el.playBtn.addEventListener('click', () => this._togglePlay());
    el.prevBtn.addEventListener('click', () => this._prev());
    el.nextBtn.addEventListener('click', () => this._next());

    // 진행바: 드래그 중엔 오디오 갱신 멈추고, 놓으면 그 위치로 이동
    let seeking = false;
    el.progress.addEventListener('mousedown',  () => { seeking = true; });
    el.progress.addEventListener('touchstart', () => { seeking = true; });
    el.progress.addEventListener('change', () => {
      audio.currentTime = parseFloat(el.progress.value);
      seeking = false;
    });
    el.progress.addEventListener('input', () => {
      this._updateSliderFill(el.progress);
      el.currentTime.textContent = formatTime(parseFloat(el.progress.value));
    });

    // 오디오가 재생되며 시간이 흐를 때 진행바 갱신
    audio.addEventListener('timeupdate', () => {
      if (!seeking && !isNaN(audio.duration)) {
        const pct = (audio.currentTime / audio.duration) * 100;
        el.progress.value = audio.currentTime;
        el.currentTime.textContent = formatTime(audio.currentTime);
        this._updateSliderFill(el.progress, pct);
      }
    });

    // 곡 정보(길이)를 다 읽으면 진행바 최대값 설정 + 복원된 재생위치 적용
    audio.addEventListener('loadedmetadata', () => {
      el.progress.max = audio.duration;
      el.duration.textContent = formatTime(audio.duration);
      const savedTime = Storage.get(SK.TIME, 0);
      if (savedTime > 0) { audio.currentTime = savedTime; Storage.remove(SK.TIME); }
    });

    // 곡이 끝나면 다음 곡 처리
    audio.addEventListener('ended', () => this._onEnded());

    // 볼륨
    el.volume.addEventListener('input', () => {
      const vol = parseInt(el.volume.value) / 100;
      audio.volume = vol;
      Storage.set(SK.VOLUME, vol);
      this._updateSliderFill(el.volume);
      el.muteBtn.textContent = vol === 0 ? '🔇' : '🔊';
    });

    // 음소거 토글
    el.muteBtn.addEventListener('click', () => {
      if (audio.volume > 0) {
        this._prevVolume = audio.volume;
        audio.volume = 0; el.volume.value = 0; el.muteBtn.textContent = '🔇';
      } else {
        const restore = this._prevVolume || 0.7;
        audio.volume = restore; el.volume.value = restore * 100; el.muteBtn.textContent = '🔊';
      }
      this._updateSliderFill(el.volume);
    });

    // 셔플
    el.shuffleBtn.addEventListener('click', () => {
      this.isShuffled = !this.isShuffled;
      if (this.isShuffled) this._buildShuffleOrder();
      el.shuffleBtn.classList.toggle('on', this.isShuffled);
      Storage.set(SK.SHUFFLE, this.isShuffled);
    });

    // 반복 (none → one → all → none)
    el.repeatBtn.addEventListener('click', () => {
      const modes = ['none', 'one', 'all'];
      this.repeatMode = modes[(modes.indexOf(this.repeatMode) + 1) % modes.length];
      Storage.set(SK.REPEAT, this.repeatMode);
      this._updateRepeatBtn();
    });

    // 재생목록 패널 열기/닫기
    el.listBtn.addEventListener('click',  () => el.panel.classList.toggle('open'));
    el.closeBtn.addEventListener('click', () => el.panel.classList.remove('open'));
  },
```

버튼과 오디오 이벤트를 전부 연결하는 구간입니다.

- **진행바(seek)** — `seeking` 플래그로 드래그 중인지 표시합니다. 드래그 중엔 오디오의 `timeupdate`가 진행바를 덮어쓰지 않게 하고(안 그러면 손과 싸움), 놓을 때(`change`) 그 지점으로 `audio.currentTime`을 옮깁니다.
- **`timeupdate`** — 재생되며 계속 발생. 진행바 위치·시간 표시·채움 색을 갱신합니다.
- **`loadedmetadata`** — 곡 길이를 알게 되는 시점. 진행바 최대값을 곡 길이로 설정하고, 페이지 복원으로 저장된 재생 위치가 있으면 그 지점부터 이어지게 합니다(한 번 쓰면 지움).
- **`ended`** — 곡이 끝나면 `_onEnded()`(아래)로 다음 동작 결정.
- **볼륨/음소거** — 볼륨을 바꾸고 저장. 음소거는 이전 볼륨을 기억했다가 해제 시 복원합니다.
- **셔플/반복** — 상태를 토글하고 저장. 반복은 none→one→all을 순환합니다.

## [3] 재생 제어

```javascript
  _togglePlay() {
    if (this.playlist.length === 0) return;
    if (this.isPlaying) { this.audio.pause(); this.isPlaying = false; }
    else {
      if (!this.audio.src || this.audio.src === window.location.href)
        this._loadTrack(this.currentIndex, false);
      this.audio.play().catch(err => console.warn('[MusicPlayer] 재생 실패:', err));
      this.isPlaying = true;
    }
    this._updatePlayBtn();
  },

  _loadTrack(index, autoPlay = true) {
    if (this.playlist.length === 0) return;
    const n = this.playlist.length;
    this.currentIndex = ((index % n) + n) % n; // 음수·초과를 목록 안으로 순환
    const track = this.playlist[this.currentIndex];
    this.audio.src = track.file || track.src || '';
    this.audio.load();
    Storage.set(SK.INDEX, this.currentIndex);
    this._updateTrackInfo();
    this._updatePlaylistHighlight();
    this._resetProgress();
    if (autoPlay) {
      this.audio.play()
        .then(() => { this.isPlaying = true; this._updatePlayBtn(); })
        .catch(err => console.warn('[MusicPlayer] 재생 실패:', err));
    }
  },

  _prev() {
    if (this.playlist.length === 0) return;
    if (this.audio.currentTime > 3) { this.audio.currentTime = 0; return; } // 3초 지났으면 처음으로
    this._loadTrack(this._getPrevIndex(), this.isPlaying);
  },

  _next() {
    if (this.playlist.length === 0) return;
    this._loadTrack(this._getNextIndex(), this.isPlaying);
  },

  _onEnded() {
    switch (this.repeatMode) {
      case 'one': // 한 곡 반복
        this.audio.currentTime = 0; this.audio.play(); break;
      case 'all': // 전체 반복: 다음 곡(마지막이면 처음)
        this._loadTrack(this._getNextIndex(), true); break;
      default: {  // 반복 없음
        const nextIdx = this._getNextIndex();
        if (nextIdx === 0 && !this.isShuffled) { // 마지막 곡 끝 → 정지
          this.isPlaying = false; this._updatePlayBtn(); this._resetProgress();
        } else this._loadTrack(nextIdx, true);
      }
    }
  },
```

- **`_togglePlay`** — 재생 중이면 멈추고, 아니면 재생. 아직 곡을 안 불러왔으면(`audio.src`가 비었으면) 먼저 로드합니다. `.catch`가 붙은 이유는 브라우저의 자동재생 차단으로 `play()`가 실패할 수 있어서예요.
- **`_loadTrack(index, autoPlay)`** — 특정 곡을 로드합니다. `((index % n) + n) % n`은 인덱스가 음수(이전 곡에서 0 밑으로)나 초과(다음 곡에서 끝 위로)여도 **목록 안으로 빙 돌게** 하는 공식입니다. 곡 정보 갱신·목록 강조·진행바 초기화를 하고, `autoPlay`면 재생합니다.
- **`_prev`** — 재생 3초 이후면 "현재 곡 처음으로", 3초 이내면 진짜 이전 곡으로. (음악 앱들의 익숙한 동작이죠.)
- **`_onEnded`** — 곡이 끝났을 때 반복 모드에 따라: `one`은 같은 곡 다시, `all`은 다음 곡(끝이면 처음), `none`은 다음 곡을 틀되 마지막 곡이었으면 정지.

## [4] 셔플 & 반복 인덱스 계산

```javascript
  // Fisher-Yates 셔플로 무작위 순서 생성 (현재 곡을 맨 앞에)
  _buildShuffleOrder() {
    const arr = Array.from({ length: this.playlist.length }, (_, i) => i);
    for (let i = arr.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [arr[i], arr[j]] = [arr[j], arr[i]]; // 두 값 맞바꾸기
    }
    const curPos = arr.indexOf(this.currentIndex);
    if (curPos !== 0) [arr[0], arr[curPos]] = [arr[curPos], arr[0]];
    this.shuffleOrder = arr;
  },

  _getNextIndex() {
    if (this.isShuffled) {
      const pos = this.shuffleOrder.indexOf(this.currentIndex);
      return this.shuffleOrder[(pos + 1) % this.shuffleOrder.length];
    }
    return (this.currentIndex + 1) % this.playlist.length;
  },

  _getPrevIndex() {
    if (this.isShuffled) {
      const pos = this.shuffleOrder.indexOf(this.currentIndex);
      return this.shuffleOrder[(pos - 1 + this.shuffleOrder.length) % this.shuffleOrder.length];
    }
    return (this.currentIndex - 1 + this.playlist.length) % this.playlist.length;
  },
```

- **`_buildShuffleOrder`** — **Fisher-Yates** 알고리즘으로 곡 순서를 무작위로 섞습니다. 뒤에서부터 임의의 앞 요소와 맞바꾸는 방식으로, 모든 순서가 고르게 나오는 표준 셔플이에요. 현재 듣던 곡은 맨 앞으로 옮겨 바로 안 바뀌게 합니다.
- **`_getNextIndex`/`_getPrevIndex`** — 셔플이 켜져 있으면 섞인 순서(`shuffleOrder`)를 따라, 아니면 원래 순서를 따라 다음/이전 인덱스를 계산합니다. 여기서도 `% 길이`로 끝에서 처음으로 순환시켜요.

## [5] UI 갱신

```javascript
  _updateTrackInfo() {
    const track = this.playlist[this.currentIndex];
    if (!track) return;
    this.el.title.textContent  = track.title  || '제목 없음';
    this.el.artist.textContent = track.artist || '';
    this.el.cover.innerHTML = track.cover
      ? `<img src="${track.cover}" alt="${track.title}" />` : '♫';
  },

  _updatePlayBtn() { this.el.playBtn.textContent = this.isPlaying ? '⏸' : '▶'; },

  _updateRepeatBtn() {
    const icons = { none: '🔁', one: '🔂', all: '🔁' };
    this.el.repeatBtn.textContent = icons[this.repeatMode];
    this.el.repeatBtn.classList.toggle('on', this.repeatMode !== 'none');
  },

  _updateControls() {
    this._updatePlayBtn();
    this._updateRepeatBtn();
    this.el.shuffleBtn.classList.toggle('on', this.isShuffled);
    const vol = this.audio.volume;
    this.el.volume.value = vol * 100;
    this._updateSliderFill(this.el.volume);
    this.el.muteBtn.textContent = vol === 0 ? '🔇' : '🔊';
  },

  _renderPlaylist() {
    const { items, count } = this.el;
    count.textContent = `(${this.playlist.length})`;
    if (this.playlist.length === 0) {
      items.innerHTML = `<li class="playlist-empty">music/playlist.json에 곡을 추가하세요.</li>`;
      return;
    }
    items.innerHTML = this.playlist.map((t, idx) => `
      <li class="playlist-item ${idx === this.currentIndex ? 'active' : ''}" data-index="${idx}">
        <span class="playlist-num">${idx + 1}</span>
        <div class="playlist-track-info">
          <div class="playlist-track-title">${t.title || '제목 없음'}</div>
          <div class="playlist-track-artist">${t.artist || ''}</div>
        </div>
      </li>`).join('');
    items.addEventListener('click', (e) => {
      const li = e.target.closest('.playlist-item');
      if (!li) return;
      this._loadTrack(parseInt(li.dataset.index), true);
      this.isPlaying = true; this._updatePlayBtn();
    });
  },

  _updatePlaylistHighlight() {
    this.el.items.querySelectorAll('.playlist-item').forEach((li, idx) => {
      li.classList.toggle('active', idx === this.currentIndex);
    });
  },

  _resetProgress() {
    this.el.progress.value = 0;
    this.el.currentTime.textContent = '0:00';
    this.el.duration.textContent = '0:00';
    this._updateSliderFill(this.el.progress, 0);
  },

  // range 슬라이더의 채워진 왼쪽 부분을 CSS 변수로 (색칠용)
  _updateSliderFill(slider, pct) {
    const value = pct ?? ((parseFloat(slider.value) / parseFloat(slider.max || 100)) * 100);
    slider.style.setProperty('--pct', `${Math.max(0, Math.min(100, value))}%`);
  },
```

화면 표시를 갱신하는 잔손질들입니다. 곡 제목/아티스트/커버 표시, 재생·반복 버튼 아이콘, 재생목록 렌더(클릭하면 그 곡 재생), 진행바 초기화, 그리고 슬라이더의 "채워진 부분" 색을 위해 `--pct` CSS 변수를 설정하는 것까지. 큰 로직은 없고, 상태를 화면에 반영하는 역할입니다.

## [6] 상태 저장 & 복원 — 핵심

```javascript
  _saveState() {
    Storage.set(SK.INDEX,   this.currentIndex);
    Storage.set(SK.TIME,    this.audio.currentTime);
    Storage.set(SK.VOLUME,  this.audio.volume);
    Storage.set(SK.SHUFFLE, this.isShuffled);
    Storage.set(SK.REPEAT,  this.repeatMode);
  },

  _restoreState() {
    this.repeatMode = Storage.get(SK.REPEAT, 'none');
    this.isShuffled = Storage.get(SK.SHUFFLE, false);
    this.audio.volume = Storage.get(SK.VOLUME, 0.7);
    if (this.playlist.length > 0) {
      const idx = Math.min(Storage.get(SK.INDEX, 0), this.playlist.length - 1);
      this._loadTrack(idx, false); // autoPlay=false → 정지 상태로 준비만
    }
    if (this.isShuffled) this._buildShuffleOrder();
  },
};

// 초 → 'M:SS'
function formatTime(sec) {
  if (isNaN(sec) || !isFinite(sec)) return '0:00';
  const m = Math.floor(sec / 60);
  const s = Math.floor(sec % 60);
  return `${m}:${s.toString().padStart(2, '0')}`;
}

export default MusicPlayer;
```

이 구간이 이 파일의 존재 이유입니다.

- **SPA 안에서는** 애초에 페이지가 안 바뀌니 Audio 객체가 그대로 살아 음악이 안 끊깁니다(10편).
- 하지만 **새로고침(F5), 주소 직접 입력, standalone post.html 진입** 등 불가피하게 페이지가 새로 로드되면 Audio가 파괴됩니다. 이때를 대비해:
  - `beforeunload`(페이지 떠나기 직전)에 `_saveState()`로 현재 곡·재생 위치·볼륨·셔플·반복을 localStorage에 저장.
  - 새 페이지 진입 시 `_restoreState()`로 그 값들을 불러와 **같은 곡, 같은 지점**부터 준비합니다.
- 단, 복원 시 `autoPlay=false`입니다. 브라우저가 **사용자 동작 없는 자동재생을 막기** 때문에, 곡만 준비해두고 재생은 사용자가 ▶를 눌러야 시작돼요.

`formatTime`은 초를 `3:07` 같은 형식으로 바꾸는 헬퍼입니다. `padStart(2, '0')`은 초를 두 자리로(예: 7 → 07) 맞춰줍니다.

## 정리

- Audio 객체 + `timeupdate`/`loadedmetadata`/`ended` 이벤트로 재생과 UI를 다룬다.
- 인덱스 순환 공식 `((i % n) + n) % n`으로 이전/다음/셔플을 안전하게 계산한다.
- **SPA라 안 끊기고**, 불가피한 페이지 재로드는 **localStorage 저장/복원**으로 이어준다.
