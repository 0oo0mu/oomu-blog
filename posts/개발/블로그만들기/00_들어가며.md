# 들어가며

이 시리즈는 **프로그래밍을 한 번도 안 해본 사람**을 기준으로 씁니다. 그대로 따라 하면 지금 보고 있는 이 블로그를 **처음부터 직접** 만들 수 있고, 만드는 과정에서 웹이 어떻게 돌아가는지도 자연스럽게 배우게 됩니다.

외울 필요 없습니다. 모르는 단어가 나와도 그 자리에서 설명하고, 필요할 때 다시 짚어줍니다. 천천히 따라오기만 하면 됩니다.

## 우리가 만들 것

완성하면 이런 블로그가 됩니다.

- 마크다운(`.md`)으로 글을 쓰면 예쁘게 보여주는 사이트
- 왼쪽에 카테고리 트리, 태그 검색, 글 목록 카드
- 다크 모드 / 색상 테마 전환
- 글 안의 코드에 색이 입혀지는 하이라이팅
- 글마다 자동으로 만들어지는 목차(TOC)
- 글·카테고리가 점으로 이어지는 연결 그래프
- 브라우저에서 바로 글을 쓰고 올리는 웹 에디터
- **서버 없이** GitHub에 무료로 배포

핵심은 **"백엔드(서버 프로그램)가 없다"**는 점입니다. 우리가 만드는 건 브라우저에서 돌아가는 파일 몇 개(HTML/CSS/JS)뿐이고, 그걸 GitHub이 공짜로 인터넷에 올려줍니다. 그래서 돈도 안 들고 구조도 단순합니다.

## 어떻게 배울까 — 쉬운 것부터

처음부터 완성본을 통째로 보면 겁먹기 쉽습니다. 그래서 이 시리즈는 **가장 단순한 "안녕 블로그" 페이지 하나**부터 시작해서, 한 편에 기능 하나씩 얹어갑니다.

각 편은 이런 흐름입니다.

1. **오늘 만들 것** — 이번 편에서 뭐가 생기는지 한 줄로
2. **개념** — 필요한 새 용어를 딱 필요한 만큼만 설명
3. **따라 하기** — 코드를 한 줄씩, 왜 그렇게 쓰는지와 함께
4. **확인** — 브라우저에서 결과 보기
5. **자주 나는 실수** — 막히면 여기부터 확인

## 준비물

거창한 건 없습니다.

- **컴퓨터** (윈도우 기준으로 설명하고, 맥은 다른 점만 따로 표시)
- **인터넷**
- **웹 브라우저** (크롬 권장)

그리고 뒤에서 설치할 프로그램 두 개(코드 편집기, Node.js)와 계정 하나(GitHub)가 전부입니다. 전부 무료입니다. 이건 다음 편(01)에서 하나씩 같이 깔 겁니다.

## 마음가짐 하나

코드를 **복사만 하지 말고, 짧게라도 "왜 이렇게 쓰는지"를 읽고 넘어가세요.** 그게 이 시리즈의 진짜 목적입니다. 처음엔 이해가 반쯤만 돼도 괜찮습니다. 만들다 보면 앞에서 흐릿했던 게 뒤에서 선명해집니다.

## 전체 로드맵

- **00. 들어가며** (이 글)
- **01. 개발 환경 준비** — 편집기·Node·Git 설치, 프로젝트 폴더, 터미널 첫걸음
- **02. 첫 웹페이지(HTML)** — "안녕 블로그"를 브라우저에 띄우기
- **03. CSS로 꾸미기** — 색·글꼴·여백, 그리고 색상 변수
- **04. 마크다운으로 글쓰기** — `.md` 글을 화면에 예쁘게 렌더링
- **05. 글 목록** — 여러 글을 카드로 나열
- **06. 빌드 스크립트** — 글 목록을 자동으로 만드는 작은 프로그램
- **07. GitHub 배포** — 내 사이트를 인터넷에 무료로 공개
- **08. SPA 라우팅** — 페이지 안 넘기고 글 열기
- **09~17.** 다크모드, 사이드바, 검색, 목차, 코드 하이라이팅, 그래프, 뮤직플레이어, 웹 에디터, 토큰·잠금·게시/수정/삭제

그럼 다음 편에서 개발 환경부터 같이 준비합시다.
