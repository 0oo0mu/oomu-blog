# 자바스크립트 기초 + 글 불러오기

지난 편에서 마크다운 문자열을 화면에 띄웠습니다. 하지만 글을 코드 안에 문자열로 박아두면 안 되겠죠. 이번 편에서는 글을 **`.md` 파일로 따로 저장**해두고, 프로그램이 그 파일을 **불러와서(fetch)** 화면에 띄웁니다. 그 전에 자바스크립트 기초를 조금 더 단단히 합니다.

## 자바스크립트 기초 5가지

딱 필요한 것만, 예제로 봅니다. VS Code에서 브라우저 개발자도구(F12)의 **Console(콘솔)** 탭을 열고, 거기에 직접 쳐보면 바로 결과가 나옵니다.

### 1) 변수 — 값에 이름 붙이기

```javascript
const name = "무";      // const: 바뀌지 않는 값
let count = 0;          // let: 나중에 바뀔 수 있는 값
count = count + 1;      // count는 이제 1
```

- `const` — 한번 정하면 안 바꾸는 값(constant). 기본적으로 이걸 씁니다.
- `let` — 나중에 값이 바뀔 수 있는 변수.
- 문장 끝의 `;`(세미콜론)은 "여기서 한 문장 끝"이라는 표시.

### 2) 함수 — 일감 묶어서 이름 붙이기

```javascript
function greet(who) {
  return "안녕, " + who;
}

greet("무");  // "안녕, 무"
```

- `function 이름(재료) { ... }` — 함수 정의. `who`는 **매개변수**(받을 재료).
- `return` — 결과를 돌려줌.
- `greet("무")` — 함수를 **호출**(실행)하며 재료를 넘김.

요즘은 **화살표 함수**라는 짧은 형태도 많이 씁니다. 앞으로 코드에서 자주 봐요.

```javascript
const greet = (who) => "안녕, " + who;
```

`=>`(화살표) 왼쪽은 재료, 오른쪽은 결과입니다. 같은 함수를 짧게 쓴 것뿐이에요.

### 3) 요소 집고 바꾸기 (DOM)

브라우저는 HTML을 **DOM**(문서를 자바스크립트가 다룰 수 있는 형태로 만든 것)으로 갖고 있습니다. 여기서 요소를 집고 바꿉니다.

```javascript
const box = document.getElementById('content'); // id로 요소 집기
box.innerHTML = "<h1>바뀐 내용</h1>";           // 내용 교체
box.textContent = "그냥 글자";                   // 태그 없이 글자만
```

### 4) 이벤트 — "무슨 일이 일어나면 실행"

```javascript
const btn = document.getElementById('myBtn');
btn.addEventListener('click', () => {
  alert("눌렀네!");
});
```

`addEventListener('click', 함수)` = "이 버튼이 **클릭되면** 이 함수를 실행해." `click` 자리에 `input`(입력), `scroll`(스크롤) 등 다양한 사건이 들어갑니다. 이 블로그 곳곳에서 이 패턴을 씁니다.

### 5) 콘솔 — 프로그램의 혼잣말

```javascript
console.log("여기까지 실행됨", count);
```

`console.log(...)`는 값을 개발자도구 콘솔에 찍어보는 도구입니다. **"왜 안 되지?" 할 때 중간중간 찍어보며 확인**하는, 초보에게 제일 중요한 무기예요.

## ES 모듈 — 파일을 나눠 만들고 조립하기

지난 편 `markdown.js` 끝에 `export default Markdown;`이 있었죠. 자바스크립트는 코드를 **여러 파일(모듈)**로 나눠 만들고, 서로 가져다 쓸 수 있습니다.

- 내보내기: `export default Markdown;` (markdown.js에서)
- 가져오기: `import Markdown from './modules/markdown.js';` (다른 파일에서)

이 방식을 쓰려면 HTML에서 스크립트를 **`type="module"`**로 불러와야 합니다.

```html
<script type="module" src="js/app.js"></script>
```

`import`의 경로에서 `./`는 "현재 파일과 같은 폴더 기준"을 뜻하고, 파일 확장자 `.js`까지 정확히 적어야 합니다.

## 글을 파일에서 불러오기 — fetch

이제 핵심입니다. 글을 `.md` 파일로 저장해두고, 프로그램이 그 파일을 읽어옵니다. 파일이나 인터넷에서 무언가를 가져오는 명령이 **`fetch`**입니다.

```javascript
const res = await fetch('posts/first.md'); // 파일 요청
const text = await res.text();             // 응답을 글자로 변환
```

여기 `await`라는 새 단어가 있죠. `fetch`는 **시간이 걸리는 일**(파일을 읽어오는 데 시간이 듦)이라, "다 되면 알려줘" 방식으로 동작합니다. `await`는 **"이게 끝날 때까지 기다렸다가 다음 줄로 가"**라는 뜻이에요. 단, `await`는 **`async`가 붙은 함수 안에서만** 쓸 수 있습니다.

```javascript
async function load() {
  const res  = await fetch('posts/first.md');
  const text = await res.text();
  console.log(text);
}
load();
```

`async function`은 "이 함수 안에는 기다릴 일이 있다"는 표시입니다. 지금은 **"fetch 앞엔 await, 그 함수엔 async"** 공식으로 외워도 됩니다.

## 직접 조립해보기

### 1) 글 파일 만들기

`Blog` 폴더에 `posts` 폴더를 만들고, 그 안에 `first.md`를 만들어 넣습니다.

```markdown
---
title: 나의 첫 글
date: 2026-07-14
tags: [블로그, 시작]
---

# 나의 첫 글

드디어 파일로 쓴 글이 화면에 떴다!

- 마크다운으로 쓰고
- 프로그램이 불러와서
- HTML로 바꿔 보여준다
```

### 2) 불러와서 렌더링하는 스크립트

`js` 폴더에 `app.js`를 만들고 아래를 넣습니다. 지난 편에 만든 `markdown.js`를 `import`해서 씁니다.

```javascript
import Markdown from './modules/markdown.js';

async function loadPost(file) {
  const res  = await fetch(`posts/${file}`);
  const raw  = await res.text();

  // Front Matter(정보)와 본문을 분리
  const { meta, content } = Markdown.parseFrontMatter(raw);

  // 제목과 본문을 화면에 넣기
  document.getElementById('title').textContent   = meta.title || '제목 없음';
  document.getElementById('content').innerHTML   = Markdown.parse(content);
}

loadPost('first.md');
```

- `import Markdown ...` — 지난 편 모듈을 가져옵니다.
- `` `posts/${file}` `` — **백틱(`)** 으로 감싼 문자열 안에서 `${변수}`를 쓰면 값이 끼워 넣어집니다(템플릿 문자열). `file`이 `'first.md'`면 `'posts/first.md'`가 됩니다.
- `parseFrontMatter(raw)`로 정보/본문을 나누고, 제목은 `textContent`로, 본문은 `parse`해서 `innerHTML`로 넣습니다.

### 3) index.html 준비

`index.html`의 `<body>`를 이렇게 바꿉니다. marked를 먼저 불러오고, 그다음 우리 `app.js`를 모듈로 불러옵니다.

```html
<body>
  <h1 id="title"></h1>
  <div id="content"></div>

  <script src="https://cdn.jsdelivr.net/npm/marked@9/marked.min.js"></script>
  <script type="module" src="js/app.js"></script>
</body>
```

## 로컬 서버 켜기 (중요!)

이제 파일을 더블클릭(`file://`)으로 열면 **fetch가 막혀 에러**가 납니다. 브라우저 보안 정책상, `file://`에서는 다른 파일을 fetch로 못 읽거든요. 그래서 **로컬 서버**로 열어야 합니다. 두 가지 방법 중 편한 걸 쓰세요.

**방법 A — VS Code Live Server (제일 쉬움)**
1. VS Code 왼쪽 확장(Extensions) 아이콘 → "Live Server" 검색 → 설치
2. `index.html`을 연 상태에서 오른쪽 아래 **"Go Live"** 클릭
3. 브라우저가 `http://127.0.0.1:5500/` 같은 주소로 자동으로 열립니다

**방법 B — 터미널에서 한 줄**
```bash
npx serve .
```
Node를 깔았으니 바로 됩니다. 터미널에 뜨는 주소(예: `http://localhost:3000`)를 브라우저에 넣으세요. (`npx`는 설치 없이 도구를 실행해주는 명령입니다. 처음 실행 시 다운로드 여부를 물으면 y.)

이제 주소가 `http://`로 시작하죠? 새로고침하면 `first.md`의 제목과 본문이 화면에 뜹니다. **파일로 쓴 글이 사이트에 렌더링된** 역사적인 순간입니다. 🎉

## 자주 나는 실수

- **`Failed to fetch` 또는 CORS 에러** → `file://`로 열었기 때문. 반드시 로컬 서버(`http://`)로 여세요.
- **`Cannot use import ... outside a module`** → `<script>`에 `type="module"`을 빠뜨림.
- **화면이 비어 있고 콘솔에 빨간 에러** → 경로 오타(`posts/first.md`), 또는 `id`가 HTML과 JS에서 다름(`title`/`content`).
- **marked 관련 에러** → marked `<script>`가 `app.js`보다 먼저 오는지 확인.
- **한글 깨짐** → `index.html`에 `<meta charset="UTF-8" />` 확인, `.md` 파일도 UTF-8로 저장(VS Code 기본).

## 정리

- 자바스크립트 기초: `const`/`let`, 함수(화살표 함수), DOM(`getElementById`/`innerHTML`), 이벤트(`addEventListener`), `console.log`.
- **ES 모듈**: `export`로 내보내고 `import`로 가져온다. HTML에선 `type="module"`.
- **fetch + async/await**로 `.md` 파일을 불러온다. ("fetch 앞엔 await, 그 함수엔 async")
- fetch는 `file://`에서 막히므로 **로컬 서버**(Live Server / `npx serve`)로 연다.
- 이제 글을 파일로 쓰면 화면에 뜬다.
