# 필터 — 글 걸러내기

지금까지는 09편에서 넣은 **임시 연결**(불러온 글을 그대로 renderer로 넘김)로 목록을 그렸습니다. 이번 편에서 그 자리에 진짜 **필터**를 넣습니다. `filter.js`는 목록의 **중심 허브**예요.

## 필터의 구조 — 방송을 모아 걸러 다시 방송

`filter.js`는 여러 방송을 **구독**해서 상태를 바꾸고, 걸러낸 결과를 **다시 방송**합니다.

- 구독: `posts:loaded`(전체 글), `filter:category`(사이드바가 카테고리 선택 — 12편), `filter:search`(검색창 입력 — 13편)
- 발행: `posts:filtered`(걸러진 글 → renderer가 그림)

이렇게 하면 renderer는 "누가 어떻게 걸렀는지" 몰라도 결과만 받아 그리면 됩니다. 카테고리·태그·검색은 **AND 조건**으로 합쳐져요("개발 카테고리 **이면서** #입문 태그 **이면서** 'javascript' 포함").

## 실제 파일 — js/modules/filter.js

`js/modules/filter.js`를 만드세요. 실제 코드입니다. (조금 길지만 하는 일은 단순합니다: 상태 저장 → 걸러내기 → 정렬 → 방송.)

```javascript
import App from '../core/app.js';

const Filter = {
  state: {
    category: 'all',
    tag:      'all',
    query:    '',
    sort:     'newest',  // 'newest' | 'oldest' | 'title'
  },
  _allPosts: [],

  init() {
    App.on('posts:loaded', ({ posts }) => {
      this._allPosts = posts;
      this._renderTagChips();
      this._bindSortBtns();
      this._applyFilter();
    });
    App.on('filter:category', ({ category }) => {
      this.state.category = category;
      this._applyFilter();
    });
    App.on('filter:search', ({ query }) => {
      this.state.query = query;
      this._applyFilter();
    });
  },

  // 태그 칩 버튼 만들기
  _renderTagChips() {
    const container = document.getElementById('tagChips');
    if (!container) return;
    const allTags = ['all', ...new Set(this._allPosts.flatMap(p => p.tags || []))];
    container.innerHTML = allTags.map(tag => `
      <button class="chip ${tag === this.state.tag ? 'active' : ''}" data-value="${tag}">
        ${tag === 'all' ? '전체' : '#' + tag}
      </button>`).join('');

    container.addEventListener('click', (e) => {
      const btn = e.target.closest('.chip');
      if (!btn) return;
      container.querySelectorAll('.chip').forEach(c => c.classList.remove('active'));
      btn.classList.add('active');
      this.state.tag = btn.dataset.value;
      this._applyFilter();
    });
  },

  // 정렬 버튼
  _bindSortBtns() {
    const bar = document.getElementById('sortBar');
    if (!bar) return;
    bar.addEventListener('click', (e) => {
      const btn = e.target.closest('.sort-btn');
      if (!btn) return;
      bar.querySelectorAll('.sort-btn').forEach(b => b.classList.remove('active'));
      btn.classList.add('active');
      this.state.sort = btn.dataset.sort;
      this._applyFilter();
    });
  },

  // 핵심: 세 조건으로 걸러내고 정렬 후 방송
  _applyFilter() {
    const { category, tag, query, sort } = this.state;

    let filtered = this._allPosts.filter(post => {
      // 카테고리 (계층 포함): '개발' 선택 시 '개발/C++'도 통과
      let catOk;
      if (category === 'all') catOk = true;
      else {
        const c = post.category || '';
        catOk = c === category || c.startsWith(category + '/');
      }
      // 태그
      const tagOk = tag === 'all' || (post.tags || []).includes(tag);
      // 검색어
      const searchOk = !query || this._matchSearch(post, query);
      return catOk && tagOk && searchOk;
    });

    // 정렬
    if (sort === 'newest') {
      filtered = [...filtered].sort((a, b) => new Date(b.date) - new Date(a.date));
    } else if (sort === 'oldest') {
      filtered = [...filtered].sort((a, b) => new Date(a.date) - new Date(b.date));
    } else if (sort === 'title') {
      filtered = [...filtered].sort((a, b) => (a.title || '').localeCompare(b.title || '', 'ko'));
    }

    App.emit('posts:filtered', { posts: filtered, query });
  },

  // 검색어 매칭: 제목+요약+카테고리+태그를 합쳐 모든 단어 포함 여부(AND)
  _matchSearch(post, query) {
    const text = [post.title, post.excerpt, post.category, ...(post.tags || [])]
      .join(' ').toLowerCase();
    const words = query.toLowerCase().split(/\s+/).filter(Boolean);
    return words.every(word => text.includes(word));
  },
};

export default Filter;
```

## 한 부분씩 해설

- **`state`** — 지금 필터 상태를 한 객체에 모아둡니다. 카테고리·태그·검색어·정렬 각각의 현재 값이에요. 어떤 방송이 오면 이 상태의 해당 값만 바꾸고 `_applyFilter()`를 다시 부릅니다. **"상태를 한곳에 모으고, 바뀌면 다시 계산"**하는 방식이라 흐름이 단순해집니다.
- **`init()`** — 세 방송을 구독합니다. `posts:loaded`가 오면 전체 글을 저장(`_allPosts`)하고 태그 칩·정렬 버튼을 준비한 뒤 첫 필터를 적용해요.
- **`_renderTagChips()`** — 모든 글의 태그를 모아(`flatMap`으로 태그 배열들을 하나로 펼치고 `new Set`으로 중복 제거) 칩 버튼을 만듭니다. 칩을 클릭하면 `state.tag`를 바꾸고 다시 필터링합니다.
- **`_applyFilter()`** — 진짜 핵심입니다.
  - `this._allPosts.filter(post => ...)` — 배열의 `filter`는 **조건이 참인 것만 남기는** 도구입니다. 각 글에 대해 카테고리·태그·검색 세 조건을 확인하고 `catOk && tagOk && searchOk`(셋 다 참)일 때만 남깁니다.
  - **카테고리 계층**: `c === category || c.startsWith(category + '/')` — '개발'을 고르면 정확히 '개발'인 글뿐 아니라 '개발/C++'처럼 **하위 카테고리**도 통과시킵니다. 이게 트리형 카테고리의 핵심이에요.
  - **정렬**: 최신순/오래된순은 날짜 비교, 제목순은 `localeCompare('ko')`로 한글 가나다순 정렬합니다. `[...filtered]`는 원본을 안 건드리려고 복사하는 표현이에요.
  - 마지막에 `App.emit('posts:filtered', { posts: filtered, query })`로 결과를 방송 → renderer가 그립니다. `query`도 같이 보내 검색어 하이라이트에 씁니다.
- **`_matchSearch()`** — 제목·요약·카테고리·태그를 한 문자열로 합쳐 소문자로 바꾸고, 검색어의 **모든 단어**가 그 안에 있는지 확인(`every`)합니다. "javascript 입문"이면 둘 다 있어야 통과하는 AND 검색이에요.

    <button class="sort-btn active" data-sort="newest">최신순</button>

## 임시 연결을 진짜 필터로 교체

`app-index.js`에서 09~10편에 넣었던 **임시 연결을 지우고**, 필터를 등록합니다.

```javascript
import Filter from './modules/filter.js';

// 삭제: App.on('posts:loaded', ({posts}) => App.emit('posts:filtered', {posts}));

App.register('renderer', Renderer);
App.register('filter',   Filter);   // ← 추가

// ... (router:post 핸들러 등은 그대로) ...

Router.init();
PostsLoader.load();
```

이제 흐름이 완성됩니다: `PostsLoader`가 `posts:loaded` 방송 → `Filter`가 받아 걸러 `posts:filtered` 방송 → `Renderer`가 그림. 태그 칩을 누르면 그 태그 글만, 정렬 버튼을 누르면 순서가 바뀝니다.

> `App.register('filter', Filter)`도 `PostsLoader.load()`보다 **먼저** 와야 첫 `posts:loaded` 방송을 놓치지 않습니다.

## 자주 나는 실수

- **태그 칩이 안 뜸** → `id="tagChips"` 요소가 있는지, 필터를 `PostsLoader.load()` 전에 등록했는지 확인.
- **목록이 두 번 그려지거나 안 그려짐** → 임시 연결을 안 지웠거나(중복), 필터 등록을 빠뜨림(누락).
- **카테고리 필터가 하위 글을 안 잡음** → `startsWith(category + '/')` 부분 확인.
- **정렬이 이상함** → 날짜 형식(`YYYY-MM-DD`)이 맞는지, 제목순은 `localeCompare(..., 'ko')`인지 확인.

## 정리

- `filter.js`는 목록의 **허브**: 여러 방송을 구독해 상태를 갱신하고, 걸러낸 결과를 `posts:filtered`로 방송한다.
- 카테고리(계층 포함)·태그·검색을 **AND**로 합치고, 최신/오래된/제목으로 정렬한다.
- 09편의 임시 연결을 필터 등록으로 교체하면 진짜 탐색 기능이 완성된다.
