# 웹 에디터

지금까지는 `.md` 파일을 VS Code로 직접 썼습니다. 이번 편에서는 **브라우저 안에서** 글을 쓰는 에디터 페이지(`editor.html` + `editor.js`)를 만듭니다. 왼쪽에 마크다운을 입력하면 오른쪽에 **실시간으로 렌더링된 미리보기**가 뜨고, 완성하면 파일로 저장할 수 있어요. editor.js는 길어서 여기선 핵심을 다룹니다.

## 화면 구성

에디터는 좌우 2단입니다.

- 왼쪽: **Front Matter 폼**(제목·날짜·카테고리·태그·요약) + **마크다운 입력창**(`<textarea>`) + 서식 버튼
- 오른쪽: **실시간 미리보기**

`editor.html`에 이런 요소들을 둡니다(요약).

```html
<input id="fmTitle" placeholder="제목" />
<input id="fmDate" type="date" />
<select id="fmCategorySelect"></select>
<input id="fmCategory" style="display:none" /> <!-- 실제 저장값 -->
<input id="fmTags" placeholder="태그 (쉼표로 구분)" />
<input id="fmExcerpt" placeholder="요약" />

<textarea id="editorTextarea"></textarea>

<div class="post-body" id="previewBody"></div>  <!-- 미리보기 -->
```

## 실시간 미리보기 — 입력이 곧바로 렌더

핵심은 "입력창이 바뀔 때마다 미리보기를 다시 그리는" 것입니다. 04편에서 만든 `Markdown.parse`를 그대로 씁니다.

```javascript
import Markdown    from './markdown.js';
import PostEnhance from './post-enhance.js';

const Editor = {
  init() {
    this._bindFormPreview();
    this._bindTextarea();
    this._bindFormatBtns();
    this._bindSaveBtn();
    // ...
    this._updatePreview();
  },

  // 폼 필드가 바뀔 때마다 미리보기 갱신
  _bindFormPreview() {
    ['fmTitle','fmDate','fmCategory','fmTags','fmExcerpt'].forEach(id => {
      document.getElementById(id)?.addEventListener('input', () => this._updatePreview());
    });
  },

  // 본문 입력 → 150ms 디바운스 후 미리보기 갱신
  _bindTextarea() {
    const ta = document.getElementById('editorTextarea');
    let timer = null;
    ta.addEventListener('input', () => {
      clearTimeout(timer);
      timer = setTimeout(() => this._updatePreview(), 150);
    });
  },

  _updatePreview() {
    const content = document.getElementById('editorTextarea').value;
    const bodyEl  = document.getElementById('previewBody');
    if (content.trim()) {
      bodyEl.innerHTML = Markdown.parse(content);  // 마크다운 → HTML
      PostEnhance.apply(bodyEl);                   // 15편의 하이라이팅·토글도 적용
    } else {
      bodyEl.innerHTML = '<p>왼쪽에 입력하면 미리보기가 표시됩니다.</p>';
    }
  },
};
```

입력할 때마다(디바운스로 150ms 뒤) `Markdown.parse`로 변환해 미리보기에 넣습니다. 실제 글과 똑같이 보이도록 15편의 `PostEnhance`(코드 색·토글)까지 적용했어요. 그래서 쓰면서 결과를 바로 확인할 수 있습니다.

## 서식 버튼 — 선택 영역에 마크다운 감싸기

**B**(굵게) 버튼을 누르면 선택한 글자를 `**...**`로 감싸는 식입니다.

```javascript
_applyFormat(format) {
  const ta = document.getElementById('editorTextarea');
  const start = ta.selectionStart, end = ta.selectionEnd;
  const sel = ta.value.slice(start, end);

  const rules = {
    bold:   ['**', '**', '굵게'],
    italic: ['*',  '*',  '기울임'],
    code:   ['`',  '`',  '코드'],
    h2:     ['## ', '',  '제목 2'],
    link:   ['[',  '](URL)', '링크'],
  };
  const [before, after, placeholder] = rules[format];
  const text = sel || placeholder;

  ta.value = ta.value.slice(0, start) + before + text + after + ta.value.slice(end);
  this._updatePreview();
}
```

`selectionStart`/`selectionEnd`로 **선택된 범위**를 알아내, 그 앞뒤에 마크다운 기호를 끼워 넣습니다. 선택한 게 없으면 "굵게" 같은 안내 텍스트를 대신 넣어요.

## 카테고리 드롭다운 — posts.json + categories.json에서

새 글의 카테고리를 직접 타이핑하면 오타가 나기 쉽죠. 그래서 **기존 카테고리를 드롭다운**으로 제공합니다. `posts.json`(글 있는 카테고리)과 `categories.json`(빈 폴더 포함)을 합쳐 채웁니다.

```javascript
async _bindCategoryDropdown() {
  const select = document.getElementById('fmCategorySelect');
  const catSet = new Set();
  try {
    (await (await fetch('posts/posts.json')).json())
      .forEach(p => { if (p.category) catSet.add(p.category); });
  } catch {}
  try {
    const c = await (await fetch('posts/categories.json')).json();
    c.forEach(x => x && catSet.add(x));
  } catch {}

  const cats = [...catSet].sort();
  select.innerHTML = [
    '<option value="">(파일 경로에서 자동)</option>',
    ...cats.map(c => `<option value="${c}">${c}</option>`),
    '<option value="__new__">+ 새 카테고리 직접 입력</option>',
  ].join('');
}
```

드롭다운에서 고른 값을 숨겨진 `#fmCategory`에 넣어 저장에 씁니다. "+ 새 카테고리"를 고르면 텍스트 입력칸이 나타나 새 카테고리를 만들 수 있어요. 13편의 사이드바 트리와 이어져, 빈 폴더 카테고리도 여기서 선택됩니다.

## 파일로 저장하기 — File System Access API

완성한 글을 `.md` 파일로 저장합니다. 최신 브라우저(크롬·엣지)의 **File System Access API**를 쓰면, 다운로드가 아니라 원하는 폴더에 직접 저장할 수 있어요. 지원 안 하는 브라우저(파이어폭스 등)는 **다운로드**로 폴백합니다.

```javascript
_buildFileContent() {
  const { title, date, category, tags, excerpt } = this._getFormValues();
  const body = document.getElementById('editorTextarea').value;
  const fm = [
    '---',
    `title: ${title}`,
    `date: ${date}`,
    category ? `category: ${category}` : null,
    `tags: [${tags}]`,
    excerpt ? `excerpt: ${excerpt}` : null,
    '---', '',
  ].filter(Boolean).join('\n');
  return fm + body;
}

async save() {
  const content = this._buildFileContent();
  const filename = this._slug() + '.md';

  if (window.showSaveFilePicker) {         // 크롬/엣지: 직접 저장
    const handle = await window.showSaveFilePicker({ suggestedName: filename });
    const w = await handle.createWritable();
    await w.write(content); await w.close();
  } else {                                  // 폴백: 다운로드
    const blob = new Blob([content], { type: 'text/markdown' });
    const a = document.createElement('a');
    a.href = URL.createObjectURL(blob); a.download = filename; a.click();
  }
}
```

`_buildFileContent`는 폼 값으로 **Front Matter**를 조립하고 본문을 붙여 완전한 `.md` 텍스트를 만듭니다(04편에서 배운 그 형식). 저장한 파일을 `posts` 폴더에 넣고 `deploy.bat`을 돌리면(07편) 사이트에 올라갑니다.

## 로컬에서만 글쓰기 버튼 보이기

이 에디터는 **나만** 써야 하죠. 그래서 `env.js`로 로컬 환경인지 판별해, 배포된 웹에선 "글쓰기" 진입을 감춥니다(또는 다음 편의 비밀번호 잠금으로 보호).

```javascript
// js/core/env.js
const Env = {
  isLocal: ['localhost', '127.0.0.1', ''].includes(window.location.hostname),
};
export default Env;
```

## 정리

- 에디터는 **왼쪽 입력 / 오른쪽 실시간 미리보기** 2단 구조. 입력이 바뀌면 `Markdown.parse`로 즉시 렌더(디바운스).
- 서식 버튼은 **선택 영역**에 마크다운 기호를 감싼다.
- 카테고리는 `posts.json`+`categories.json`에서 뽑은 **드롭다운**으로(오타 방지).
- 완성 글은 Front Matter를 조립해 **File System Access API**로 저장(미지원 시 다운로드).

다음 편(19)에서는 이 에디터에서 **GitHub에 바로 게시·수정·삭제**하고, 아무나 못 쓰게 **비밀번호로 잠그는(토큰 암호화)** 보안 기능을 만듭니다.
