# 웹 에디터 (전체 코드 해설)

브라우저에서 글을 쓰는 에디터(`editor.html` + `editor.js`)입니다. 이 편에서는 **글쓰기·미리보기·저장·수정 불러오기** 부분의 전체 코드를 봅니다. GitHub 게시·수정·삭제와 비밀번호 잠금은 다음 편(19)에서 다뤄요.

> 참고: 아래 코드 일부에 ```` ``` ````(코드 블록 기호)가 문자열로 들어갑니다. 그래서 이 글의 코드 상자는 4중 백틱으로 감쌌습니다 — 붙여넣을 땐 상자 안 내용만 쓰면 됩니다.

## init — 조립

````javascript
import Markdown    from './markdown.js';
import PostEnhance from './post-enhance.js';

const Editor = {
  _fileHandle: null, // File System Access 파일 핸들

  async init() {
    this._bindFormPreview();       // 폼 입력 → 미리보기
    await this._bindCategoryDropdown(); // 카테고리 드롭다운
    this._bindTextarea();          // 본문 입력 → 미리보기
    this._bindFormatBtns();        // 서식 버튼
    this._bindSaveBtn();           // 로컬 저장
    this._bindPublishBtn();        // GitHub 게시 (19편)
    this._bindDeleteBtn();         // GitHub 삭제 (19편)
    this._bindNewBtn();            // 새 글
    this._bindGitHubSettings();    // GitHub 설정 패널 (19편)
    this._setDefaultDate();        // 날짜 기본값 오늘
    this._updatePreview();
    this._applyGitHubSettingsToUI();
    await this._loadEditParam();   // ?edit= 있으면 기존 글 불러오기
  },
````

`init()`이 모든 기능을 연결합니다. `async`인 이유는 카테고리 드롭다운과 수정-불러오기가 fetch(비동기)를 쓰기 때문이에요.

## Front Matter 폼 → 미리보기 연결

````javascript
  _bindFormPreview() {
    ['fmTitle', 'fmDate', 'fmCategory', 'fmTags', 'fmExcerpt'].forEach(id => {
      document.getElementById(id)?.addEventListener('input', () => this._updatePreview());
    });
  },

  _getFormValues() {
    return {
      title:    document.getElementById('fmTitle')?.value.trim()    || '',
      date:     document.getElementById('fmDate')?.value.trim()     || '',
      category: document.getElementById('fmCategory')?.value.trim() || '',
      tags:     document.getElementById('fmTags')?.value.trim()     || '',
      excerpt:  document.getElementById('fmExcerpt')?.value.trim()  || '',
    };
  },

  _setDefaultDate() {
    const dateEl = document.getElementById('fmDate');
    if (dateEl && !dateEl.value) dateEl.value = new Date().toISOString().slice(0, 10);
  },
````

제목·날짜·카테고리·태그·요약 입력칸이 바뀔 때마다 미리보기를 갱신하고, `_getFormValues`로 현재 폼 값을 한 객체로 모읍니다. 날짜는 기본값을 오늘로 채워요(`toISOString().slice(0,10)` → `2026-07-14`).

## 카테고리 드롭다운 — posts.json + categories.json

````javascript
  async _bindCategoryDropdown() {
    const select   = document.getElementById('fmCategorySelect');
    const textInput = document.getElementById('fmCategory');
    if (!select || !textInput) return;
    const NEW = '__new__';

    // 드롭다운 변경 → 실제 저장값(#fmCategory) 세팅
    select.addEventListener('change', () => {
      if (select.value === NEW) {           // "직접 입력" 선택
        textInput.style.display = '';
        textInput.value = '';
        textInput.focus();
      } else {                               // 기존 카테고리 or "자동"
        textInput.style.display = 'none';
        textInput.value = select.value;
      }
      this._updatePreview();
    });

    // 목록 = posts.json(글 있는 카테고리) + categories.json(빈 폴더 포함)
    const catSet = new Set();
    try {
      (await (await fetch('posts/posts.json', { cache: 'no-store' })).json())
        .forEach(p => { if (p.category) catSet.add(p.category); });
    } catch (e) { console.warn('[Editor] posts.json 로드 실패:', e.message); }
    try {
      const c = await (await fetch('posts/categories.json', { cache: 'no-store' })).json();
      c.forEach(x => { if (x) catSet.add(x); });
    } catch (_) {}
    const categories = [...catSet].sort();

    select.innerHTML = [
      `<option value="">(파일 경로에서 자동)</option>`,
      ...categories.map(c => `<option value="${c}">${c}</option>`),
      `<option value="${NEW}">+ 새 카테고리 직접 입력</option>`,
    ].join('');
    textInput.style.display = 'none';
  },
````

카테고리를 직접 타이핑하면 오타가 나기 쉬우니 **드롭다운**으로 제공합니다. 글이 있는 카테고리(`posts.json`)와 글이 없는 빈 폴더(`categories.json`)를 **합쳐서** 채워, 13편 사이드바에 보이던 빈 카테고리도 여기서 고를 수 있어요. 화면엔 보이는 `<select>`가 있고, 실제 저장에 쓰는 값은 숨겨진 `#fmCategory`에 넣습니다. "+ 새 카테고리"를 고르면 텍스트칸이 나타나 새로 입력할 수 있습니다.

## 실시간 미리보기

````javascript
  _bindTextarea() {
    const ta = document.getElementById('editorTextarea');
    if (!ta) return;
    let timer = null;
    ta.addEventListener('input', () => {
      clearTimeout(timer);
      timer = setTimeout(() => this._updatePreview(), 150); // 150ms 디바운스
    });
  },

  _updatePreview() {
    const meta    = this._getFormValues();
    const content = document.getElementById('editorTextarea')?.value || '';

    // 미리보기 헤더 (제목/날짜/카테고리/태그)
    const headerEl = document.getElementById('previewHeader');
    if (headerEl) {
      const tagsHtml = meta.tags
        ? meta.tags.split(',').map(t => `<span class="post-tag">#${t.trim()}</span>`).join('') : '';
      headerEl.innerHTML = `
        ${meta.category ? `<span class="post-category">${meta.category}</span>` : ''}
        <h1>${meta.title || '제목을 입력하세요'}</h1>
        <div class="post-card-meta"><span class="post-date">${meta.date ? formatDate(meta.date) : ''}</span>
        <div class="post-tags">${tagsHtml}</div></div>`;
    }

    // 미리보기 본문
    const bodyEl = document.getElementById('previewBody');
    if (bodyEl) {
      if (content.trim()) {
        bodyEl.innerHTML = Markdown.parse(content); // 04편 마크다운 파서
        PostEnhance.apply(bodyEl);                  // 15편 하이라이팅·토글도 적용
      } else {
        bodyEl.innerHTML = `<div class="preview-empty"><div class="icon">✏️</div>
          <p>왼쪽에서 마크다운을 입력하면<br>여기에 미리보기가 표시됩니다.</p></div>`;
      }
    }
  },
````

본문 입력은 150ms **디바운스**(14편) 후 미리보기를 갱신합니다. 핵심은 `Markdown.parse(content)`로 마크다운을 HTML로 바꾸고, 실제 글과 똑같이 보이도록 15편의 `PostEnhance.apply`(코드 하이라이팅·헤더 토글)까지 적용하는 것. 그래서 쓰면서 최종 모습을 그대로 확인할 수 있습니다.

## 서식 버튼 — 선택 영역 감싸기

````javascript
  _bindFormatBtns() {
    const bar = document.getElementById('formatBar');
    if (!bar) return;
    bar.addEventListener('click', (e) => {
      const btn = e.target.closest('.fmt-btn');
      if (btn) this._applyFormat(btn.dataset.format);
    });
  },

  _applyFormat(format) {
    const ta    = document.getElementById('editorTextarea');
    const start = ta.selectionStart, end = ta.selectionEnd;
    const sel   = ta.value.slice(start, end); // 선택된 텍스트

    // [앞에 붙일 것, 뒤에 붙일 것, 기본 텍스트]
    const rules = {
      bold:      ['**', '**', '굵게'],
      italic:    ['*',  '*',  '기울임'],
      strike:    ['~~', '~~', '취소선'],
      code:      ['`',  '`',  '코드'],
      codeblock: ['```\n', '\n```', '코드 블록'],
      link:      ['[',  '](URL)', '링크 텍스트'],
      image:     ['![', '](URL)', '이미지 설명'],
      h2:        ['## ', '', '제목 2'],
      h3:        ['### ', '', '제목 3'],
      quote:     ['> ', '', '인용문'],
      ul:        ['- ', '', '목록 항목'],
      ol:        ['1. ', '', '목록 항목'],
    };
    const rule = rules[format];
    if (!rule) return;
    const [before, after, placeholder] = rule;
    const text = sel || placeholder; // 선택 없으면 기본 텍스트

    ta.value = ta.value.slice(0, start) + before + text + after + ta.value.slice(end);
    const newPos = start + before.length + text.length + after.length;
    ta.setSelectionRange(newPos, newPos);
    ta.focus();
    this._updatePreview();
  },
````

**B**(굵게)를 누르면 선택한 글자를 `**...**`로 감쌉니다. `selectionStart`/`selectionEnd`로 선택 범위를 알아내, 규칙표(`rules`)의 앞뒤 기호를 끼워 넣어요. 선택한 게 없으면 "굵게" 같은 안내 텍스트를 대신 넣습니다. 삽입 후 커서 위치를 조정하고 미리보기를 갱신합니다.

## 수정 글 불러오기 — ?edit=경로

````javascript
  async _loadEditParam() {
    const params = new URLSearchParams(location.search);
    const file = params.get('edit') || params.get('file');
    if (!file) return; // 새 글 작성이면 아무 것도 안 함

    try {
      const res = await fetch('posts/' + file, { cache: 'no-store' });
      if (!res.ok) throw new Error('HTTP ' + res.status);
      const { meta, content } = Markdown.parseFrontMatter(await res.text());

      const set = (id, v) => { const el = document.getElementById(id); if (el) el.value = v; };
      set('fmTitle',        meta.title   || '');
      set('fmDate',         meta.date    || '');
      set('fmTags',         (meta.tags   || []).join(', '));
      set('fmExcerpt',      meta.excerpt || '');
      set('editorTextarea', content.replace(/^\n+/, ''));
      set('filenameInput',  file); // 같은 파일 경로 → 게시 시 덮어쓰기

      // 카테고리 반영
      const catSel = document.getElementById('fmCategorySelect');
      const catInput = document.getElementById('fmCategory');
      if (catInput) catInput.value = meta.category || '';
      if (catSel) {
        catSel.value = meta.category || '';
        if (catSel.value !== (meta.category || '')) { // 목록에 없는 카테고리면 직접입력으로
          if ([...catSel.options].some(o => o.value === '__new__')) catSel.value = '__new__';
          if (catInput) catInput.style.display = '';
        } else if (catInput) catInput.style.display = 'none';
      }

      const pub = document.getElementById('publishBtn');
      if (pub) pub.innerHTML = '🚀 수정 게시';
      const del = document.getElementById('deleteBtn');
      if (del) del.style.display = ''; // 수정 모드에서만 삭제 버튼 표시

      this._updatePreview();
      showToast('✏️ 기존 글 불러옴: ' + file);
    } catch (e) {
      console.error('[Editor] 수정 불러오기 실패:', e);
      showToast('불러오기 실패: ' + e.message);
    }
  },
````

글 화면의 "✏️ 수정" 버튼은 `editor.html?edit=글경로`로 이 에디터를 엽니다. 그러면 이 함수가 그 글을 `fetch`해 `parseFrontMatter`로 나누고(04편), 폼과 본문을 **원래 내용으로 채웁니다.** 파일 경로칸(`filenameInput`)에 원래 경로를 넣어 두면, 게시할 때 **같은 파일을 덮어써서** 수정이 됩니다(19편). 삭제 버튼도 이때만 보이게 하고요.

## 파일로 저장 — File System Access / 다운로드

````javascript
  _buildFileContent() {
    const { title, date, category, tags, excerpt } = this._getFormValues();
    const body = document.getElementById('editorTextarea')?.value || '';
    const fm = [
      '---',
      `title: ${title}`,
      `date: ${date}`,
      category ? `category: ${category}` : null,
      `tags: [${tags}]`,
      excerpt ? `excerpt: ${excerpt}` : null,
      '---', '',
    ].filter(Boolean).join('\n');
    return fm + body;
  },

  _bindSaveBtn() {
    document.getElementById('saveBtn')?.addEventListener('click', () => this.save());
  },

  async save() {
    const content  = this._buildFileContent();
    const filename = this._getSuggestedFilename();
    this._downloadFile(content, filename); // (아래) 항상 다운로드로 저장
  },

  _getSuggestedFilename() {
    const manual = document.getElementById('filenameInput')?.value.trim();
    if (manual) return manual.endsWith('.md') ? manual : manual + '.md';
    const title = document.getElementById('fmTitle')?.value.trim() || '새-글';
    return title.toLowerCase().replace(/[^\w\s가-힣]/g, '').replace(/\s+/g, '-').slice(0, 50) + '.md';
  },

  _downloadFile(content, filename) {
    const blob = new Blob([content], { type: 'text/markdown;charset=utf-8' });
    const url  = URL.createObjectURL(blob);
    const a    = document.createElement('a');
    a.href = url; a.download = filename; a.click();
    URL.revokeObjectURL(url);
    showToast('💾 다운로드됨: ' + filename + ' → posts 폴더로 옮기세요');
  },
````

- **`_buildFileContent`** — 폼 값으로 **Front Matter**를 조립하고 본문을 붙여 완전한 `.md` 텍스트를 만듭니다(04편 형식). `.filter(Boolean)`은 값이 없는 줄(예: 카테고리 미입력)을 빼줍니다.
- **저장** — `Blob`(파일 데이터 덩어리)을 만들어 다운로드 링크를 클릭시키는 방식으로 `.md` 파일을 내려받습니다. 저장한 파일을 `posts` 폴더에 넣고 배포하면 사이트에 올라갑니다(07편).

> 참고: 크롬/엣지는 File System Access API(`window.showSaveFilePicker`)로 다운로드 대신 원하는 폴더에 **직접 저장**할 수도 있습니다. 이 블로그는 브라우저 상관없이 다운로드로 통일했지만, 원하면 `showSaveFilePicker` 분기를 넣으면 됩니다(부록의 실제 코드 참고).

## HTML 구조 (요약)

`editor.html`은 좌우 2단입니다. 실제 전체는 부록 A에 있습니다.

````html
<input id="fmTitle" /> <input id="fmDate" type="date" />
<select id="fmCategorySelect"></select>
<input id="fmCategory" style="display:none" />
<input id="fmTags" /> <input id="fmExcerpt" />
<input id="filenameInput" />           <!-- 파일 경로 (선택) -->

````

`app-editor.js`는 `Theme.init(); Accent.init(); Editor.init();`만 부르는 짧은 진입점입니다(19편에서 잠금도 추가).

## 정리

- 폼·본문 입력이 바뀌면 **디바운스** 후 `Markdown.parse` + `PostEnhance`로 실시간 미리보기.
- 카테고리는 `posts.json`+`categories.json`을 합친 **드롭다운**(오타 방지, 빈 카테고리 포함).
- 서식 버튼은 **선택 영역**에 마크다운 기호를 감싼다.
- `?edit=경로`로 열면 기존 글을 폼에 불러와 **수정**할 수 있다.
- 저장은 Front Matter를 조립해 `.md`로 **다운로드**.

다음 편(19)에서는 이 에디터에서 **GitHub에 바로 게시·수정·삭제**하고, **비밀번호로 잠그는(토큰 암호화)** 전체 코드(editor-auth.js)를 해설합니다.
