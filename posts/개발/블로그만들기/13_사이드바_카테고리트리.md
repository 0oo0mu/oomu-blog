# 사이드바 카테고리 트리

11편의 필터는 `filter:category` 방송을 기다리고 있었죠. 그 방송을 쏘는 게 바로 **사이드바**입니다. `개발/C++`처럼 슬래시로 이어진 카테고리 경로를, 접었다 펼 수 있는 **폴더 트리**로 만듭니다.

## 문제 — 평평한 문자열을 계층 트리로

글들의 카테고리는 이렇게 **평평한 문자열**입니다.

```
개발/블로그만들기
개발/C++
독후감
```

이걸 화면엔 이런 **계층 트리**로 보여주고 싶습니다.

```
📁 개발
   📁 블로그만들기
   📁 C++
📁 독후감
```

즉 `/`로 나뉜 경로를 **부모-자식 구조의 데이터**로 바꿔야 합니다. 이게 이 편의 핵심 아이디어예요.

## 트리 데이터 만들기

각 카테고리 문자열을 `/`로 쪼개, 한 조각씩 트리 안으로 파고들며 노드를 만듭니다. 노드 하나는 `{ _posts: 글수, _children: {자식들} }` 모양입니다.

```javascript
const root = { _posts: posts.length, _children: {} };

posts.forEach(post => {
  if (!post.category) return;
  const parts = post.category.split('/');   // "개발/C++" → ["개발","C++"]
  let node = root;
  parts.forEach((part, depth) => {
    if (!node._children[part]) {
      node._children[part] = { _posts: 0, _children: {} };
    }
    if (depth === parts.length - 1) node._children[part]._posts++; // 마지막 조각에 글 1개
    node = node._children[part];   // 자식으로 내려가기
  });
});
```

`["개발","C++"]`를 처리하면: root 밑에 `개발` 노드를 만들고 그 안으로 들어가서, 다시 `C++` 노드를 만들고 글 수를 1 올립니다. 다른 글도 같은 식으로 쌓이면, `개발` 밑에 `블로그만들기`, `C++`가 나란히 생겨요.

## 실제 파일 — js/modules/sidebar.js (핵심)

`js/modules/sidebar.js`를 만드세요. (이 블로그의 sidebar.js는 SPA 포스트 뷰·standalone 페이지에서 클릭하는 경우까지 처리하느라 조금 더 길지만, 아래가 **핵심 골격**입니다. 트리 만들기 → 재귀 렌더 → 클릭 시 필터 방송.)

```javascript
import App    from '../core/app.js';
import Router from '../core/router.js';

const Sidebar = {
  _allPosts: [],
  _categories: [],

  init() {
    App.on('posts:loaded', ({ posts, categories }) => {
      this._allPosts   = posts;
      this._categories = categories || [];
      this._build(posts, this._categories);
    });
  },

  _build(posts, categories = []) {
    const treeEl = document.getElementById('categoryTree');
    if (!treeEl) return;

    // ── 트리 데이터 만들기 ──
    const root = { _posts: posts.length, _children: {} };

    posts.forEach(post => {
      if (!post.category) return;
      const parts = post.category.split('/').filter(Boolean);
      let node = root;
      parts.forEach((part, depth) => {
        if (!node._children[part]) node._children[part] = { _posts: 0, _children: {} };
        if (depth === parts.length - 1) node._children[part]._posts++;
        node = node._children[part];
      });
    });

    // ── 폴더 기반 빈 카테고리도 병합 (글 없는 폴더도 표시) ──
    categories.forEach(cat => {
      const parts = cat.split('/').filter(Boolean);
      let node = root;
      parts.forEach(part => {
        if (!node._children[part]) node._children[part] = { _posts: 0, _children: {} };
        node = node._children[part];
      });
    });

    calcTotal(root); // 각 노드의 하위 포함 총 글 수 계산

    // ── DOM 렌더링 ──
    treeEl.innerHTML = '';

    // "전체" 항목
    const allLi = document.createElement('li');
    allLi.className = 'tree-node';
    allLi.innerHTML = `
      <button class="tree-item tree-item-all active" data-category="all">
        <span class="tree-name">🗂 전체</span>
        <span class="tree-count">${posts.length}</span>
      </button>`;
    allLi.querySelector('.tree-item').addEventListener('click', () => this._select('all'));
    treeEl.appendChild(allLi);

    // 루트의 자식들을 재귀 렌더
    Object.entries(root._children).forEach(([name, node]) => {
      treeEl.appendChild(this._renderNode(name, node, ''));
    });
  },

  // 노드 하나를 <li>로 (자식 있으면 재귀)
  _renderNode(name, node, parentPath) {
    const fullPath    = parentPath ? `${parentPath}/${name}` : name;
    const hasChildren = Object.keys(node._children).length > 0;

    const li = document.createElement('li');
    li.className = 'tree-node';
    li.dataset.path = fullPath;

    const btn = document.createElement('button');
    btn.className = 'tree-item';
    btn.dataset.category = fullPath;
    btn.innerHTML = `
      ${hasChildren ? `<span class="tree-arrow">▶</span>`
                    : `<span class="tree-arrow" style="opacity:0">▶</span>`}
      <span class="tree-name">📁 ${name}</span>
      <span class="tree-count">${node._total}</span>`;

    btn.addEventListener('click', () => {
      if (hasChildren) li.classList.toggle('open'); // 접기/펼치기
      this._select(fullPath);
    });
    li.appendChild(btn);

    if (hasChildren) {
      const ul = document.createElement('ul');
      ul.className = 'tree-children';
      Object.entries(node._children).forEach(([childName, childNode]) => {
        ul.appendChild(this._renderNode(childName, childNode, fullPath));
      });
      li.appendChild(ul);
    }
    return li;
  },

  // 카테고리 선택 → active 표시 + 조상 펼치기 + 필터 방송
  _select(category) {
    const treeEl = document.getElementById('categoryTree');
    if (treeEl) {
      treeEl.querySelectorAll('.tree-item').forEach(btn => {
        btn.classList.toggle('active', btn.dataset.category === category);
      });
      // 선택된 노드의 '조상'만 펼치기 (자기 자신은 클릭 토글에 맡김)
      if (category !== 'all') {
        const ancestors = category.split('/').slice(0, -1);
        let cur = '';
        ancestors.forEach(part => {
          cur = cur ? `${cur}/${part}` : part;
          const node = treeEl.querySelector(`[data-path="${cur}"]`);
          if (node) node.classList.add('open');
        });
      }
    }
    App.emit('filter:category', { category }); // ← 11편 필터가 이걸 듣는다
  },
};

// 각 노드의 하위 포함 총 글 수 계산 (재귀)
function calcTotal(node) {
  const childrenTotal = Object.values(node._children)
    .reduce((sum, child) => sum + calcTotal(child), 0);
  node._total = node._posts + childrenTotal;
  return node._total;
}

export default Sidebar;
```

## 한 부분씩 해설

- **`_build`** — `posts:loaded`가 오면 트리 데이터를 만들고 그립니다. 위에서 본 "경로 쪼개서 파고들기"로 트리를 세우고, 12편에서 배운 `categories`(빈 폴더 포함)도 합쳐 **글 없는 폴더도 카테고리로** 나오게 합니다. `calcTotal(root)`로 각 폴더의 **하위까지 합친 글 수**를 계산해요.
- **`calcTotal(node)`** — 재귀 함수입니다. 자식들의 총합을 구해 자기 글 수에 더합니다. 그래서 `개발`의 숫자에는 `개발/C++`, `개발/블로그만들기`의 글이 다 합산돼요. 06편의 `findMarkdownFiles`처럼, **트리 구조엔 재귀가 딱 맞습니다.**
- **`_renderNode(name, node, parentPath)`** — 노드 하나를 `<li>` + 버튼으로 만들고, **자식이 있으면 자기 자신을 다시 호출**해 하위 트리를 그립니다(재귀 렌더). `data-path`에 전체 경로를 넣어 나중에 특정 노드를 찾을 때 씁니다. 자식이 있는 폴더 버튼을 누르면 `li`에 `open` 클래스를 토글해 **접었다 폈다** 합니다(펼침은 CSS로 처리).
- **`_select(category)`** — 클릭된 카테고리를 active로 표시하고, 그 **조상 폴더들만** 펼친 뒤(자기 자신은 클릭 토글에 맡김 — 안 그러면 폴더가 안 닫히는 버그가 남), `App.emit('filter:category', { category })`로 방송합니다. 이 방송을 11편 필터가 듣고 걸러내죠. 계층 필터라 `개발`을 누르면 `개발/C++` 글까지 다 나옵니다.

> 실제 이 블로그의 `_select`는 여기에 더해, **standalone post.html**이나 **SPA 포스트 뷰**에서 카테고리를 눌렀을 때 목록으로 돌아가 필터를 거는 경로(약 30줄)를 더 갖고 있습니다. 원리는 같으니, 위 골격을 이해했다면 저장소의 전체 코드도 쉽게 읽힙니다.

## HTML & CSS

목록 뷰(또는 공통 레이아웃)에 트리가 들어갈 `<ul>`을 둡니다.

```html
<aside class="sidebar">
  <ul id="categoryTree" class="category-tree"></ul>
</aside>
```

접기/펼치기의 핵심 CSS(예: `css/sidebar.css`):

```css
.tree-children { display: none; list-style: none; padding-left: 1rem; }
.tree-node.open > .tree-children { display: block; }   /* open이면 자식 보임 */
.tree-arrow { display: inline-block; transition: transform 0.15s; }
.tree-node.open > .tree-item .tree-arrow { transform: rotate(90deg); } /* 펼치면 ▶ 회전 */

.tree-item {
  display: flex; align-items: center; gap: 0.4rem; width: 100%;
  background: none; border: none; color: var(--text); cursor: pointer;
  padding: 0.35rem 0.5rem; border-radius: 6px; text-align: left;
}
.tree-item.active { background: var(--accent-light); color: var(--accent); }
.tree-count { margin-left: auto; font-size: 0.75rem; color: var(--text-muted); }
```

핵심은 `.tree-children { display: none }`이 기본이고, 부모에 `open`이 붙으면(`.tree-node.open > .tree-children`) 자식이 보이는 것. 화살표는 `open`일 때 90도 회전해 ▶ → ▼처럼 보입니다.

## 자주 나는 실수

- **트리가 안 뜸** → `id="categoryTree"` 요소가 있는지, `App.register('sidebar', Sidebar)`(진입점에서)와 `PostsLoader.load()` 순서 확인.
- **폴더가 안 접힘** → `_select`에서 자기 자신까지 `open`을 강제로 붙이면 클릭 토글이 무효화됩니다. **조상만**(`slice(0, -1)`) 펼치세요.
- **하위 글 수가 부모에 안 더해짐** → `calcTotal` 재귀 확인.
- **빈 카테고리 안 보임** → `categories`(categories.json) 병합 부분과, build.js가 `.gitkeep`으로 빈 폴더를 유지하는지 확인(뒤 편에서 다룸).

## 정리

- 슬래시로 이어진 카테고리 경로를 **부모-자식 트리 데이터**로 변환한다(경로 쪼개서 파고들기).
- **재귀**로 트리를 그리고, `calcTotal`로 하위 포함 글 수를 계산한다.
- 폴더 클릭 → `open` 토글로 접기/펼치기, 카테고리 클릭 → `filter:category` 방송 → 11편 필터가 계층 필터링.
- 진입점에서 `App.register('sidebar', Sidebar)`.
