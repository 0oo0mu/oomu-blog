# 개발 환경 준비

집을 짓기 전에 연장을 챙기는 단계입니다. 세 가지를 깔고, 폴더 하나를 만들고, 터미널을 처음 열어봅니다.

## 오늘 설치할 것과 이유

- **VS Code** — 코드를 쓰는 편집기. 메모장이랑 비슷하지만 색 표시·자동완성이 있어 훨씬 편합니다.
- **Node.js** — 우리 컴퓨터에서 자바스크립트를 실행하게 해주는 도구. 나중에 "글 목록 자동 생성" 같은 작은 프로그램을 돌릴 때 씁니다.
- **Git** — 코드의 변경 기록을 저장하고, GitHub에 올릴 때 쓰는 도구.

지금 다 이해 안 돼도 됩니다. "이런 걸 깐다" 정도면 충분합니다.

## 1) VS Code 설치

1. 브라우저에서 `code.visualstudio.com` 접속
2. 큰 다운로드 버튼(Windows면 Windows용) 클릭
3. 내려받은 설치 파일 실행 → 계속 "다음" (설치 중 **"PATH에 추가", "Code로 열기"** 항목이 있으면 체크)
4. 설치 끝나면 VS Code 실행

> 맥: 다운로드한 앱을 `응용 프로그램` 폴더로 드래그하면 끝.

## 2) Node.js 설치

1. `nodejs.org` 접속
2. **LTS**라고 적힌 버튼 다운로드 (LTS = 오래 안정적으로 지원되는 버전)
3. 설치 파일 실행 → 전부 기본값으로 "다음" → 설치

## 3) Git 설치

1. `git-scm.com` 접속 → Download
2. 설치 파일 실행 → 옵션이 많이 나오는데 **전부 기본값으로 "Next"** 눌러도 됩니다
3. 설치 완료

## 설치가 됐는지 확인하기 (터미널 첫 만남)

**터미널**은 마우스 대신 글자 명령으로 컴퓨터에 일을 시키는 창입니다. 무섭게 생겼지만 그냥 "명령 → 엔터"의 반복입니다.

VS Code에서 상단 메뉴 **터미널 → 새 터미널**을 누르면 아래에 창이 하나 열립니다. 거기에 다음을 한 줄씩 치고 엔터하세요.

```bash
node -v
git --version
```

버전 숫자(예: `v20.11.0`, `git version 2.43.0`)가 나오면 성공입니다. `'node'은(는) ... 인식되지 않습니다` 같은 에러가 나오면 설치가 안 됐거나, **컴퓨터를 한 번 재부팅**하면 대개 해결됩니다.

## 프로젝트 폴더 만들기

블로그 파일들을 담을 폴더를 하나 만듭니다.

1. 원하는 위치(예: `D:\`)에 `Blog`라는 폴더를 탐색기에서 만듭니다
2. VS Code에서 **파일 → 폴더 열기** → 방금 만든 `Blog` 폴더 선택
3. 왼쪽에 폴더 이름이 뜨면 준비 완료

이제부터 우리가 만드는 모든 파일은 이 `Blog` 폴더 안에 들어갑니다.

## 터미널 기본 명령 3개만

앞으로 자주 쓸 것만 미리 익혀둡시다. (윈도우 PowerShell 기준, 맥은 괄호 안)

- `dir` (맥: `ls`) — 현재 폴더에 뭐가 있는지 목록 보기
- `cd 폴더이름` — 그 폴더로 들어가기 (`cd ..` 는 한 단계 위로)
- `node 파일.js` — 자바스크립트 파일 실행

지금은 "이런 게 있구나" 정도면 됩니다. 실제로는 필요할 때마다 다시 알려드립니다.

## 자주 나는 실수

- **`node -v`가 인식 안 됨** → 재부팅 후 다시. 그래도 안 되면 Node.js 재설치.
- **어느 폴더에 있는지 헷갈림** → 터미널 프롬프트 맨 앞에 현재 경로가 보입니다. `Blog` 폴더 안에 있는지 항상 확인.
- **VS Code에서 폴더가 아니라 파일 하나만 열었을 때** → 반드시 "폴더 열기"로 `Blog` 폴더 전체를 여세요.

준비 끝났습니다. 다음 편에서 드디어 첫 웹페이지를 브라우저에 띄웁니다.
