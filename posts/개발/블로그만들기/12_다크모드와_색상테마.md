# 다크 모드 & 색상 테마

03편에서 색을 전부 **CSS 변수**로 만들어 뒀죠. 이제 그 변수 값만 바꾸면 사이트 전체가 한 번에 바뀝니다. 이번 편에서 **다크 모드 전환**과 **포인트 색 선택**을 붙입니다. 선택은 브라우저에 저장돼 다음에 와도 유지됩니다.

## 부품 1 — storage.js (설정 저장소)

사용자의 선택(다크/라이트, 색상)을 브라우저에 저장해야 합니다. 브라우저에는 **localStorage**라는 작은 저장 공간이 있어요. 새로고침하거나 브라우저를 껐다 켜도 남아 있습니다.

localStorage를 매번 직접 쓰면 예외 처리가 번거로우니, 한 곳에서 감싸 관리합니다. `js/core/storage.js`를 만드세요.

```javascript
const Storage = {
  set(key, value) {
    try { localStorage.setItem(key, JSON.stringify(value)); }
    catch (e) { console.warn('[Storage] 저장 실패:', key, e); }
  },
  get(key, defaultValue = null) {
    try {
      const raw = localStorage.getItem(key);
      return raw !== null ? JSON.parse(raw) : defaultValue;
    } catch (e) {
      console.warn('[Storage] 읽기 실패:', key, e);
      return defaultValue;
    }
  },
  remove(key) {
    try { localStorage.removeItem(key); }
    catch (e) { console.warn('[Storage] 삭제 실패:', key, e); }
  },
};

export default Storage;
```

- `set(key, value)` — 값을 저장. `JSON.stringify`로 객체·배열도 글자로 바꿔 저장합니다(localStorage는 글자만 저장 가능).
- `get(key, 기본값)` — 저장된 값을 꺼내 `JSON.parse`로 원래 형태로. 없으면 기본값 반환.
- 전부 `try/catch`로 감쌌습니다. (사생활 보호 모드 등에서 localStorage가 막힐 때 앱이 안 죽게.)

## 부품 2 — theme.js (다크/라이트 전환)

`js/core/theme.js`를 만드세요.

```javascript
import Storage from './storage.js';
import App from './app.js';

const STORAGE_KEY = 'theme';

const Theme = {
  init() {
    const saved = Storage.get(STORAGE_KEY, 'light');
    this._apply(saved);

    const btn = document.getElementById('themeToggle');
    if (btn) btn.addEventListener('click', () => this.toggle());
  },

  toggle() {
    const next = document.documentElement.classList.contains('dark') ? 'light' : 'dark';
    this._apply(next);
    Storage.set(STORAGE_KEY, next);
    App.emit('theme:change', { theme: next });
  },

  current() {
    return document.documentElement.classList.contains('dark') ? 'dark' : 'light';
  },

  _apply(theme) {
    if (theme === 'dark') {
      document.documentElement.classList.add('dark');
      this._setButton('☀️', '라이트');
    } else {
      document.documentElement.classList.remove('dark');
      this._setButton('🌙', '다크');
    }
  },

  _setButton(icon, label) {
    const iconEl  = document.getElementById('themeIcon');
    const labelEl = document.getElementById('themeLabel');
    if (iconEl)  iconEl.textContent  = icon;
    if (labelEl) labelEl.textContent = label;
  },
};

export default Theme;
```

**핵심**: 다크 모드는 **`<html>` 태그에 `dark` 클래스를 붙이고 떼는 것**이 전부입니다. 03편 `variables.css`에 `:root.dark { ... }`를 정의했죠? `:root`는 `<html>`을 뜻하므로, `<html>`에 `dark` 클래스가 붙는 순간 그 안의 변수 값들이 어두운 색으로 덮어써지고, 그 변수를 쓰는 모든 요소가 한꺼번에 바뀝니다.

- `init()` — 저장된 테마를 불러와 적용하고, 헤더의 토글 버튼(`themeToggle`)에 클릭 이벤트를 답니다.
- `toggle()` — 지금이 dark면 light로, 아니면 dark로 바꾸고 저장한 뒤 `theme:change` 방송(다른 모듈이 알아야 할 때 대비).
- `_apply(theme)` — `<html>`에 클래스를 add/remove하고 버튼 아이콘(🌙/☀️)을 바꿉니다.
- **왜 `<body>`가 아니라 `document.documentElement`(=`<html>`)에 붙일까?** 아래 '섬광 방지'에서 이유가 나옵니다.

## 부품 3 — accent.js (포인트 색 8종)

`js/core/accent.js`를 만드세요. 미리 정해둔 8가지 색 중 하나를 골라 `--accent`를 바꿉니다.

```javascript
import Storage from './storage.js';

const STORAGE_KEY = 'accent_preset';

const PRESETS = [
  { name: '인디고', accent: '#6366f1', light: 'rgba(99,102,241,0.13)'  },
  { name: '블루',   accent: '#3b82f6', light: 'rgba(59,130,246,0.13)'  },
  { name: '에메랄드', accent: '#10b981', light: 'rgba(16,185,129,0.13)' },
  { name: '티얼',   accent: '#06b6d4', light: 'rgba(6,182,212,0.13)'   },
  { name: '보라',   accent: '#8b5cf6', light: 'rgba(139,92,246,0.13)'  },
  { name: '핑크',   accent: '#ec4899', light: 'rgba(236,72,153,0.13)'  },
  { name: '로즈',   accent: '#f43f5e', light: 'rgba(244,63,94,0.13)'   },
  { name: '오렌지', accent: '#f97316', light: 'rgba(249,115,22,0.13)'  },
];

const Accent = {
  _current: 0,

  init() {
    this._current = Storage.get(STORAGE_KEY, 0);
    if (this._current < 0 || this._current >= PRESETS.length) this._current = 0;
    this._apply(this._current);
    this._buildPopup();
    this._bindEvents();
  },

  _apply(index) {
    const preset = PRESETS[index];
    if (!preset) return;
    const root = document.documentElement;
    root.style.setProperty('--accent',       preset.accent);
    root.style.setProperty('--accent-light', preset.light);
    document.querySelectorAll('.color-dot').forEach(dot => {
      dot.style.background = preset.accent;
    });
  },

  _buildPopup() {
    const popup = document.getElementById('colorPresetPopup');
    if (!popup) return;
    popup.innerHTML = PRESETS.map((p, i) => `
      <button class="preset-swatch ${i === this._current ? 'active' : ''}"
              data-index="${i}" title="${p.name}"
              style="background: ${p.accent};"></button>`).join('');
  },

  _bindEvents() {
    const btn   = document.getElementById('colorPresetBtn');
    const popup = document.getElementById('colorPresetPopup');
    const wrap  = document.getElementById('colorPresetWrap');
    if (!btn || !popup || !wrap) return;

    btn.addEventListener('click', (e) => {
      e.stopPropagation();
      popup.classList.toggle('open');
    });
    popup.addEventListener('click', (e) => {
      const swatch = e.target.closest('.preset-swatch');
      if (!swatch) return;
      const index = parseInt(swatch.dataset.index, 10);
      this._current = index;
      this._apply(index);
      Storage.set(STORAGE_KEY, index);
      popup.querySelectorAll('.preset-swatch').forEach((s, i) =>
        s.classList.toggle('active', i === index));
      popup.classList.remove('open');
    });
    document.addEventListener('click', (e) => {
      if (!wrap.contains(e.target)) popup.classList.remove('open');
    });
  },
};

export default Accent;
```

- `PRESETS` — 8가지 색 목록. 각각 `accent`(주 색)와 `light`(연한 배경용)를 함께 정의해, 어디서나 색이 일관돼요.
- `_apply(index)` — `root.style.setProperty('--accent', ...)`로 **CSS 변수 값을 자바스크립트에서 직접 바꿉니다.** 이 한 줄로 사이트 전체 포인트 색이 즉시 바뀝니다. CSS 변수의 힘이죠.
- `_buildPopup()` — 색 스와치 버튼들을 만들고, `_bindEvents()`에서 버튼 열기/닫기·스와치 클릭·바깥 클릭 닫기를 답니다. `e.stopPropagation()`은 "이 클릭이 '바깥 클릭 닫기'까지 번지지 않게" 막는 것이고요.

## 섬광 방지 — 새로고침 때 번쩍임 없애기

여기서 중요한 기법 하나. 다크 모드로 저장해둔 사람이 페이지를 새로고침하면, **잠깐 하얀 화면이 번쩍**였다가 어두워집니다. 왜냐하면 우리 `theme.js`(모듈 스크립트)는 **CSS와 HTML이 다 로드된 뒤에야** 실행돼서, 그 사이 잠깐 라이트 모드가 보이거든요. 이 번쩍임을 **섬광(FOUC)**이라고 합니다.

해결책: **CSS가 로드되기도 전에**, `<head>` 맨 위에서 즉시 실행되는 작은 스크립트로 `<html>`에 `dark` 클래스를 미리 붙여둡니다. 각 HTML의 `<head>`에 이걸 넣으세요.

```html
<script>
  (function () {
    try {
      if (JSON.parse(localStorage.getItem('theme')) === 'dark')
        document.documentElement.classList.add('dark');
      var i = parseInt(localStorage.getItem('accent_preset'), 10);
      var presets = ['#6366f1','#3b82f6','#10b981','#06b6d4','#8b5cf6','#ec4899','#f43f5e','#f97316'];
      if (!isNaN(i) && presets[i]) {
        document.documentElement.style.setProperty('--accent', presets[i]);
      }
    } catch (e) {}
  })();
</script>
```

이 스크립트는 `<head>`에서 **CSS보다 먼저** 실행되어, 브라우저가 화면을 그리기 전에 이미 다크 클래스와 색을 세팅합니다. 그래서 번쩍임이 없어요. **이것이 다크 클래스를 `<body>`가 아니라 `<html>`(`documentElement`)에 붙이는 이유**입니다 — 이 시점엔 `<body>`가 아직 안 만들어졌지만 `<html>`은 항상 존재하거든요. `(function(){...})()`는 "즉시 실행 함수"로, 변수들이 밖으로 새지 않게 감싼 것입니다.

## 자주 나는 실수

- **버튼 눌러도 안 바뀜** → `themeToggle`/`colorPresetBtn` 등 id가 HTML과 JS에서 일치하는지, `Theme.init()`/`Accent.init()`을 호출했는지 확인.
- **새로고침 때 번쩍임** → 섬광 방지 인라인 스크립트가 `<head>` 안, CSS `<link>`보다 **위**에 있는지 확인.
- **색만 바뀌고 연한 배경(--accent-light)은 그대로** → `_apply`에서 `--accent-light`도 setProperty 하는지 확인.
- **설정이 저장 안 됨** → 시크릿 모드/localStorage 차단 환경일 수 있음. `try/catch`로 앱은 안 죽지만 저장은 안 됩니다.

## 정리

- 다크 모드 = `<html>`에 `dark` 클래스 붙이고 떼기. CSS `:root.dark` 변수가 자동 적용된다.
- 포인트 색 = 자바스크립트로 `--accent` 변수 값을 바꾸기(`setProperty`). 8종 프리셋 제공.
- 선택은 **localStorage**(storage.js)에 저장해 재방문 시 유지.
- **섬광 방지**: CSS 로드 전 `<head>` 인라인 스크립트로 `<html>`에 미리 세팅.

다음 편(13)에서는 왼쪽 **사이드바 카테고리 트리(sidebar.js)**를 만들어, 폴더 구조를 접었다 펴는 트리로 보여주고 클릭하면 필터가 걸리게 합니다.
