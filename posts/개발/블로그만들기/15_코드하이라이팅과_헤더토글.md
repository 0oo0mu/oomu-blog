# 코드 하이라이팅 & 헤더 토글

개발 블로그라면 코드가 예뻐야죠. 이번 편에서는 마크다운이 HTML로 변환된 **본문을 한 번 더 손봐서(후처리)** 두 가지를 넣습니다.

1. 코드 블록에 **문법 색상**(하이라이팅) + 언어 라벨 + 복사 버튼
2. 소제목(h2~h4)을 클릭하면 아래 내용을 **접었다 펴는 토글**

이 "렌더 후 DOM을 손보는" 방식은 아주 흔한 패턴이라 익혀두면 두루 씁니다.

## highlight.js 불러오기

코드 색칠은 **highlight.js** 라이브러리로 합니다. marked처럼 CDN으로 불러옵니다. 각 HTML `<head>`에 추가하세요.

```html
<script src="https://cdn.jsdelivr.net/npm/highlight.js@11.9.0/lib/highlight.min.js"></script>
```

이러면 `window.hljs.highlightElement(코드요소)`로 특정 `<code>`에 색을 입힐 수 있습니다.

## 후처리 모듈 — post-enhance.js

`js/modules/post-enhance.js`를 만드세요. 본문 요소를 받아 두 작업을 수행합니다.

```javascript
const PostEnhance = {
  apply(bodyEl) {
    if (!bodyEl) return;
    this._highlightCode(bodyEl);
    this._makeCollapsibleHeaders(bodyEl);
  },

  // [1] 코드 블록 하이라이팅 + 헤더바(언어 라벨 + 복사)
  _highlightCode(bodyEl) {
    bodyEl.querySelectorAll('pre code').forEach(code => {
      const pre = code.closest('pre');
      if (!pre || pre.parentElement.classList.contains('code-block')) return; // 중복 방지

      // 언어 감지: marked가 붙인 language-xxx 클래스
      const langClass = [...code.classList].find(c => c.startsWith('language-'));
      const lang = langClass ? langClass.replace('language-', '') : '';

      if (window.hljs) {
        try { window.hljs.highlightElement(code); } catch (_) {}
      }

      // <div.code-block> 로 감싸고 헤더바 추가
      const block = document.createElement('div');
      block.className = 'code-block';
      pre.replaceWith(block);

      const head = document.createElement('div');
      head.className = 'code-block-head';
      const label = document.createElement('span');
      label.className = 'code-lang';
      label.textContent = (lang || 'code').toUpperCase();
      const copyBtn = document.createElement('button');
      copyBtn.className = 'code-copy';
      copyBtn.textContent = '복사';
      copyBtn.addEventListener('click', () => {
        navigator.clipboard?.writeText(code.textContent).then(() => {
          copyBtn.textContent = '복사됨!';
          setTimeout(() => { copyBtn.textContent = '복사'; }, 1500);
        });
      });
      head.append(label, copyBtn);
      block.append(head, pre);
    });
  },

  // [2] 소제목 접기/펼치기
  _makeCollapsibleHeaders(bodyEl) {
    bodyEl.querySelectorAll('h2, h3, h4').forEach(header => {
      // 이 헤더 다음부터 "다음 헤더 직전"까지의 형제들을 모아
      const content = [];
      let sib = header.nextElementSibling;
      while (sib && !/^H[1-4]$/.test(sib.tagName)) {
        content.push(sib);
        sib = sib.nextElementSibling;
      }
      // 래퍼로 감싸 헤더 뒤에 넣기
      const wrapper = document.createElement('div');
      wrapper.className = 'toggle-content';
      header.after(wrapper);
      content.forEach(el => wrapper.appendChild(el));

      header.classList.add('toggle-header');
      header.addEventListener('click', () => {
        const collapsed = header.classList.toggle('collapsed');
        wrapper.classList.toggle('collapsed', collapsed);
      });
    });
  },
};

export default PostEnhance;
```

## 해설

### 코드 하이라이팅

- **`bodyEl.querySelectorAll('pre code')`** — 마크다운의 코드 블록은 `<pre><code>...</code></pre>` 형태로 변환됩니다. 그걸 다 찾아 하나씩 처리해요.
- **언어 감지** — marked는 ```` ```js ````처럼 적으면 `<code class="language-js">`를 붙여줍니다. 그 클래스에서 언어 이름(`js`)을 뽑습니다.
- **`window.hljs.highlightElement(code)`** — highlight.js가 그 코드의 문법을 분석해 키워드·문자열·숫자 등에 각각 다른 클래스(`hljs-keyword` 등)를 붙입니다. **색 자체는 CSS**로 입혀요(다음 절).
- **노션식 헤더바** — 코드 블록을 `<div class="code-block">`으로 감싸고, 위에 **언어 라벨**과 **복사 버튼**을 답니다. 복사는 `navigator.clipboard.writeText`로 클립보드에 넣고 "복사됨!"을 잠깐 보여줍니다. `pre.parentElement.classList.contains('code-block')` 체크로 이미 처리한 블록을 또 감싸지 않게 막았어요(미리보기에서 여러 번 호출될 때 대비).

### 헤더 토글

- 소제목 하나를 잡고, **그 다음 형제부터 다음 소제목이 나오기 직전까지**의 요소들을 모읍니다(`nextElementSibling`을 따라가며). 정규식 `/^H[1-4]$/`로 "태그가 H1~H4인가"를 검사해 다음 소제목에서 멈춰요.
- 모은 내용을 `<div class="toggle-content">`로 감싸 헤더 바로 뒤에 넣고, 헤더에 클릭 이벤트를 답니다. 클릭하면 헤더와 래퍼에 `collapsed` 클래스를 토글해, CSS가 내용을 숨기거나 보입니다.

## CSS — 색과 토글 모양

색은 highlight.js가 붙인 클래스에 우리가 직접 지정합니다. 라이트/다크 테마에 맞춰 CSS 변수로 정의하면 좋아요. `css/code.css`에 넣습니다(일부).

```css
/* 토큰 색 (라이트) */
:root {
  --hl-keyword: #d73a49; --hl-string: #032f62; --hl-number: #005cc5;
  --hl-comment: #6a737d; --hl-title: #6f42c1;
}
:root.dark {
  --hl-keyword: #ff7b72; --hl-string: #a5d6ff; --hl-number: #79c0ff;
  --hl-comment: #8b949e; --hl-title: #d2a8ff;
}
.hljs-keyword { color: var(--hl-keyword); }
.hljs-string  { color: var(--hl-string); }
.hljs-number  { color: var(--hl-number); }
.hljs-comment { color: var(--hl-comment); font-style: italic; }
.hljs-title, .hljs-title\.function_ { color: var(--hl-title); }

/* 코드 블록 컨테이너 */
.code-block { border: 1px solid var(--border); border-radius: 8px; overflow: hidden; margin-bottom: 1.5rem; }
.code-block-head {
  display: flex; justify-content: space-between; align-items: center;
  padding: 0.4rem 0.75rem; background: var(--bg-card);
  border-bottom: 1px solid var(--border); font-size: 0.72rem;
}
.code-copy { background: none; border: 1px solid var(--border); border-radius: 5px;
  color: var(--text-muted); cursor: pointer; padding: 0.15rem 0.55rem; }
.code-block pre { margin: 0; border: none; }

/* 헤더 토글 */
.toggle-header { cursor: pointer; }
.toggle-header::before {
  content: '▾'; display: inline-block; width: 0.9em; margin-right: 0.35em;
  color: var(--text-muted); transition: transform 0.15s;
}
.toggle-header.collapsed::before { transform: rotate(-90deg); }
.toggle-content.collapsed { display: none; }
```

색을 **직접 CSS 변수로 정의**한 이유: highlight.js가 제공하는 기본 테마 CSS를 쓰면 다크/라이트 전환에 안 맞습니다. 우리가 변수로 정의하면 12편의 다크 모드에 자동으로 어울려요. 토글은 `.toggle-content.collapsed { display: none }`으로 접고, 소제목 앞 `▾` 화살표를 `collapsed`일 때 회전시켜 접힘을 표시합니다.

## 연결

포스트 뷰 렌더 + 목차 생성 뒤에 `PostEnhance.apply(bodyEl)`를 부릅니다.

```javascript
import PostEnhance from './modules/post-enhance.js';
// ...
bodyEl.innerHTML = Markdown.parse(content);
Toc.build();
PostEnhance.apply(bodyEl);   // ← 추가 (목차 뒤에: heading id 유지)
```

목차(`Toc.build`)가 heading에 id를 붙인 뒤에 후처리를 하는 순서가 안전합니다.

## 자주 나는 실수

- **코드에 색이 안 입혀짐** → highlight.js CDN을 `<head>`에 넣었는지, 코드 블록을 ```` ```언어 ````로 언어를 지정했는지 확인.
- **색이 흐릿하거나 다크에서 안 어울림** → `.hljs-*` 색을 CSS 변수로 정의하고 `:root.dark`에서 다시 지정했는지.
- **복사 버튼이 안 됨** → `navigator.clipboard`는 `https`나 `localhost`에서만 동작. `file://`에선 막힐 수 있습니다.
- **토글이 목차를 깨뜨림** → `PostEnhance.apply`를 `Toc.build` **뒤에** 호출하세요.

## 정리

- 마크다운 → HTML로 렌더된 **본문을 후처리**해서 기능을 얹는 패턴을 배웠다.
- **highlight.js**로 코드 문법을 분석하고, **색은 CSS 변수**로 지정해 다크 모드와 어울리게.
- 코드 블록에 언어 라벨·복사 버튼을 단다.
- 소제목 아래 내용을 모아 래퍼로 감싸 **접기/펼치기 토글**을 만든다.
