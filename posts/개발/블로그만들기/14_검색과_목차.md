# 검색창과 목차

이번 편은 두 기능입니다. 목록을 검색하는 **검색창**(11편 필터와 연결)과, 긴 글을 읽을 때 위치를 잡아주는 **목차(TOC)**입니다.

## 검색창 — search.js

검색창은 아주 단순합니다. 입력이 들어오면 `filter:search`를 방송만 하면, 나머지(걸러내기)는 11편 필터가 알아서 합니다.

`js/modules/search.js`를 만드세요.

```javascript
import App from '../core/app.js';

const Search = {
  init() {
    const input    = document.getElementById('searchInput');
    const clearBtn = document.getElementById('searchClear');
    if (!input) return;

    let debounce = null;

    input.addEventListener('input', () => {
      clearTimeout(debounce);
      debounce = setTimeout(() => {
        const query = input.value.trim();
        if (clearBtn) clearBtn.style.display = query ? 'flex' : 'none';
        App.emit('filter:search', { query });   // ← 필터가 이걸 듣는다
      }, 200);
    });

    if (clearBtn) {
      clearBtn.addEventListener('click', () => {
        input.value = '';
        clearBtn.style.display = 'none';
        App.emit('filter:search', { query: '' });
        input.focus();
      });
    }

    // '/' 키로 검색창 포커스 (입력 중이 아닐 때)
    document.addEventListener('keydown', (e) => {
      const tag = document.activeElement?.tagName;
      const isTyping = ['INPUT', 'TEXTAREA', 'SELECT'].includes(tag);
      if (e.key === '/' && !isTyping) {
        e.preventDefault();
        input.focus();
        input.select();
      }
    });
  },
};

export default Search;
```

**핵심 개념 — 디바운스(debounce)**

`input` 이벤트는 **글자 하나 칠 때마다** 발생합니다. "javascript"를 치면 10번이나 발생해요. 매번 필터링하면 낭비죠. 그래서 **"입력이 멈추고 200ms 지난 뒤에 한 번만"** 실행합니다. 이걸 **디바운스**라고 해요.

- `clearTimeout(debounce)` — 이전에 예약해둔 실행을 취소.
- `setTimeout(() => {...}, 200)` — 200ms 뒤 실행을 새로 예약.
- 계속 타이핑하면 매번 취소되고 다시 예약되니, **멈춘 순간 딱 한 번**만 방송됩니다.

나머지는 X(지우기) 버튼과, `/` 키를 누르면 검색창에 포커스되는 단축키입니다. `document.activeElement`로 지금 입력 중인지 확인해, 글 쓰는 중엔 단축키가 안 튀게 했어요.

HTML엔 검색 입력칸을 둡니다.

```html
<input type="text" id="searchInput" placeholder="검색... (단축키: /)" />
<button id="searchClear" style="display:none">✕</button>
```

이제 검색창에 치면 → `filter:search` 방송 → 11편 필터가 `state.query`를 갱신하고 다시 걸러 → renderer가 결과를 그립니다. **모듈들이 이벤트로만 연결돼 있어서, 검색창은 필터의 내부를 전혀 몰라도 됩니다.** 이게 이벤트 버스의 힘이에요.

## 목차(TOC) — toc.js

긴 글에는 오른쪽에 **목차**가 있으면 좋죠. 본문의 소제목(`h2`~`h4`)을 모아 목차를 만들고, 스크롤하면 **지금 읽는 섹션을 하이라이트**합니다.

### 두 가지 핵심 개념

1. **heading에 id 부여** — 목차 링크가 특정 소제목으로 점프하려면, 각 소제목에 고유한 `id`가 있어야 합니다(`<h2 id="h-0-...">`). 그래야 `#id`로 이동할 수 있어요.
2. **스크롤 스파이(scroll spy)** — 스크롤 위치를 보고 "지금 어느 섹션이지?"를 계산해 그 목차 항목을 활성화합니다.

`js/modules/toc.js`를 만드세요.

```javascript
const Toc = {
  _rafId: null,
  _scrollHandler: null,
  _headings: [],

  build({ bodyId = 'postBody', tocId = 'tocList', sidebarId = 'tocSidebar' } = {}) {
    this._cleanup(); // 이전 목차 정리 (글 바꿀 때 중복 방지)

    const body    = document.getElementById(bodyId);
    const tocList = document.getElementById(tocId);
    const sidebar = document.getElementById(sidebarId);
    if (!body || !tocList || !sidebar) return;

    // 본문에서 h2, h3, h4 모으기
    const headings = Array.from(body.querySelectorAll('h2, h3, h4'));
    if (headings.length === 0) { sidebar.style.display = 'none'; return; }
    sidebar.style.display = '';
    tocList.innerHTML = '';

    // 각 heading에 id 부여 + 목차 항목 생성
    headings.forEach((heading, idx) => {
      const id = `h-${idx}-` + heading.textContent
        .toLowerCase().replace(/[^\w\s가-힣]/g, '').replace(/\s+/g, '-').slice(0, 40);
      heading.id = id;

      const level = parseInt(heading.tagName[1]); // 2, 3, 4
      const li = document.createElement('li');
      li.className = `toc-item level-${level}`;
      const a = document.createElement('a');
      a.href = `#${id}`;
      a.textContent = heading.textContent;
      a.addEventListener('click', (e) => {
        e.preventDefault();
        this._setActive(tocList, id);
        document.getElementById(id)?.scrollIntoView({ behavior: 'smooth', block: 'start' });
      });
      li.appendChild(a);
      tocList.appendChild(li);
    });

    this._headings = headings;

    // 스크롤 감지 (성능을 위해 requestAnimationFrame으로 제한)
    this._scrollHandler = () => {
      if (this._rafId) cancelAnimationFrame(this._rafId);
      this._rafId = requestAnimationFrame(() => this._updateActive(tocList));
    };
    window.addEventListener('scroll', this._scrollHandler, { passive: true });
    this._updateActive(tocList);
  },

  // 현재 스크롤 위치 기준 활성 섹션 계산
  _updateActive(tocList) {
    if (!this._headings.length) return;
    const headerHeight = parseInt(
      getComputedStyle(document.documentElement).getPropertyValue('--header-height') || '60');

    // 기준선을 화면 위 40% 지점("읽는 지점")에 두어, 화면을 채운 섹션이 잡히게
    const readingLine = window.scrollY + headerHeight
                      + (window.innerHeight - headerHeight) * 0.4;

    let activeId = null;
    for (const heading of this._headings) {
      if (heading.offsetTop <= readingLine) activeId = heading.id;
      else break;
    }
    // 페이지 끝이면 마지막 섹션
    if (window.innerHeight + window.scrollY >= document.documentElement.scrollHeight - 2) {
      activeId = this._headings[this._headings.length - 1].id;
    }
    if (!activeId) activeId = this._headings[0].id;
    this._setActive(tocList, activeId);
  },

  _setActive(tocList, id) {
    tocList.querySelectorAll('a.active').forEach(a => a.classList.remove('active'));
    const link = tocList.querySelector(`a[href="#${id}"]`);
    if (link) { link.classList.add('active'); link.scrollIntoView({ block: 'nearest' }); }
  },

  _cleanup() {
    if (this._scrollHandler) window.removeEventListener('scroll', this._scrollHandler);
    if (this._rafId) cancelAnimationFrame(this._rafId);
    this._scrollHandler = null; this._rafId = null; this._headings = [];
  },
};

export default Toc;
```

### 해설

- **`build()`** — 글을 그린 뒤 호출합니다(포스트 뷰 렌더 후). 본문에서 `querySelectorAll('h2, h3, h4')`로 소제목을 다 모아, 각각 고유 `id`를 붙이고 목차 링크(`<a href="#id">`)를 만듭니다. 소제목이 없으면 목차 사이드바를 숨겨요.
- **id 만들기** — 소제목 텍스트에서 특수문자를 걷어내고 공백을 `-`로 바꿔 슬러그를 만들되, 앞에 `h-순번-`을 붙여 **중복을 방지**합니다(같은 제목이 여러 개여도 안전).
- **스크롤 스파이(`_updateActive`)** — 지금 스크롤 위치에서 **화면 위 40% 지점("읽는 지점")** 을 기준선으로 잡고, 그 선을 지나친 소제목 중 **가장 마지막 것**을 현재 섹션으로 봅니다. 화면을 꽉 채운 섹션이 자연스럽게 잡히도록 한 거예요. 페이지 맨 끝까지 내리면 마지막 섹션을 강제로 활성화합니다(짧은 마지막 섹션 대응).
- **성능** — `scroll` 이벤트는 초당 수십 번 터집니다. 매번 계산하면 버벅여요. 그래서 `requestAnimationFrame`으로 **화면 한 프레임당 한 번만** 계산하도록 제한합니다. `{ passive: true }`는 "이 스크롤 처리는 스크롤을 막지 않아"라고 브라우저에 알려 더 부드럽게 해줍니다.
- **`_cleanup()`** — SPA에서 글을 바꾸면 목차를 새로 그려야 하는데, 옛 스크롤 리스너가 남아 있으면 중복·누수가 생깁니다. 그래서 새로 `build`할 때마다 옛 리스너를 제거합니다.

### 연결

포스트 뷰를 렌더한 직후 `Toc.build()`를 부릅니다(10편 `router:post` 핸들러 끝에).

```javascript
import Toc from './modules/toc.js';
// ... 본문 렌더 후 ...
bodyEl.innerHTML = Markdown.parse(content);
Toc.build();   // ← 추가
```

HTML엔 목차가 들어갈 자리를 둡니다.

```html
<aside id="tocSidebar">
  <ul id="tocList"></ul>
</aside>
```

## 자주 나는 실수

- **검색이 즉각 반응 안 함** → 디바운스 200ms 때문(정상). 너무 느리면 숫자를 줄이세요.
- **목차 링크가 엉뚱한 곳으로 점프** → heading에 `id`가 안 붙었거나 중복. `h-순번-` 접두사 확인.
- **목차 하이라이트가 안 따라옴** → `Toc.build()`를 본문 렌더 **후에** 불렀는지, `--header-height` 변수가 있는지 확인.
- **글 바꿀 때마다 스크롤이 버벅** → `_cleanup()`으로 옛 리스너 제거를 빠뜨림.

## 정리

- **검색창**은 디바운스로 입력이 멎으면 `filter:search`만 방송한다. 걸러내기는 필터가 담당(이벤트로 분리).
- **목차**는 본문 h2~h4에 id를 붙여 링크를 만들고, **스크롤 스파이**로 현재 섹션을 하이라이트한다.
- 스크롤 처리는 `requestAnimationFrame`으로 성능을 지키고, SPA 재렌더 시 `_cleanup`으로 정리한다.
