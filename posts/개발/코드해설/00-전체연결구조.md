## 들어가기 전에

이 블로그는 React나 Vue 같은 프레임워크를 전혀 쓰지 않습니다.  
순수한 HTML, CSS, JavaScript 파일들이 서로 약속을 지키면서 하나의 앱처럼 동작하는 구조예요.

코드를 처음 보면 파일이 15개나 되어서 막막할 수 있어요.  
하지만 각 파일이 **딱 하나의 역할**만 담당하도록 설계되어 있어서, 하나씩 이해하면 전체가 보입니다.

---

## 파일 구조 한눈에 보기

```
js/
├── core/          ← 뼈대 (모든 모듈이 공통으로 쓰는 것들)
│   ├── app.js         → 모듈들의 우체국 (이벤트 버스)
│   ├── router.js      → 페이지 이동 담당
│   ├── storage.js     → 브라우저 저장소 담당
│   ├── theme.js       → 다크/라이트 모드
│   ├── accent.js      → 포인트 컬러 선택
│   ├── env.js         → 로컬/배포 환경 구분
│   └── config.js      → 블로그 설정값
│
├── modules/       ← 기능 (실제로 화면에 보이는 것들)
│   ├── posts-loader.js   → 게시글 목록 불러오기
│   ├── filter.js         → 카테고리/태그/검색어 필터
│   ├── search.js         → 검색창
│   ├── renderer.js       → 게시글 카드 그리기
│   ├── sidebar.js        → 왼쪽 카테고리 트리
│   ├── toc.js            → 게시글 오른쪽 목차
│   ├── music-player.js   → 하단 뮤직 플레이어
│   └── markdown.js       → 마크다운 → HTML 변환
│
├── app-index.js   ← 메인 페이지 시작점
└── app-editor.js  ← 에디터 페이지 시작점
```

---

## 핵심 개념: 모듈이란?

**모듈(Module)**이란 하나의 기능만 담당하는 JS 파일을 말합니다.

예를 들어 `search.js`는 검색창 하나만 담당합니다.  
검색창이 어떻게 생겼는지, 글자를 어떻게 저장하는지, 카드를 어떻게 그리는지는 몰라도 됩니다.  
"검색어가 바뀌었어요!"라고 소식만 전달하면 끝이에요.

이 소식을 전달하는 역할을 `app.js`가 맡습니다.

---

## 소식 전달 방식: 이벤트 버스

이 블로그의 모든 모듈은 `app.js`를 통해 소통합니다.

```
[search.js]         →  "검색어: javascript"  →  [app.js]
                                                     ↓
[filter.js]         ←  "필터 적용해!"        ←  [app.js]
                                                     ↓
[renderer.js]       ←  "이 글들 보여줘!"     ←  [app.js]
```

마치 우체국처럼, 보내는 쪽과 받는 쪽이 서로 직접 연락하지 않아요.  
`app.js`라는 우체국을 통해서만 소통합니다.

이걸 **이벤트 버스 패턴**이라고 합니다.

## 페이지 로드 순서

블로그를 열면 이런 순서로 실행됩니다:

```
1. index.html 로드
2. app-index.js 실행
3. Theme.init()     → 다크/라이트 모드 적용
4. Accent.init()    → 포인트 컬러 적용
5. Router.init()    → URL 파악 (목록? 특정 게시글?)
6. PostsLoader.load() → posts.json 가져오기
7. Sidebar.init()   → 카테고리 트리 그리기
8. Filter.init()    → 필터 준비
9. Search.init()    → 검색창 준비
10. Renderer.init() → 카드 목록 그리기
```

모든 준비가 끝나면 화면에 게시글 카드들이 나타납니다.

## 다음 글들

각 파일을 하나씩 자세히 설명합니다:

- **01** `app.js` — 모듈들의 우체국
- **02** `router.js` — 음악이 끊기지 않는 페이지 이동
- **03** `storage.js` — 브라우저에 데이터 저장하기
- **04** `theme.js` — 다크모드는 어떻게 동작하나
- **05** `accent.js` — 8가지 컬러 프리셋
- **06** `env.js` — 로컬인가 배포인가
- **07** `posts-loader.js` — 게시글 목록 불러오기
- **08** `filter.js` — 카테고리·태그·검색어 통합 필터
- **09** `search.js` — 실시간 검색과 디바운스
- **10** `renderer.js` — 포스트 카드를 화면에 그리기
- **11** `sidebar.js` — 폴더 트리 만들기
- **12** `toc.js` — 스크롤 따라가는 목차
- **13** `music-player.js` — 페이지 이동해도 음악이 안 끊기는 이유
- **14** `markdown.js` — 마크다운 파서
- **15** `build.js` — 빌드 스크립트
