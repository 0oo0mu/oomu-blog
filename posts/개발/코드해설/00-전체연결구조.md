# 전체 연결 구조 — 모든 파일이 어떻게 이어지나

## 파일 목록 한눈에 보기

이 블로그는 아래 15개 파일로 구성됩니다.

```
js/
├── core/              ← 기반 레이어 (다른 모듈들이 의존)
│   ├── app.js         [01] 이벤트 버스 & 모듈 레지스트리
│   ├── router.js      [02] SPA 라우터 (페이지 이동 없는 화면 전환)
│   ├── storage.js     [03] localStorage 래퍼
│   ├── theme.js       [04] 다크/라이트 테마
│   ├── accent.js      [05] 8가지 컬러 프리셋
│   ├── env.js         [06] 로컬/배포 환경 감지
│   └── config.js      build.js가 자동 생성하는 사이트 설정
│
└── modules/           ← 기능 레이어 (각 기능 담당)
    ├── posts-loader.js [07] posts.json 로드 & 캐싱
    ├── filter.js       [08] 카테고리·태그·검색 통합 필터
    ├── search.js       [09] 검색창 입력 처리 & 디바운스
    ├── renderer.js     [10] 포스트 카드 HTML 렌더링
    ├── sidebar.js      [11] 카테고리 트리 사이드바
    ├── toc.js          [12] 목차 생성 & 스크롤 하이라이트
    ├── music-player.js [13] 뮤직 플레이어
    ├── markdown.js     [14] 마크다운 파싱 & Front Matter
    └── editor.js       로컬 전용 글 작성 에디터

build.js               [15] 빌드 스크립트 (Node.js)
```

---

## 핵심 설계: 이벤트 버스

모든 모듈이 **app.js**를 통해 이벤트로 소통합니다.
화살표 방향이 "이 이벤트를 발행한다"는 뜻입니다.

```
posts-loader ──'posts:loaded'──▶ filter
                                 sidebar
                                 (renderer는 'posts:filtered'를 기다림)

sidebar      ──'filter:category'──▶ filter
search       ──'filter:search'───▶ filter

filter       ──'posts:filtered'──▶ renderer

router       ──'router:post'────▶ app-index.js (마크다운 로드)
             ──'router:list'────▶ app-index.js (목록 뷰 복원)

theme        ──'theme:change'───▶ (구독자 없음, 확장용)
```

## 시나리오 1: 페이지 처음 로드

```
브라우저가 index.html 열기
      │
      ├── <head> 인라인 스크립트 실행
      │       → localStorage에서 theme/accent 읽어 즉시 적용 (섬광 방지)
      │
      ├── CSS 로드 (이미 dark 클래스 있으면 다크 색상으로 시작)
      │
      └── app-index.js 실행 (ES Module)
              │
              ├── App.register('theme',   Theme)   → Theme.init()
              ├── App.register('accent',  Accent)  → Accent.init()
              ├── App.register('router',  Router)  → Router.init()
              ├── App.register('search',  Search)  → Search.init()
              ├── App.register('filter',  Filter)  → Filter.init()
              ├── App.register('renderer',Renderer)→ Renderer.init()
              ├── App.register('sidebar', Sidebar) → Sidebar.init()
              └── App.register('music',   Music)   → Music.init()
                                                          │
                        PostsLoader.load() 호출 ◀────────┘
                              │
                              ▼
                        fetch('posts/posts.json')
                              │
                              ▼
                        날짜 내림차순 정렬
                              │
                              ▼
                        App.emit('posts:loaded', { posts })
                              │
                    ┌─────────┼─────────┐
                    ▼         ▼         ▼
                 Filter    Sidebar   (기타 구독자)
                    │         │
                    │         └── 카테고리 트리 렌더링
                    │
                    └── 태그 칩 생성
                    └── _applyFilter() 실행
                              │
                              ▼
                        App.emit('posts:filtered', { posts: 전체, query: '' })
                              │
                              ▼
                         Renderer
                              │
                              └── postsGrid에 카드 HTML 삽입
```

## 시나리오 2: 카드 클릭 (글 읽기)

```
카드 클릭
      │
      ▼
Router (document 클릭 이벤트 위임)
      │
      ├── e.preventDefault()  ← 기본 링크 이동 막기
      ├── history.pushState() ← URL만 변경
      └── _applyView('post')
              │
              ├── listView 숨기기 (view-hidden 클래스)
              ├── postView 보이기
              └── App.emit('router:post', { file })
                        │
                        ▼
                  app-index.js
                        │
                        └── fetch('posts/hello.md')
                                  │
                                  ▼
                            Markdown.parseFrontMatter()
                            → { meta, content }
                                  │
                                  ▼
                            Markdown.parse(content)
                            → '<h1>...</h1><p>...</p>'
                                  │
                                  ▼
                            postBody.innerHTML = html
                                  │
                                  ▼
                              Toc.build()
                              → h2/h3/h4 찾아서 목차 생성
                              → 스크롤 이벤트 연결
```

## 시나리오 3: 검색

```
검색창에 타이핑
      │
      ▼
Search (input 이벤트)
      │
      ├── clearTimeout(이전 타이머)
      └── setTimeout(200ms 후...)
                  │
                  ▼ (200ms 후)
            App.emit('filter:search', { query: '자바스크립트' })
                  │
                  ▼
             Filter
                  │
                  ├── state.query 업데이트
                  └── _applyFilter()
                          │
                          ├── 카테고리 필터 (AND)
                          ├── 태그 필터 (AND)
                          └── 검색어 필터 (AND)
                                  │
                                  ▼
                          App.emit('posts:filtered', { posts: 결과, query })
                                  │
                                  ▼
                             Renderer
                                  │
                                  └── 카드 재렌더링 (검색어 하이라이트 포함)
```

## 시나리오 4: 뒤로가기

```
브라우저 ← 버튼 or 뒤로가기 제스처
      │
      ▼
popstate 이벤트 (Router가 구독)
      │
      ▼
e.state = { view: 'list' }  ← pushState 때 저장해둔 데이터
      │
      ▼
_applyView('list')
      │
      ├── postView 숨기기
      ├── listView 보이기
      ├── App.emit('router:list')
      └── requestAnimationFrame → 저장된 스크롤 위치 복원
```

## 데이터 흐름 전체 요약

```
[build.js 실행] (배포 전)
  posts/*.md 파일들
        │ 파싱
        ▼
  posts/posts.json 생성

[브라우저 실행]
  posts/posts.json
        │ fetch
        ▼
  PostsLoader._cache (메모리 캐시)
        │ posts:loaded 이벤트
        ├──▶ Filter._allPosts (필터링 원본)
        └──▶ Sidebar._allPosts (트리 생성 원본)
                    │
        사용자 조작 (카테고리/태그/검색)
                    │
                    ▼
               Filter._applyFilter()
                    │ posts:filtered 이벤트
                    ▼
               Renderer.render()
                    │
                    ▼
            postsGrid (화면)
```

## 파일별 의존 관계

아래는 "→"가 "를 import한다"는 뜻입니다.

```
app-index.js → app.js, router.js, theme.js, accent.js, env.js
             → posts-loader.js, filter.js, search.js, renderer.js
             → sidebar.js, music-player.js, markdown.js

router.js    → app.js
theme.js     → storage.js, app.js
accent.js    → storage.js
filter.js    → app.js
search.js    → app.js
renderer.js  → app.js
sidebar.js   → app.js, router.js
posts-loader.js → app.js
music-player.js → storage.js
markdown.js  → (의존성 없음, window.marked 사용)
toc.js       → (의존성 없음, 독립 모듈)
editor.js    → markdown.js
```

**핵심:** app.js와 storage.js가 가장 많이 쓰이는 기반 모듈입니다.
app.js에 의존하는 모듈은 직접 서로를 import하지 않아도 이벤트로 소통합니다.
toc.js와 music-player.js는 독립적이라 어떤 페이지에서도 쓸 수 있습니다.
