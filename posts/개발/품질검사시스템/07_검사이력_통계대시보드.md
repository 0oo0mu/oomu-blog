## 1. 검사이력 목록 — 전체 코드

```tsx

  const [filterResult,   setFilterResult]   = useState("all");

      if (filterCategory !== "all" && ins.inspection_category !== filterCategory) return false;
      if (filterResult   !== "all" && ins.result  !== filterResult)             return false;
      if (filterStatus   !== "all" && ins.status  !== filterStatus)             return false;
      if (filterDate) {

                    <td className="px-4 py-3">

                      </Link>
                    </td>
                  </tr>
                );
              })}
            </tbody>
          </table>
        </div>
      )}

        <div className="flex justify-center gap-1">
          <button onClick={() => setPage((p) => Math.max(1, p - 1))} disabled={page === 1} className="px-3 py-1.5 text-sm border border-slate-300 rounded-lg disabled:opacity-40 hover:bg-slate-50">이전</button>

            <button key={p} onClick={() => setPage(p)} className={`px-3 py-1.5 text-sm rounded-lg border ${p === page ? "bg-blue-600 text-white border-blue-600" : "border-slate-300 hover:bg-slate-50"}`}>{p}</button>
          ))}
          <button onClick={() => setPage((p) => Math.min(totalPages, p + 1))} disabled={page === totalPages} className="px-3 py-1.5 text-sm border border-slate-300 rounded-lg disabled:opacity-40 hover:bg-slate-50">다음</button>
        </div>
      )}
    </div>
  );
}
```

## 2. 핵심 부분 뜯어보기

### 모든 필터를 하나의 `useMemo`에서 한꺼번에 처리

```tsx
const filtered = useMemo(() => {
  return initialInspections.filter((ins) => {
    if (filterShip     !== "all" && ins.ship_id !== filterShip)               return false;
    if (filterCategory !== "all" && ins.inspection_category !== filterCategory) return false;
    if (filterResult   !== "all" && ins.result  !== filterResult)             return false;
    if (filterStatus   !== "all" && ins.status  !== filterStatus)             return false;
    if (filterDate) { ... }
    if (search) { ... }
    return true;
  });
}, [initialInspections, filterShip, filterCategory, filterResult, filterStatus, filterDate, search]);
```

이 코드의 패턴은 **"하나라도 조건에 안 맞으면 즉시 `false`를 반환하고 빠져나간다(early return)"**입니다. 6개의 필터(선박/검사종류/결과/상태/날짜/검색어) 중 사용자가 설정한 것만 검사하고, 설정 안 한 건(`"all"`이거나 빈 문자열) 그냥 통과시킵니다. 모든 조건을 다 통과한 항목만 최종적으로 `true`가 되어 결과 배열에 남습니다.

이 방식의 장점: 새 필터를 추가하고 싶으면(예: "검사자별 필터") `if (...) return false;` 한 줄만 추가하면 됩니다 — 기존 로직을 건드릴 필요가 없습니다.

`useMemo`의 의존성 배열에 사용된 모든 필터 상태값을 빠짐없이 넣어야 합니다. 하나라도 빠뜨리면, 그 필터를 바꿔도 "다시 계산"이 일어나지 않아서 화면이 갱신 안 되는 버그가 생깁니다.

### 클라이언트 사이드 페이지네이션

```tsx
const totalPages = Math.ceil(filtered.length / PAGE_SIZE);
const paged = filtered.slice((page - 1) * PAGE_SIZE, page * PAGE_SIZE);
```

- `Math.ceil(나누기결과)`: 올림. 예를 들어 23건을 10건씩 보여주면 `Math.ceil(23/10) = 3`페이지가 필요합니다 (2.3을 올려서 3).
- `.slice(시작, 끝)`: 배열의 일부만 잘라내는 함수. 1페이지면 `slice(0, 10)`(0~9번째), 2페이지면 `slice(10, 20)`처럼 계산됩니다.

이 방식은 **"이미 다 가져온 데이터를, 화면에서만 나눠서 보여주는"** 클라이언트 사이드 페이지네이션입니다. 데이터가 수만 건 이상으로 많아지면 서버에서부터 페이지 단위로 나눠서 가져오는(서버 사이드 페이지네이션) 방식이 더 적절하지만, 검사 기록이 수백~수천 건 수준인 이 프로젝트 규모에서는 단순한 클라이언트 방식으로도 충분합니다.

### 신뢰도를 막대그래프처럼 보여주기

```tsx
<div className="w-16 bg-slate-100 rounded-full h-1.5">
  <div
    className={`h-full rounded-full ${ins.result === "defect" ? "bg-red-400" : "bg-green-400"}`}
    style={{ width: `${(ins.confidence ?? 0) * 100}%` }}
  />
</div>
```

바깥쪽 `<div>`(회색 배경, 너비 64px 고정)와 안쪽 `<div>`(색깔 있는 막대, 너비를 `confidence * 100%`로 동적 지정)를 겹쳐서, **순수 CSS만으로 작은 막대그래프**를 만든 것입니다. 차트 라이브러리 없이도 간단한 시각화는 이런 식으로 충분히 구현할 수 있습니다.

## 3. 통계 대시보드 — 전체 코드

```tsx
"use client";
// components/dashboard/StatsDashboard.tsx
// 통계 대시보드 - recharts 차트 4종 + 요약 카드

import { useMemo, useState } from "react";
import {
  PieChart, Pie, Cell, Tooltip, Legend, ResponsiveContainer,
  BarChart, Bar, XAxis, YAxis, CartesianGrid,
  LineChart, Line,
} from "recharts";
import { CheckCircle, AlertTriangle, Activity, TrendingUp, BarChart2 } from "lucide-react";
import { defectTypeKr, CATEGORY_LIST, categoryShortLabel } from "@/lib/inspectionMeta";

const COLORS = ["#ef4444", "#3b82f6", "#f59e0b", "#10b981", "#8b5cf6", "#ec4899"];

interface Props {
  inspections: any[];
  ships: { id: string; name: string }[];
}

function StatCard({ title, value, sub, icon: Icon, color }: { title: string; value: string | number; sub?: string; icon: any; color: string; }) {
  return (
    <div className="bg-white rounded-xl border border-slate-200 p-5 flex items-center gap-4">
      <div className={`w-12 h-12 rounded-xl flex items-center justify-center flex-shrink-0 ${color}`}>
        <Icon className="w-6 h-6 text-white" />
      </div>
      <div>
        <p className="text-xs text-slate-500 mb-0.5">{title}</p>
        <p className="text-2xl font-bold text-slate-800">{value}</p>
        {sub && <p className="text-xs text-slate-400">{sub}</p>}
      </div>
    </div>
  );
}

export default function StatsDashboard({ inspections, ships }: Props) {
  const [selectedShip, setSelectedShip] = useState("all");
  const [period, setPeriod] = useState<"7" | "30" | "90">("30");

  const filtered = useMemo(() => {
    if (selectedShip === "all") return inspections;
    return inspections.filter((ins) => ins.ship_id === selectedShip);
  }, [inspections, selectedShip]);

  const now = Date.now();
  const periodFiltered = useMemo(() => {
    const cutoff = now - Number(period) * 24 * 60 * 60 * 1000;
    return filtered.filter((ins) => new Date(ins.created_at).getTime() >= cutoff);
  }, [filtered, period, now]);

  const total    = periodFiltered.length;
  const defects  = periodFiltered.filter((i) => i.result === "defect").length;
  const normals  = total - defects;
  const defectRate = total ? ((defects / total) * 100).toFixed(1) : "0.0";
  const avgConf  = total ? ((periodFiltered.reduce((s, i) => s + (i.confidence ?? 0), 0) / total) * 100).toFixed(1) : "0.0";

  const pieData = [{ name: "정상", value: normals }, { name: "불량", value: defects }];
  const PIE_COLORS = ["#22c55e", "#ef4444"];

  const defectTypeMap: Record<string, number> = {};
  periodFiltered.forEach((ins) => {
    if (ins.result === "defect" && ins.defect_type) {
      defectTypeMap[ins.defect_type] = (defectTypeMap[ins.defect_type] ?? 0) + 1;
    }
  });
  const defectTypeData = Object.entries(defectTypeMap)
    .map(([key, cnt]) => ({ name: defectTypeKr[key] ?? key, count: cnt }))
    .sort((a, b) => b.count - a.count);

  const dayMap: Record<string, { date: string; total: number; defect: number }> = {};
  periodFiltered.forEach((ins) => {
    const d = new Date(ins.created_at).toISOString().slice(0, 10);
    if (!dayMap[d]) dayMap[d] = { date: d, total: 0, defect: 0 };
    dayMap[d].total++;
    if (ins.result === "defect") dayMap[d].defect++;
  });
  const trendData = Object.values(dayMap)
    .sort((a, b) => a.date.localeCompare(b.date))
    .map((d) => ({ date: d.date.slice(5), total: d.total, defect: d.defect }));

  const shipMap: Record<string, { name: string; total: number; defect: number }> = {};
  inspections.forEach((ins) => {
    const sid  = ins.ship_id;
    const sname = ins.ship?.name ?? sid;
    if (!shipMap[sid]) shipMap[sid] = { name: sname, total: 0, defect: 0 };
    shipMap[sid].total++;
    if (ins.result === "defect") shipMap[sid].defect++;
  });
  const shipData = Object.values(shipMap).sort((a, b) => b.defect - a.defect).slice(0, 8);

  return (
    <div className="space-y-6">
      <div className="flex flex-wrap gap-3 items-center bg-white border border-slate-200 rounded-xl p-4">
        <div>
          <label className="text-xs text-slate-500 mr-2">선박</label>
          <select value={selectedShip} onChange={(e) => setSelectedShip(e.target.value)} className="text-sm border border-slate-300 rounded-lg px-3 py-1.5 focus:outline-none focus:ring-2 focus:ring-blue-500">
            <option value="all">전체</option>
            {ships.map((s) => <option key={s.id} value={s.id}>{s.name}</option>)}
          </select>
        </div>
        <div>
          <label className="text-xs text-slate-500 mr-2">기간</label>
          {(["7", "30", "90"] as const).map((d) => (
            <button key={d} onClick={() => setPeriod(d)} className={`text-xs px-3 py-1.5 rounded-lg border mr-1 transition-colors ${period === d ? "bg-blue-600 text-white border-blue-600" : "border-slate-300 text-slate-600 hover:bg-slate-50"}`}>{d}일</button>
          ))}
        </div>
      </div>

      <div className="grid grid-cols-2 lg:grid-cols-4 gap-4">
        <StatCard title="전체 검사"   value={total}        icon={Activity}      color="bg-blue-500" />
        <StatCard title="불량 건수"   value={defects}      icon={AlertTriangle} color="bg-red-500"  sub={`불량률 ${defectRate}%`} />
        <StatCard title="정상 건수"   value={normals}      icon={CheckCircle}   color="bg-green-500" />
```

## 4. 핵심 부분 뜯어보기

### recharts의 기본 작동 원리

`recharts`는 "데이터 배열을 넣으면 그 모양에 맞춰 차트를 그려주는" React 차트 라이브러리입니다. 모든 차트가 공통적으로 따르는 패턴이 있습니다:

```tsx
<BarChart data={배열}>
  <XAxis dataKey="name" />     {/* X축에 표시할 값은 배열 각 항목의 "name" 속성 */}
  <YAxis />
  <Bar dataKey="count" />       {/* 막대 높이는 배열 각 항목의 "count" 속성 */}
</BarChart>
```

즉, **데이터 배열의 각 객체가 어떤 모양(`{name, count}` 등)인지 우리가 가공해서 넘겨주고, `dataKey`로 "이 축/막대는 그 객체의 어떤 속성을 쓸지" 지정**하는 구조입니다. 차트를 그리기 전에 원본 데이터(`inspections` 배열)를 차트가 원하는 모양으로 가공하는 작업이 항상 먼저 필요합니다 — 이게 이 컴포넌트 코드의 대부분을 차지하는 이유입니다.

### 데이터 집계(Aggregation) 패턴 — 불량 유형별 건수 세기

```tsx
const defectTypeMap: Record<string, number> = {};
periodFiltered.forEach((ins) => {
  if (ins.result === "defect" && ins.defect_type) {
    defectTypeMap[ins.defect_type] = (defectTypeMap[ins.defect_type] ?? 0) + 1;
  }
});
const defectTypeData = Object.entries(defectTypeMap)
  .map(([key, cnt]) => ({ name: defectTypeKr[key] ?? key, count: cnt }))
  .sort((a, b) => b.count - a.count);
```

이건 "같은 종류끼리 묶어서 개수를 세는" 매우 흔한 데이터 처리 패턴입니다.

1. **빈 딕셔너리(`{}`)에서 시작**: `defectTypeMap`을 빈 객체로 시작
2. **하나씩 돌면서 카운트 증가**: `defectTypeMap[키] = (기존값 ?? 0) + 1` — 키가 처음 나오면 `?? 0`으로 0에서 시작해서 1이 되고, 이미 있던 키면 기존 값에 1을 더함
3. **딕셔너리를 배열로 변환**: `Object.entries(딱셔너리)`는 `[[키1, 값1], [키2, 값2], ...]` 형태의 배열을 만들어줍니다. 이걸 `.map()`으로 차트가 원하는 `{name, count}` 모양으로 바꿉니다.
4. **정렬**: `.sort((a, b) => b.count - a.count)`는 "개수가 많은 것부터" 내림차순 정렬 (이 빼기 방식의 정렬 함수는 자바스크립트의 관용적인 표현입니다 — `b - a`면 내림차순, `a - b`면 오름차순)

같은 패턴이 "일별 추이"(날짜별로 묶기)와 "선박별 현황"(선박 id별로 묶기)에도 반복해서 쓰였습니다. **"무언가의 키를 기준으로 묶어서 집계한다"**는 이 패턴 자체를 익혀두면, 어떤 통계 화면을 만들든 거의 항상 응용할 수 있습니다.

### 기간 필터 — 밀리초 계산

```tsx
const now = Date.now();
const periodFiltered = useMemo(() => {
  const cutoff = now - Number(period) * 24 * 60 * 60 * 1000;
  return filtered.filter((ins) => new Date(ins.created_at).getTime() >= cutoff);
}, [filtered, period, now]);
```

자바스크립트의 시간은 기본적으로 **1970년 1월 1일부터 흐른 밀리초(1/1000초) 수**로 다뤄집니다. "7일 전"을 구하려면:

```
7일 × 24시간 × 60분 × 60초 × 1000밀리초 = 7일을 밀리초로 환산한 값
지금 시각(now) - 그 값 = "7일 전" 시각
```

그 다음 각 검사 기록의 `created_at`을 같은 단위(밀리초)로 변환(`new Date(...).getTime()`)해서, "7일 전 시각보다 더 최근인가?"를 비교합니다.

### Recharts 컴포넌트 구조: `ResponsiveContainer` → 차트 → 축/막대/선

```tsx
<ResponsiveContainer width="100%" height={240}>
  <BarChart data={...}>
    <CartesianGrid .../>   {/* 배경 격자줄 */}
    <XAxis .../>            {/* X축 */}
    <YAxis .../>             {/* Y축 */}
    <Tooltip .../>           {/* 마우스를 올리면 나오는 말풍선 */}
    <Legend />                {/* 범례 (색깔-이름 표) */}
    <Bar dataKey="count" />   {/* 실제 막대 */}
  </BarChart>
</ResponsiveContainer>
```

- **`ResponsiveContainer`**: 부모 요소의 크기에 맞춰 차트 크기를 자동으로 조절해주는 래퍼(wrapper) 컴포넌트. `width="100%"`로 두면 화면 너비가 바뀌어도(반응형 디자인) 차트가 알맞게 늘어나거나 줄어듭니다.
- **`<Cell>`로 막대마다 색 다르게 칠하기**:
  ```tsx
  <Bar dataKey="count">
    {defectTypeData.map((_, idx) => <Cell key={idx} fill={COLORS[idx % COLORS.length]} />)}
  </Bar>
  ```
  기본적으로 `<Bar>`는 모든 막대를 같은 색으로 그립니다. 막대마다 다른 색을 주려면 데이터 개수만큼 `<Cell>`을 자식으로 넣어서 각각 색을 지정해야 합니다. `idx % COLORS.length`는 "색상 배열의 개수를 넘어가면 다시 처음 색부터 반복"하는 나머지 연산(modulo) 활용입니다.

## 5. 정리

이번 글의 핵심 개념:

- **early return 필터링**: 여러 조건을 순서대로 검사하며 하나라도 안 맞으면 즉시 탈락시키는 패턴
- **클라이언트 사이드 페이지네이션**: `slice()`로 화면에 보여줄 구간만 잘라내기
- **데이터 집계(Aggregation) 패턴**: 빈 딕셔너리 → 순회하며 카운트 누적 → 배열로 변환 → 정렬
- **recharts**: 가공된 데이터 배열 + `dataKey`로 차트를 선언적으로 그리는 라이브러리
- **시간 계산**: 밀리초 단위로 날짜를 다루고 "N일 전" 같은 기준 시각을 계산하는 방법
- **`<Cell>`을 이용한 색상 분기**: 막대/파이 차트의 각 조각마다 다른 색을 입히는 방법
