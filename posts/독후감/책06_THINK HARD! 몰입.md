- 풀리지 않는 문제에 몰입을 하게 되면 자신의 가치와 삶의 만족도가 치솟는다.
[그래프: 세로축 과제(낮음~높음), 가로축 실력(낮음~높음)
- 불안(업무, 공부) / 각성(배움, 학습) / 몰입
- 걱정(선쟁) / 자신감(운전)
- 무관심(TV) / 권태(가사, 잡일) / 느긋함(독서, 식사)]
몰입 초기: 「왜?」로 시작 ← 수렴적 사고
몰입 중반: 「어떻게?」를 생각 ← 분산적 사고

몰입하기 위한 (법)
제1일 - 잡념을 털어내고 자세를 만든다.
      - 천천히 명상하듯 생각
      - 아이디어가 떠오를 시 즉시 기록
      - 규칙적인 운동
      - 언제나 생각
제2일 - 아이디어가 움직이기 시작한다
제3일 - 생각하는 재미가 솟구친다.

- 운동을 하며 몰입을 하는 것은 장기간의 몰입을 도와준다.
- 잠 잘 때도 펜과 노트를 머리맡에 두고 자기
- 몰입에 들어가려면 목적지향을 이용해야 한다. (위기감을 느끼거나 → 목표와 멀어질 때 / 재미를 활용하거나 → 목표와 가까워지며)
- 무엇인가를 진정으로 원하는 사람은 언젠가는 그 목표를 반드시 이루고야만다.
- 능동적인 몰입 (효율↑, 즐거움) / 수동적인 몰입 (문제 해결력↑, 스트레스)
  - 전환 방법 '천천히 생각하기'
- 몰입을 유도하는 죽음에의 통찰 '죽음이 없으면 삶도 없다' '죽음이 없으면 발전도 없다'
- 문제를 충분히 읽고 완전히 이해한 후 스스로 천천히 생각만 하기

몰입에 이르는 다섯 단계 (습관 형성)
제1단계 생각하기 연습 (20분 생각하기)
  - 풀리지 않는 문제를 20분간 생각한다, 하루에 5번, 2주 이상 연습
제2단계 천천히 생각하기 (2시간 생각하기)
  - 풀리지 않는 문제를 2시간 동안 생각한다. 하루에 1번, 2주 동안 연습
제3단계 최상의 컨디션 유지 (하루 종일 생각하기)
  - 좋아하는 운동을 매일 1시간씩 한다. 풀리지 않는 문제를 매일 2시간씩, 일요일에는 하루종일
제4단계 두뇌활동의 극대화 (7일간 생각하기)
제5단계 가치관의 변화
